## 基本概念

信号量本质上是一个**整型计数器**，表示某种资源的可用数量：

- **P 操作**（`wait` / `down`）：申请资源，计数器减 1。若结果小于 0，表示资源不可用，调用者阻塞等待。
- **V 操作**（`signal` / `up`）：释放资源，计数器加 1。若结果 ≤ 0，唤醒一个等待的线程。

公式表示：

```
P(S): S = S - 1; if (S < 0) block();
V(S): S = S + 1; if (S <= 0) wakeup();
```



## 类型

1. **计数信号量（Counting Semaphore）**
   - 计数值可以大于 1。
   - 常用于限制同时访问某资源的线程数（比如连接池、线程池、数据库连接数）。
2. **二进制信号量（Binary Semaphore / Mutex Semaphore）**
   - 计数值只能是 0 或 1。
   - 类似于互斥锁，用于保证同一时刻只有一个线程进入临界区。
