### . “条件变量 + 互斥锁”的典型使用模式

```
std::mutex mtx;
std::condition_variable cv;
bool ready = false;

void worker() {
    std::unique_lock<std::mutex> lock(mtx);
    cv.wait(lock, []{ return ready; }); // 自动解锁并阻塞，唤醒后重新加锁
    // 这里一定看到 ready == true
    // 执行任务
}

void notifier() {
    {
        std::lock_guard<std::mutex> lock(mtx);
        ready = true;
    }
    cv.notify_one(); // 通知等待的线程
}
```

- `wait` 内部会：
  1. 解锁互斥量；
  2. 阻塞等待信号；
  3. 被唤醒后重新加锁，检查条件。

这样保证了**不会丢信号**，而且**条件与数据访问同步**。
