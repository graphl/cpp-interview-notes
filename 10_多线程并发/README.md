# C++ 多线程并发

并发题必须先说共享状态和不变量，再选择锁或原子操作。只展示 API 而不说明 happens-before、退出协议和资源生命周期，代码通常并不完整。

## 推荐学习顺序

```text
thread 生命周期、join/detach
  -> mutex 与 RAII 锁
  -> condition_variable 与谓词
  -> 死锁条件和锁顺序
  -> atomic、CAS、内存序
  -> future/promise/async
  -> 线程池与无锁结构
```

## 分析并发代码的固定问题

1. 哪些状态被多个线程访问？
2. 每个不变量由哪把锁或哪个原子变量保护？
3. 等待条件由谁修改，通知丢失是否会影响正确性？
4. 停止、异常、析构和线程退出如何协调？
5. 操作之间需要怎样的可见性和顺序保证？
6. 代码防住数据竞争后，是否仍存在死锁、活锁、饥饿或伪共享？

## 待补重点

六种内存序的可运行实验、ABA、无锁内存回收、伪共享、`thread_local`、`call_once` 和结构化停止协议。
