## 所有构造方式（重点）

### 1️⃣ 立即加锁（最常用）

```c
std::unique_lock<std::mutex> lock(mtx);
```

```C++
❌ 已经加锁不能再加锁了
std::unique_lock<std::mutex> lock(mtx);
lock.lock();

terminate called after throwing an instance of 'std::system_error'
  what():  Resource deadlock avoided
Aborted (core dumped)
```

------

### 2️⃣ 延迟加锁（`defer_lock`）

```
std::unique_lock<std::mutex> lock(mtx, std::defer_lock);
// 此时还没加锁
lock.lock();
```

📌 **用途：**

- 条件判断后再加锁
- 多锁协作

------

### 3️⃣ 尝试加锁（`try_to_lock`）

```
std::unique_lock<std::mutex> lock(mtx, std::try_to_lock);
if (!lock.owns_lock()) { // owns_lock() 用来判断 unique_lock 当前是否“真的持有”这把互斥锁
    return;
}

```

✔️ 不阻塞
 ✔️ try_lock 语义

```
❌ 已经加锁不能再加锁了
std::unique_lock<std::mutex> uLock(mtx, std::try_to_lock);
uLock.lock();

terminate called after throwing an instance of 'std::system_error'
  what():  Resource deadlock avoided
Aborted (core dumped)
```

------

### 4️⃣ 接管已加锁的 mutex（`adopt_lock`）

```
mtx.lock(); // 加入没上锁lock不会上锁
/// 锁所有权的接管（adopt）
std::unique_lock<std::mutex> lock(mtx, std::adopt_lock);
```

```
std::unique_lock<std::mutex> lock(mtx);
std::unique_lock<std::unique_lock<std::mutex>> uLock(lock, std::adopt_lock);
increase++;
```

📌 **责任转移**

- mutex 必须已经被当前线程锁住

------

### 5️⃣ timed_mutex 专用构造

```
std::timed_mutex tmtx;

std::unique_lock<std::timed_mutex> lock(
    tmtx,
    std::chrono::milliseconds(10)
);
```
