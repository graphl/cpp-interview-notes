## C++ 标准库里的锁（<mutex>）

### 1. `std::mutex` —— 最基础的互斥锁

```
#include <mutex>

std::mutex mtx;

void func() {
    mtx.lock();
    // 临界区
    mtx.unlock();
}
```

### 2. `std::timed_mutex`（带超时）

```
std::timed_mutex tmtx;

if (tmtx.try_lock_for(std::chrono::milliseconds(100))) {
    // 成功
    tmtx.unlock();
}
```

### 3. `std::recursive_mutex`（递归锁）

```
std::recursive_mutex rmtx;

void f() {
    rmtx.lock();
    f();    // 同一线程可再次加锁
    rmtx.unlock();
}
```
