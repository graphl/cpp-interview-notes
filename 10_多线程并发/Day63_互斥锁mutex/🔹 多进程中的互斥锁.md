## 🔹 多进程中的互斥锁

进程之间有独立的虚拟地址空间，不能直接共享普通变量，所以互斥锁要借助**共享内存**或**操作系统提供的 IPC 机制**。

### 常见实现方式

1. **POSIX 进程间互斥锁（pthread + 共享内存）**

   - `pthread_mutexattr_setpshared(&attr, PTHREAD_PROCESS_SHARED);`
      设置锁可以在**多个进程之间共享**。
   - 锁对象必须放在 **共享内存** 中（如 `mmap`、`shmget`）。

   ✅ 示例：

   ```
   pthread_mutex_t *lock;
   pthread_mutexattr_t attr;
   
   int fd = shm_open("/myshm", O_CREAT | O_RDWR, 0666);
   ftruncate(fd, sizeof(pthread_mutex_t));
   lock = (pthread_mutex_t*)mmap(NULL, sizeof(pthread_mutex_t),
                                 PROT_READ | PROT_WRITE, MAP_SHARED, fd, 0);
   
   pthread_mutexattr_init(&attr);
   pthread_mutexattr_setpshared(&attr, PTHREAD_PROCESS_SHARED);
   pthread_mutex_init(lock, &attr);
   
   // 各个进程都能加锁解锁
   pthread_mutex_lock(lock);
   // 临界区
   pthread_mutex_unlock(lock);
   ```

2. **System V / POSIX 信号量（sem_t, sem_open, semget）**

   - `sem_t` 可以用作互斥锁，适合多进程。
   - 信号量值为 1 时，相当于互斥锁。

   ✅ 示例（POSIX 信号量）：

   ```
   sem_t *sem = sem_open("/mysem", O_CREAT, 0666, 1);
   
   sem_wait(sem);   // 加锁
   // 临界区
   sem_post(sem);   // 解锁
   ```

3. **文件锁（fcntl, flock）**

   - 通过锁文件的方式在多个进程之间实现互斥。
   - 常用于进程间的简单互斥（如日志写入）。
