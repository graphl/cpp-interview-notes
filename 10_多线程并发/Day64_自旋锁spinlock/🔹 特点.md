## 🔹 特点

1. **忙等**：线程一直占用 CPU，不释放执行权。
2. **适用场景**：
   - 临界区很短（锁持有时间极短）；
   - 多核 CPU；
   - 避免线程切换的开销比忙等开销还要大时。
3. **不适用场景**：
   - 临界区长（比如里面有 I/O 操作）；
   - 单核 CPU（其他线程永远得不到运行机会 → 死锁）。

## 🔹 和互斥锁的对比

| 特性           | 互斥锁 (mutex)     | 自旋锁 (spinlock)    |
| -------------- | ------------------ | -------------------- |
| 等待方式       | 阻塞，可能睡眠     | 忙等，占 CPU         |
| 临界区长度     | 适合较长（可睡眠） | 适合极短             |
| 使用场景       | 进程/线程同步      | 内核同步、中断上下文 |
| 单核行为       | 阻塞/唤醒          | 退化为关中断         |
| 内核上下文使用 | 可以睡眠           | 不允许睡眠           |
