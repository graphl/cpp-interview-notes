## 如何排查死锁？

现象：

```text
程序不崩溃，但不继续运行
CPU 可能很低
线程都在 futex / pthread_mutex_lock / condition_variable 等待
日志停在某个位置
```

GDB：

```bash
gdb -p <pid>
```

```gdb
info threads
thread apply all bt
```

如果看到多个线程卡在：

```text
pthread_mutex_lock
std::mutex::lock
std::condition_variable::wait
futex
```

就要看它们分别在等哪把锁。

Linux 命令：

```bash
pstack <pid>
strace -p <pid>
top -H -p <pid>
```
