##  实际场景 1：转账业务死锁

###  错误写法

两个账户转账：

```cpp
struct Account {
    std::mutex mtx;
    int balance;
};

void transfer(Account& from, Account& to, int money) {
    std::lock_guard<std::mutex> lock1(from.mtx);
    std::lock_guard<std::mutex> lock2(to.mtx);

    from.balance -= money;
    to.balance += money;
}
```

如果两个线程同时执行：

```text
线程 A：transfer(account1, account2)
线程 B：transfer(account2, account1)
```

可能发生：

```text
线程 A 拿到 account1.mtx，等待 account2.mtx
线程 B 拿到 account2.mtx，等待 account1.mtx
```

这就是典型死锁。

###  正确写法：std::lock

```cpp
void transfer(Account& from, Account& to, int money) {
    std::lock(from.mtx, to.mtx);

    std::lock_guard<std::mutex> lock1(from.mtx, std::adopt_lock);
    std::lock_guard<std::mutex> lock2(to.mtx, std::adopt_lock);

    from.balance -= money;
    to.balance += money;
}
```

C++17 更推荐：

```cpp
void transfer(Account& from, Account& to, int money) {
    std::scoped_lock lock(from.mtx, to.mtx);

    from.balance -= money;
    to.balance += money;
}
```

`std::scoped_lock` 可以一次锁住多把锁，并使用避免死锁的加锁策略。
