# C++ 异常安全

异常安全关注的不只是“能不能 catch”，而是控制流提前离开后，对象、资源和业务状态是否仍满足承诺。

## 推荐学习顺序

```text
throw、异常对象与 catch 匹配
  -> 栈展开与局部对象析构
  -> RAII
  -> 基本/强/nothrow 保证
  -> 构造、析构与 noexcept
  -> 智能指针和容器的异常边界
```

## 必会问题

1. 抛出的异常对象存在哪里，为什么通常按 `const&` 捕获？
2. 栈展开期间哪些对象会析构，哪些尚未构造完成？
3. 构造函数抛异常时，完整对象的析构函数为什么不执行？
4. 析构函数在栈展开期间再次抛异常为什么危险？
5. 基本保证和强保证分别承诺什么？copy-and-swap 如何提供强保证？
6. `noexcept` 如何影响终止行为和容器的移动策略？

## 待补重点

异常对象生命周期、catch 匹配顺序、重新抛出、`exception_ptr`、嵌套异常和跨线程传播。
