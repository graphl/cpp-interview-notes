# 构造函数是否可以抛异常？

✅ **可以抛出异常**。

- C++ 允许构造函数在初始化过程中因为资源获取失败而抛出异常，比如分配内存失败、打开文件失败等。

- 如果构造函数抛出异常，**对象不会被认为构造完成**，因此：

  1. 已经构造成功的成员会被自动析构。
  2. 对象本身不会进入有效状态，也不会调用析构函数。

  ```
  #include <iostream>
  #include <stdexcept>
  using namespace std;
  
  class A {
  public:
      A() {
          cout << "A constructor\n";
          throw runtime_error("fail in constructor");
      }
      ~A() { cout << "A destructor\n"; }
  };
  
  int main() {
      try {
          A a; // 构造时抛异常
      } catch (const exception& e) {
          cout << "Caught: " << e.what() << endl;
      }
  }
  
  ```


  结果:
  A constructor
  Caught: fail in constructor
  注意：析构函数没有执行，因为对象根本没有构造完成。
