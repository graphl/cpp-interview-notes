##  析构函数是否可以抛异常？

⚠️ **强烈不建议抛异常**，虽然语法上允许你 `throw`。
 原因：

1. 如果在 **栈展开（stack unwinding）** 过程中析构函数又抛异常，程序会直接调用 `std::terminate`，导致程序崩溃。

   ```
   class B {
   public:
       ~B() {
           throw runtime_error("error in destructor");
       }
   };
   int main() {
       try {
           B b;
       } catch (...) {
           cout << "catch\n"; // 捕获不到
       }
   }
   程序直接 terminate，不会执行 catch。
   ```

   

2. 标准库的 RAII 资源管理对象（如 `std::lock_guard`, `std::unique_ptr`）都假设析构函数不会抛异常，否则会破坏异常安全。

3. 👉 **推荐做法**：

   - 析构函数内部如果有可能失败，应该用 **捕获并记录错误**，而不是继续抛异常。

     ```
     ~B() noexcept {
         try {
             // 可能失败的操作
         } catch (...) {
             // 记录日志，保证不抛出
         }
     }
     ```
