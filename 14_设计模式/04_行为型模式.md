# 04_行为型模式

## 核心总结

行为型模式关注对象之间如何通信、如何分配职责、如何替换算法、如何管理状态变化。面试中行为型模式非常高频，因为它们容易和业务场景结合。

## 1. 策略模式

### 高频问题

- 策略模式解决什么问题？
- 策略模式和工厂模式如何结合？
- 策略模式和状态模式有什么区别？

### 答题要点

- 把一组算法封装起来，使它们可以相互替换。
- 调用方依赖抽象策略，不依赖具体算法。
- 策略通常由外部选择，状态通常由对象内部状态驱动切换。

### 场景示例

- 支付方式：支付宝、微信、银行卡。
- 排序策略：快速排序、归并排序、堆排序。
- 压缩策略：zip、gzip、lz4。

## 2. 观察者模式

### 高频问题

- 观察者模式是什么？
- 观察者模式和发布订阅模式有什么区别？
- C++ 中实现观察者模式要注意什么？

### 答题要点

- 一个对象状态变化时，自动通知多个依赖对象。
- 观察者和被观察者通常直接关联。
- 发布订阅一般通过事件中心解耦发布者和订阅者。
- C++ 中要注意对象生命周期，避免悬空指针。

## 3. 模板方法模式

### 高频问题

- 模板方法模式的核心思想是什么？
- 模板方法和策略模式有什么区别？

### 答题要点

- 父类定义算法骨架，子类实现部分步骤。
- 模板方法基于继承，策略模式基于组合。
- 模板方法适合流程稳定、步骤可变的场景。

## 4. 责任链模式

### 高频问题

- 责任链模式适合处理什么问题？
- 责任链模式有什么缺点？

### 答题要点

- 请求沿处理链传递，直到被某个节点处理。
- 降低发送者和处理者之间的耦合。
- 缺点是请求可能没人处理，链路过长会影响调试和性能。

### 场景示例

- 日志级别处理。
- HTTP 中间件。
- 审批流程。
- 异常处理链。

## 5. 命令模式

### 高频问题

- 命令模式的作用是什么？
- 命令模式如何支持撤销和重做？

### 答题要点

- 将请求封装成对象。
- 可以支持队列、日志、撤销、重做、事务。
- 每个命令对象保存执行所需信息。

## 6. 状态模式

### 高频问题

- 状态模式和策略模式有什么区别？
- 状态模式适合什么业务？

### 答题要点

- 对象行为随内部状态变化而变化。
- 把不同状态下的行为封装成独立状态类。
- 适合订单、工单、播放器、连接状态、协议状态机等场景。

## 7. 其他行为型模式

### 迭代器模式

- 提供统一方式遍历集合。
- C++ STL 迭代器就是典型体现。

### 中介者模式

- 用中介对象封装多个对象之间的复杂交互。
- 适合对象之间关系网复杂的场景。

### 访问者模式

- 在不修改对象结构的前提下增加新操作。
- 适合对象结构稳定、操作经常变化的场景。

### 备忘录模式

- 保存对象某一时刻的状态，用于恢复。
- 常见于撤销、快照、游戏存档。

### 解释器模式

- 为某种语言或表达式定义解释规则。
- 常见于规则引擎、表达式解析、小型 DSL。

## 小结

行为型模式最容易结合项目经验。复习时建议重点准备策略、观察者、模板方法、责任链、命令、状态这六个模式。
