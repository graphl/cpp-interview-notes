# 14_设计模式

## 模块总览

设计模式面试题通常不只考“背模式名称”，更常考三件事：

1. 能否说清楚某个模式解决了什么设计问题。
2. 能否对比相似模式的边界。
3. 能否结合 C++ 项目场景给出合理实现。

如果已经能说出模式定义但不会做场景选择，优先阅读：[相似模式对比与选择](./知识点拆分版/25_相似模式对比与选择.md)。

本目录按模块整理：

- `01_基础概念与设计原则.md`：设计模式分类、SOLID、组合优于继承等基础。
- `02_创建型模式.md`：单例、工厂、抽象工厂、建造者、原型。
- `03_结构型模式.md`：适配器、装饰器、代理、外观、桥接、组合、享元。
- `04_行为型模式.md`：策略、观察者、模板方法、责任链、命令、状态等。
- `05_场景设计与高阶追问.md`：系统设计场景、模式组合、项目经验追问。

## 复习优先级

高频必会：

- 单例模式
- 工厂方法模式
- 抽象工厂模式
- 策略模式
- 观察者模式
- 装饰器模式
- 适配器模式
- 代理模式
- 责任链模式
- 模板方法模式
- 状态模式

## 面试回答模板

回答某个设计模式时，可以按下面顺序组织：

1. 它解决什么问题。
2. 核心角色有哪些。
3. C++ 中如何实现。
4. 优点和缺点。
5. 适用场景和不适用场景。
6. 和相似模式的区别。
