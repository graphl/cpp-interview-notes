# 06_原型模式

## 一句话总结

原型模式通过复制已有对象来创建新对象，适合创建成本高或初始状态复杂的场景。

## 面试高频问法

1. 原型模式是什么？
2. C++ 中如何实现 clone？
3. 深拷贝和浅拷贝有什么区别？
4. 原型模式适合什么场景？

## 核心原理

对象自己提供复制接口，客户端无需知道具体类型也能复制对象。

## C++ 实现

```cpp
class Shape {
public:
    virtual ~Shape() = default;
    virtual std::unique_ptr<Shape> clone() const = 0;
};

class Circle : public Shape {
public:
    std::unique_ptr<Shape> clone() const override {
        return std::make_unique<Circle>(*this);
    }
};
```

## 优点

- 避免重复复杂初始化。
- 客户端不依赖具体类型。
- 运行期可以复制多态对象。

## 缺点

- 深拷贝实现可能复杂。
- 对象中有指针、文件句柄、网络连接时要特别小心。

## 适用场景

- 图形编辑器复制图形对象。
- 游戏对象复制。
- 配置模板复制。
- 创建成本较高的对象。

## 常见追问

浅拷贝只复制指针值，多个对象可能共享同一资源；深拷贝会复制资源本身，更安全但成本更高。

## 小红书分享文案

原型模式一句话：别重新造，复制一个。C++ 里常用虚函数 `clone()` 复制多态对象，面试一定要顺带讲清楚深拷贝和浅拷贝。
