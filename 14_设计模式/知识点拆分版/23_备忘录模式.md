# 23_备忘录模式

## 一句话总结

备忘录模式在不破坏封装的前提下，保存对象状态，以便之后恢复。

## 面试高频问法

1. 备忘录模式解决什么问题？
2. 备忘录模式如何支持撤销？
3. 备忘录和命令模式有什么关系？
4. 备忘录模式有什么缺点？

## 核心原理

原发器创建备忘录保存状态，管理者保存备忘录，但不直接操作状态内容。

## C++ 实现

```cpp
class Memento {
public:
    explicit Memento(std::string state) : state_(std::move(state)) {}
    const std::string& state() const { return state_; }

private:
    std::string state_;
};

class Editor {
public:
    Memento save() const {
        return Memento(text_);
    }

    void restore(const Memento& memento) {
        text_ = memento.state();
    }

private:
    std::string text_;
};
```

## 优点

- 支持状态恢复。
- 不破坏对象封装。
- 适合撤销、快照、回滚。

## 缺点

- 状态大时内存开销高。
- 频繁保存快照成本高。

## 适用场景

- 编辑器撤销。
- 游戏存档。
- 事务回滚。
- 配置快照。

## 常见追问

命令模式可以记录操作，备忘录模式可以保存状态；撤销系统中二者经常配合使用。

## 小红书分享文案

备忘录模式可以理解成“存档”。编辑器撤销、游戏存档、事务回滚，本质都是保存某个时刻的状态，之后再恢复。
