# 09_代理模式

## 一句话总结

代理模式为真实对象提供一个代理对象，用来控制对真实对象的访问。

## 面试高频问法

1. 代理模式解决什么问题？
2. 代理模式有哪些类型？
3. 代理和装饰器有什么区别？
4. 静态代理和动态代理有什么区别？

## 核心原理

代理对象和真实对象实现相同接口，客户端访问代理对象，由代理对象决定如何访问真实对象。

## C++ 实现

```cpp
class Image {
public:
    virtual ~Image() = default;
    virtual void display() = 0;
};

class RealImage : public Image {
public:
    void display() override {}
};

class ImageProxy : public Image {
public:
    void display() override {
        if (!image_) {
            image_ = std::make_unique<RealImage>();
        }
        image_->display();
    }

private:
    std::unique_ptr<RealImage> image_;
};
```

## 优点

- 控制真实对象访问。
- 可以延迟加载。
- 可以增加权限、缓存、日志等逻辑。

## 缺点

- 增加间接层。
- 可能让调用链变复杂。

## 适用场景

- 延迟加载。
- 权限控制。
- 远程调用。
- 缓存代理。

## 常见追问

代理是为了控制访问，装饰器是为了增强功能。两者结构相似，但设计意图不同。

## 小红书分享文案

代理模式面试最容易和装饰器混。记住一句话：代理控制访问，装饰器增强功能。比如图片懒加载、权限校验、远程调用，都很适合代理。
