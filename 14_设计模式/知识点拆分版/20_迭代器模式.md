# 20_迭代器模式

## 一句话总结

迭代器模式提供一种统一方式遍历集合，而不暴露集合内部结构。

## 面试高频问法

1. 迭代器模式解决什么问题？
2. C++ STL 迭代器体现了什么思想？
3. 迭代器有什么优点？
4. 迭代器失效是什么？

## 核心原理

把遍历逻辑封装到迭代器对象中，集合只提供获取迭代器的接口。

## C++ 实现

```cpp
std::vector<int> nums{1, 2, 3};

for (auto it = nums.begin(); it != nums.end(); ++it) {
    int value = *it;
}
```

## 优点

- 统一遍历接口。
- 隐藏容器内部结构。
- 支持多种遍历方式。

## 缺点

- 修改容器时可能导致迭代器失效。
- 自定义迭代器实现需要遵守语义约定。

## 适用场景

- STL 容器遍历。
- 自定义集合类。
- 树、图等复杂结构遍历。

## 常见追问

vector 扩容可能导致迭代器失效；list 插入删除通常只影响被删除元素的迭代器。

## 小红书分享文案

C++ 里的 STL 迭代器就是迭代器模式的经典体现。它让不同容器拥有统一遍历方式，但面试一定要补充迭代器失效问题。
