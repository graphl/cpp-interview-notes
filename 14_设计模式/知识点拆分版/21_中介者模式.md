# 21_中介者模式

## 一句话总结

中介者模式用一个中介对象封装多个对象之间的复杂交互。

## 面试高频问法

1. 中介者模式解决什么问题？
2. 中介者模式和观察者模式有什么区别？
3. 中介者模式有什么缺点？
4. 什么场景适合中介者？

## 核心原理

对象之间不直接相互调用，而是通过中介者协调交互。

## C++ 实现

```cpp
class Mediator {
public:
    virtual ~Mediator() = default;
    virtual void notify(const std::string& event) = 0;
};

class Component {
public:
    explicit Component(Mediator* mediator) : mediator_(mediator) {}

protected:
    Mediator* mediator_;
};
```

## 优点

- 降低多个对象之间的网状依赖。
- 交互逻辑集中管理。
- 对象本身更简单。

## 缺点

- 中介者可能变得复杂。
- 可能形成新的中心化耦合。

## 适用场景

- UI 控件联动。
- 聊天室。
- 机场调度。
- 多模块协同流程。

## 常见追问

观察者偏一对多通知；中介者偏集中协调多对象复杂交互。

## 小红书分享文案

对象之间互相调用太乱时，可以考虑中介者模式。它把网状关系变成星型关系，所有交互通过中介者协调。
