# 16_模板方法模式

## 一句话总结

模板方法模式在父类中定义算法骨架，把某些步骤延迟到子类实现。

## 面试高频问法

1. 模板方法模式的核心思想是什么？
2. 模板方法和策略模式有什么区别？
3. 模板方法适合什么场景？
4. 模板方法有什么缺点？

## 核心原理

父类控制流程顺序，子类只实现变化步骤。

## C++ 实现

```cpp
class DataProcessor {
public:
    virtual ~DataProcessor() = default;

    void process() {
        read();
        parse();
        save();
    }

protected:
    virtual void read() = 0;
    virtual void parse() = 0;
    virtual void save() = 0;
};
```

## 优点

- 复用稳定流程。
- 子类只关注变化步骤。
- 避免重复代码。

## 缺点

- 依赖继承。
- 父类变化可能影响所有子类。

## 适用场景

- 数据处理流程。
- 测试框架生命周期。
- 算法流程固定但步骤可变。

## 常见追问

模板方法基于继承，父类控制流程；策略模式基于组合，算法可以运行期替换。

## 小红书分享文案

模板方法适合“流程固定，步骤可变”的场景。父类写好整体流程，子类填充细节。比如读取、解析、保存这类固定处理链。
