# 14_策略模式

## 一句话总结

策略模式把一组算法封装起来，使它们可以相互替换。

## 面试高频问法

1. 策略模式解决什么问题？
2. 策略模式和工厂模式如何结合？
3. 策略模式和状态模式有什么区别？
4. 现代 C++ 中如何简化策略模式？

## 核心原理

调用方依赖抽象策略，不依赖具体算法；不同算法可以运行期切换。

## C++ 实现

```cpp
class PayStrategy {
public:
    virtual ~PayStrategy() = default;
    virtual void pay(int amount) = 0;
};

class WeChatPay : public PayStrategy {
public:
    void pay(int amount) override {}
};

class Order {
public:
    explicit Order(std::unique_ptr<PayStrategy> strategy)
        : strategy_(std::move(strategy)) {}

    void pay(int amount) {
        strategy_->pay(amount);
    }

private:
    std::unique_ptr<PayStrategy> strategy_;
};
```

## 优点

- 消除大量条件分支。
- 算法可独立扩展。
- 符合开闭原则。

## 缺点

- 策略类数量增加。
- 调用方需要知道选择哪种策略。

## 适用场景

- 支付方式。
- 排序算法。
- 压缩算法。
- 折扣计算。

## 常见追问

策略由外部选择；状态由对象内部状态驱动变化。

## 小红书分享文案

看到一堆 `if else` 在选择算法，就可以考虑策略模式。比如支付方式、优惠规则、排序算法，把每种算法拆成策略类，扩展时新增策略即可。
