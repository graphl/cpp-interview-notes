# 01_单例模式

## 一句话总结

单例模式保证一个类在进程中只有一个实例，并提供全局访问点。

## 面试高频问法

1. 单例模式是什么？
2. C++ 如何实现线程安全单例？
3. 懒汉式和饿汉式有什么区别？
4. Meyers Singleton 为什么线程安全？
5. 单例模式为什么有时被认为是反模式？

## 核心原理

构造函数私有化，禁止外部直接创建对象；通过静态函数返回唯一实例。

## C++ 实现

```cpp
class Singleton {
public:
    static Singleton& instance() {
        static Singleton obj;
        return obj;
    }

private:
    Singleton() = default;
    Singleton(const Singleton&) = delete;
    Singleton& operator=(const Singleton&) = delete;
};
```

## 优点

- 控制实例数量。
- 提供统一访问入口。
- 适合全局唯一资源。

## 缺点

- 容易隐藏全局依赖。
- 不利于单元测试。
- 共享可变状态可能带来并发问题。

## 适用场景

- 日志系统。
- 配置管理。
- 线程池管理器。
- 全局资源管理器。

## 常见追问

Meyers Singleton 在 C++11 后局部静态变量初始化是线程安全的，但成员函数内部的共享数据仍然需要自己保证线程安全。

## 小红书分享文案

C++ 单例模式最推荐写法是局部静态变量，也叫 Meyers Singleton。它简洁、懒加载，并且 C++11 后初始化线程安全。但单例不是万能药，能不用全局状态就别滥用。
