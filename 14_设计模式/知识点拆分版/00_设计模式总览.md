# 00_设计模式总览

## 一句话总结

设计模式是针对常见代码设计问题的可复用解决方案，核心目标是降低耦合、隔离变化、提升可维护性。

## 面试高频问法

1. 什么是设计模式？
2. 设计模式分为哪几类？
3. 设计模式和算法有什么区别？
4. 设计模式一定能提高代码质量吗？
5. 现代 C++ 中设计模式是否还重要？

## 核心分类

- 创建型模式：解决对象如何创建。
- 结构型模式：解决对象和类如何组合。
- 行为型模式：解决对象之间如何协作。

## 复习重点

- 创建型：单例、工厂方法、抽象工厂、建造者。
- 结构型：适配器、装饰器、代理、外观、桥接。
- 行为型：策略、观察者、模板方法、责任链、命令、状态。

## 面试回答模板

1. 这个模式解决什么问题。
2. 核心角色有哪些。
3. C++ 中如何实现。
4. 优点和缺点是什么。
5. 适合什么场景。
6. 和相似模式有什么区别。

## 小红书分享文案

C++ 面试问设计模式，不要只背名字。真正高频的是：这个模式解决什么问题、适合什么场景、和相似模式有什么区别。建议按“创建型、结构型、行为型”三类复习，再重点掌握单例、工厂、策略、观察者、装饰器、代理、责任链和状态模式。
