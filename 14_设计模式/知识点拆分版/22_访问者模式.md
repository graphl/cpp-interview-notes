# 22_访问者模式

## 一句话总结

访问者模式在不修改对象结构的前提下，为对象结构增加新的操作。

## 面试高频问法

1. 访问者模式解决什么问题？
2. 访问者模式适合什么场景？
3. 访问者模式有什么缺点？
4. 什么是双分派？

## 核心原理

对象结构稳定，操作经常变化时，把操作封装到访问者中。

## C++ 实现

```cpp
class Circle;
class Rect;

class Visitor {
public:
    virtual ~Visitor() = default;
    virtual void visit(Circle& circle) = 0;
    virtual void visit(Rect& rect) = 0;
};

class Shape {
public:
    virtual ~Shape() = default;
    virtual void accept(Visitor& visitor) = 0;
};
```

## 优点

- 新增操作方便。
- 把相关操作集中到访问者类。
- 适合对象结构稳定的系统。

## 缺点

- 新增元素类型困难。
- 访问者可能破坏封装。
- 理解成本较高。

## 适用场景

- AST 语法树处理。
- 编译器。
- 报表导出。
- 对稳定对象结构执行多种操作。

## 常见追问

访问者适合“结构稳定、操作多变”；如果元素类型经常变化，访问者会很痛苦。

## 小红书分享文案

访问者模式面试不算最高频，但很能体现设计能力。记住它的适用条件：对象结构稳定，新增操作频繁，比如编译器 AST 的分析、检查、生成代码。
