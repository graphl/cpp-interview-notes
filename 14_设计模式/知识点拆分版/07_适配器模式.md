# 07_适配器模式

## 一句话总结

适配器模式把一个已有接口转换成客户端期望的接口。

## 面试高频问法

1. 适配器模式解决什么问题？
2. 类适配器和对象适配器有什么区别？
3. 适配器和外观模式有什么区别？
4. 适配器适合什么时候使用？

## 核心原理

通过包装已有对象，把不兼容接口转换为目标接口。

## C++ 实现

```cpp
class Target {
public:
    virtual ~Target() = default;
    virtual void request() = 0;
};

class Adaptee {
public:
    void specificRequest() {}
};

class Adapter : public Target {
public:
    explicit Adapter(Adaptee* adaptee) : adaptee_(adaptee) {}

    void request() override {
        adaptee_->specificRequest();
    }

private:
    Adaptee* adaptee_;
};
```

## 优点

- 复用已有类。
- 解决接口不兼容。
- 客户端无需修改。

## 缺点

- 适配层过多会增加理解成本。
- 不适合接口差异特别大的场景。

## 适用场景

- 老接口兼容新系统。
- 第三方库接口封装。
- 不同模块接口对接。

## 常见追问

适配器解决接口不兼容；外观模式简化复杂子系统的使用。

## 小红书分享文案

适配器模式就像“接口翻译器”。已有类能用，但接口不符合当前系统要求，这时候加一个 Adapter，既复用旧代码，又不污染新接口。
