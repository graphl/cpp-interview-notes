# 02_创建型模式

## 核心总结

创建型模式关注对象的创建过程，目标是把“使用对象”和“创建对象”的代码解耦。当对象创建逻辑复杂、类型需要动态切换、产品族需要统一创建时，创建型模式很常见。

## 1. 单例模式

### 典型问题

- 单例模式是什么？适用于什么场景？
- C++ 中如何实现线程安全单例？
- 懒汉式和饿汉式有什么区别？
- Meyers Singleton 为什么线程安全？
- 单例模式有哪些缺点？

### 答题要点

- 保证一个类在进程中只有一个实例，并提供全局访问点。
- C++11 后局部静态变量初始化是线程安全的。
- 常用于配置管理、日志对象、全局资源管理器。
- 缺点是隐藏依赖、影响测试、可能引入全局状态。

### C++ 示例

```cpp
class Logger {
public:
    static Logger& instance() {
        static Logger logger;
        return logger;
    }

    void log(const std::string& msg);

private:
    Logger() = default;
    ~Logger() = default;
    Logger(const Logger&) = delete;
    Logger& operator=(const Logger&) = delete;
};
```

## 2. 工厂方法模式

### 典型问题

- 简单工厂和工厂方法有什么区别？
- 工厂方法模式解决什么问题？
- 工厂方法模式是否符合开闭原则？

### 答题要点

- 简单工厂通常由一个工厂函数根据参数创建对象。
- 工厂方法把创建逻辑延迟到子类。
- 新增产品时可以新增工厂类，减少对原工厂的修改。

## 3. 抽象工厂模式

### 典型问题

- 抽象工厂解决什么问题？
- 工厂方法和抽象工厂如何选择？
- 什么是产品族？

### 答题要点

- 抽象工厂用于创建一组相关或相互依赖的对象。
- 工厂方法关注一个产品等级结构。
- 抽象工厂关注多个产品等级结构组成的产品族。

### 场景示例

跨平台 UI：

- WindowsFactory 创建 WindowsButton、WindowsTextBox。
- MacFactory 创建 MacButton、MacTextBox。

## 4. 建造者模式

### 典型问题

- 建造者模式适合什么场景？
- 建造者模式和工厂模式有什么区别？

### 答题要点

- 适合创建过程复杂、参数很多、步骤固定但细节可变的对象。
- 工厂模式重点是“创建哪一种对象”。
- 建造者模式重点是“如何一步步构造对象”。

## 5. 原型模式

### 典型问题

- 原型模式是什么？
- C++ 中如何实现 clone？
- 深拷贝和浅拷贝有什么区别？

### 答题要点

- 通过复制已有对象创建新对象。
- 适合对象创建成本高，或对象初始状态复杂的场景。
- C++ 中常用虚函数 `clone()` 返回智能指针。

```cpp
class Shape {
public:
    virtual ~Shape() = default;
    virtual std::unique_ptr<Shape> clone() const = 0;
};
```

## 小结

创建型模式的核心是“隔离创建变化”。面试中要重点掌握单例的 C++ 实现、工厂方法和抽象工厂的区别、建造者适用场景。
