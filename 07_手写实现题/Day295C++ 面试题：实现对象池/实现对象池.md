# C++ 面试题：实现对象池

## 1. 考点

对象池预先分配一批槽位，重复构造和销毁对象，减少频繁向通用堆分配器申请内存的开销。

面试主要考：

1. 原始存储与对象生命周期
2. placement new
3. 显式调用析构函数
4. 空闲链表
5. 对齐
6. 异常安全

---

## 2. 固定容量对象池

```cpp
#include <cstddef>
#include <new>
#include <stdexcept>
#include <type_traits>
#include <utility>
#include <vector>

template <typename T>
class ObjectPool {
    union Slot {
        alignas(T) std::byte storage[sizeof(T)];
        Slot* next;
    };

public:
    explicit ObjectPool(size_t capacity)
        : slots_(capacity), used_(capacity, false) {
        for (size_t i = 0; i < capacity; ++i) {
            slots_[i].next = free_;
            free_ = &slots_[i];
        }
    }

    ~ObjectPool() {
        for (size_t i = 0; i < slots_.size(); ++i) {
            if (used_[i]) {
                object_at(i)->~T();
            }
        }
    }

    ObjectPool(const ObjectPool&) = delete;
    ObjectPool& operator=(const ObjectPool&) = delete;

    template <typename... Args>
    T* create(Args&&... args) {
        if (!free_) {
            throw std::bad_alloc();
        }

        Slot* slot = free_;
        free_ = free_->next;
        size_t index = static_cast<size_t>(slot - slots_.data());

        try {
            T* object = ::new (static_cast<void*>(slot->storage))
                T(std::forward<Args>(args)...);
            used_[index] = true;
            return object;
        } catch (...) {
            slot->next = free_;
            free_ = slot;
            throw;
        }
    }

    void destroy(T* object) noexcept {
        if (!object) return;

        Slot* slot = reinterpret_cast<Slot*>(object);
        size_t index = static_cast<size_t>(slot - slots_.data());
        // 生产代码还应验证 object 确实属于该池且正处于使用状态。
        object->~T();
        used_[index] = false;
        slot->next = free_;
        free_ = slot;
    }

    size_t capacity() const noexcept { return slots_.size(); }

private:
    T* object_at(size_t index) noexcept {
        return std::launder(reinterpret_cast<T*>(slots_[index].storage));
    }

    std::vector<Slot> slots_;
    std::vector<bool> used_; // 便于析构时清理仍存活的对象
    Slot* free_ = nullptr;
};
```

---

## 3. 内存分配和对象构造是两件事

对象池初始化时只取得满足大小与对齐要求的原始存储。`create` 使用 placement new 在槽位上构造 `T`；`destroy` 显式调用 `T` 的析构函数，但不把槽位归还给系统，而是放回空闲链表。

---

## 4. 复杂度和收益

1. 初始化 O(capacity)
2. `create` 和 `destroy` 都是 O(1)
3. 减少分配器调用、内存碎片和锁竞争
4. 地址更集中，通常有更好的缓存局部性

对象池不一定总是更快。对象数量少、生命周期长或容量估计错误时，额外复杂度可能得不偿失。

---

## 5. 生产版本注意点

1. 检测外部指针、重复释放和越界指针
2. 线程安全需要锁、线程本地池或无锁空闲链表
3. 池的生命周期必须长于池中对象
4. 固定容量耗尽时可失败，也可按块扩容
5. 指针算术只对同一数组内元素有效
6. 若返回智能指针，可绑定自定义删除器让对象自动归池

---

## 6. 面试回答

对象池把内存分配和对象生命周期分开：先批量准备对齐的槽位，用空闲链表管理；创建对象时通过 placement new 在槽位中构造，销毁时显式调用析构函数，再把槽位放回空闲链表。这样创建和销毁可以做到 O(1)，并减少通用分配器开销和内存碎片。
