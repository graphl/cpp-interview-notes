## 5. copy-swap 的好处

```cpp
String& operator=(const String& other) {
    if (this != &other) {
        String temp(other);
        swap(temp);
    }
    return *this;
}
```

优点：

1. 先拷贝成功，再交换资源
2. 如果申请内存失败，原对象不受影响
3. 异常安全性更好
4. 代码简洁

---

## 6. 为什么需要移动语义？

拷贝构造会重新申请内存并复制字符，成本较高。

移动构造可以直接“偷走”临时对象的资源：

```cpp
String(String&& other) noexcept
    : data_(other.data_), size_(other.size_) {
    other.data_ = nullptr;
    other.size_ = 0;
}
```

移动后，原对象必须置为空状态，防止析构时重复释放。

---

## 7. `new[]` 为什么对应 `delete[]`？

字符串底层是字符数组：

```cpp
data_ = new char[size_ + 1];
```

所以释放时必须使用：

```cpp
delete[] data_;
```

不能写成：

```cpp
delete data_;
```

否则行为不正确。

## 8. 常见追问

### 追问 1：为什么要多申请 1 个字节？

因为 C 风格字符串需要以 `'\0'` 结尾。

```cpp
data_ = new char[size_ + 1];
```

其中 `size_` 表示有效字符长度，不包含 `'\0'`。

### 追问 2：`strlen` 和 `sizeof` 有什么区别？

| 对比            | `strlen`   | `sizeof`             |
| --------------- | ---------- | -------------------- |
| 含义            | 字符串长度 | 对象或类型占用字节数 |
| 是否包含 `'\0'` | 不包含     | 数组时包含           |
| 运行时/编译期   | 运行时遍历 | 多数情况编译期确定   |

### 追问 3：真实 `std::string` 只有这些吗？

不是。

真实 `std::string` 还可能包含：

1. 容量管理
2. 小字符串优化 SSO
3. allocator
4. 迭代器
5. 查找、插入、删除等接口
6. 异常安全和性能优化

## 9. 面试回答模板

可以这样回答：

> 手写 `string` 类的重点是资源管理。因为类中有 `char*` 指针指向堆内存，所以必须自定义析构函数释放资源，并实现拷贝构造和拷贝赋值来完成深拷贝，避免多个对象共享同一块内存导致 double free。拷贝赋值要处理自赋值，常用 copy-swap 保证异常安全。C++11 之后还应该实现移动构造和移动赋值，直接接管临时对象资源，提高效率。

## 10. 总结

| 函数     | 作用                   |
| -------- | ---------------------- |
| 构造函数 | 申请内存并保存字符串   |
| 析构函数 | 释放堆内存             |
| 拷贝构造 | 深拷贝新对象           |
| 拷贝赋值 | 释放旧资源，拷贝新资源 |
| 移动构造 | 接管临时对象资源       |
| 移动赋值 | 释放旧资源，接管新资源 |

最终记忆：

> 手写 string 类，就是在考你能不能正确管理堆内存：深拷贝、防自赋值、防 double free、移动语义和异常安全。
