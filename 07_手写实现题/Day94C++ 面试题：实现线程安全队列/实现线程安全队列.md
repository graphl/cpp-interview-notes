# C++ 面试题：实现线程安全队列

## 1. 考点

线程安全队列常用于多线程任务分发。

面试主要考：

1. `std::mutex`
2. `std::condition_variable`
3. 互斥访问共享队列
4. 阻塞式 `pop`
5. 停止队列

---

## 2. 实现

```cpp
#include <condition_variable>
#include <mutex>
#include <queue>

template <typename T>
class ThreadSafeQueue {
public:
    void push(T value) {
        {
            std::lock_guard<std::mutex> lock(mtx_);
            q_.push(std::move(value));
        }
        cv_.notify_one();
    }

    bool wait_pop(T& value) {
        std::unique_lock<std::mutex> lock(mtx_);
        cv_.wait(lock, [this] {
            return stopped_ || !q_.empty();
        });

        if (q_.empty()) {
            return false;
        }

        value = std::move(q_.front());
        q_.pop();
        return true;
    }

    void stop() {
        {
            std::lock_guard<std::mutex> lock(mtx_);
            stopped_ = true;
        }
        cv_.notify_all();
    }

private:
    std::queue<T> q_;
    std::mutex mtx_;
    std::condition_variable cv_;
    bool stopped_ = false;
};
```

---

## 3. 为什么 `wait` 要用谓词？

```cpp
cv_.wait(lock, [] { return 条件; });
```

原因：

1. 防止虚假唤醒
2. 避免通知先发生导致线程永久等待
3. 代码更安全

---

## 4. 面试回答

线程安全队列的核心是用互斥锁保护队列，用条件变量实现阻塞等待。`push` 时加锁入队并通知消费者，`pop` 时用 `condition_variable::wait` 等待队列非空。`wait` 必须配合条件判断，防止虚假唤醒。
