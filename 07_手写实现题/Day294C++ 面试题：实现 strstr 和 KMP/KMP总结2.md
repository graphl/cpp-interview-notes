## 5. 为什么失配后使用 `j = lps[j - 1]`？

假设已经成功匹配了 `j` 个字符：

```text
text[i-j .. i-1] == pattern[0 .. j-1]
```

此时 `text[i]` 和 `pattern[j]` 失配。`lps[j - 1]` 表明已匹配部分的某段后缀，同时也是模式串的前缀。

这部分字符已经确定相等，没有必要重新比较。因此可以让模式串回退到：

```cpp
j = lps[j - 1];
```

然后仍然使用同一个 `text[i]` 继续比较。这就是 KMP 中主串下标 `i` 不回退的原因。

---

## 6. 匹配过程示例

```text
text:    ABABABABCA
pattern: ABABABCA
lps:     0 0 1 2 3 4 0 1
```

前面匹配到多个字符后发生失配，KMP 不会把主串退回到下一个起点，而是根据 `lps` 把 `j` 调整到仍可能匹配的位置。最终模式串从主串下标 `2` 开始完整匹配。

关键点不是“跳过字符”，而是前面的比较结果已经证明：失配位置之前的某段后缀等于模式串前缀，可以直接复用。

---

## 7. 复杂度为什么是线性的？

设主串长度为 `n`，模式串长度为 `m`。

构造 `lps` 时，`i` 只向右移动。虽然 `len` 会回退，但其增长和回退的总次数为 `O(m)`，所以预处理复杂度为 `O(m)`。

匹配时，每轮要么主串下标 `i` 增加，要么模式串下标 `j` 沿着 `lps` 变小，因此总匹配复杂度为 `O(n)`。

| 阶段       | 时间复杂度 | 空间复杂度 |
| ---------- | ---------: | ---------: |
| 构造 `lps` |     `O(m)` |     `O(m)` |
| 匹配       |     `O(n)` |     `O(1)` |
| 总体       | `O(n + m)` |     `O(m)` |

---

## 8. 边界条件和常见错误

1. 空模式串应返回位置 `0`。
2. 模式串比主串长时返回未找到。
3. 构造 `lps` 失配且 `len > 0` 时，只回退 `len`，不能移动 `i`。
4. 匹配失配且 `j > 0` 时，只回退 `j`，不能移动 `i`。
5. 完整匹配后的起点是 `i - j`，不是 `i`。
6. 回退公式是 `lps[j - 1]`，注意不能访问 `lps[-1]`。
7. 不要混用 `lps` 和 `next[0] = -1` 两套定义。

建议测试：

```text
text = "hello",       pattern = "ll"       -> 2
text = "aaaaa",       pattern = "bba"      -> 未找到
text = "abc",         pattern = ""         -> 0
text = "ababababca",  pattern = "abababca" -> 2
text = "aaaaab",      pattern = "aaab"     -> 2
```

## 9. 面试口述版

> KMP 用于字符串匹配。它先为模式串构造 `lps` 数组，其中 `lps[i]` 表示 `pattern[0..i]` 的最长相等真前缀和真后缀长度。匹配到模式串第 `j` 个字符失配时，将 `j` 更新为 `lps[j - 1]`，复用已经匹配的后缀信息，主串下标不回退。构造 `lps` 是 `O(m)`，匹配是 `O(n)`，总时间复杂度为 `O(n + m)`，额外空间复杂度为 `O(m)`。

## 10. 记忆口诀

```text
构造 LPS：
相等一起走，失配回前缀；退无可退，i 再走。

执行匹配：
相等 i、j 一起走；
失配 j 回 lps[j - 1]，i 不动；
j 已经为 0，i 向后走；
j 到模式串末尾，答案是 i - j。
```
