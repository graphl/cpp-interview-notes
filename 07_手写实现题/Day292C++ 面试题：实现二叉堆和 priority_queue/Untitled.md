## 3. 数组下标关系

对下标 `i`：

1. 父节点：`(i - 1) / 2`
2. 左孩子：`2 * i + 1`
3. 右孩子：`2 * i + 2`

只有完全二叉树才能这样紧凑存储，不需要保存指针。

---

## 4. 复杂度

| 操作               |     复杂度 |
| ------------------ | ---------: |
| `top`              |       O(1) |
| `push`             |   O(log n) |
| `pop`              |   O(log n) |
| 逐个插入建堆       | O(n log n) |
| 自底向上 `heapify` |       O(n) |

`heapify` 是 O(n)，因为越靠近叶子的节点越多，而这些节点下沉的高度很小。

---

## 5. 常见错误

1. 混淆比较器语义，写反大根堆和小根堆
2. 空堆直接访问 `front()`
3. `size_t` 从 0 递减造成无符号下溢
4. `pop` 后忘记对新堆顶执行下沉
5. 认为堆中所有元素整体有序；堆只保证父子关系

---

## 6. 面试回答

优先队列可以用数组形式的完全二叉堆实现。插入时把元素放在数组末尾并不断上浮；删除堆顶时用末尾元素替换堆顶，再向下选择优先级更高的孩子交换。堆顶访问 O(1)，插入和删除 O(log n)，自底向上建堆 O(n)。
