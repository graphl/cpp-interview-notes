# C++ 面试题：实现二分查找

## 1. 考点

二分查找要求数组有序。

面试主要考：

1. 边界条件
2. `left <= right` 和 `left < right`
3. 防止 `mid` 溢出
4. 查找第一个或最后一个目标值

---

## 2. 普通二分

```cpp
#include <vector>

int binarySearch(const std::vector<int>& nums, int target) {
    int left = 0;
    int right = static_cast<int>(nums.size()) - 1;

    while (left <= right) {
        int mid = left + (right - left) / 2;

        if (nums[mid] == target) {
            return mid;
        } else if (nums[mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }

    return -1;
}
```

---

## 3. 查找第一个大于等于 target 的位置

```cpp
int lowerBound(const std::vector<int>& nums, int target) {
    int left = 0;
    int right = static_cast<int>(nums.size());

    while (left < right) {
        int mid = left + (right - left) / 2;

        if (nums[mid] < target) {
            left = mid + 1;
        } else {
            right = mid;
        }
    }

    return left;
}
```

---

## 4. 注意点

`mid` 推荐这样写：

```cpp
int mid = left + (right - left) / 2;
```

不要写成：

```cpp
int mid = (left + right) / 2;
```

因为 `left + right` 可能整数溢出。

---

## 5. 面试回答

二分查找的前提是数据有序。每次取中间元素和目标比较，如果中间值小于目标，就去右半区间，否则去左半区间。写代码时重点注意循环条件、区间开闭和 `mid` 防溢出。
