### 1.5倍 vs 2倍：一个权衡的天平

- **2倍扩容：用空间换时间，但牺牲了内存复用**。它的优点是扩容次数少，`push_back`的均摊时间复杂度更低（虽然都是O(1)）。但代价是内部碎片可能更多，且无法利用旧内存，对缓存和内存管理器不友好。
- **1.5倍扩容：用更多扩容次数换更好的内存表现**。它扩容稍频繁一些，但内存利用率更高，碎片更少。尤其在大型应用中，内存效率至关重要。

## 最大浪费率怎么算？

>假设扩容倍率为：g
>旧容量 = C
>新容量 = g × C
>实际元素 = C + 1
>利用率最低:利用率 ≈ (C+1)/(g×C)
>当 C 很大时：(C+1)≈C
>所以 : 最大浪费率 (C)/(g×C)≈  1/g

------

##  搬迁次数怎么算？

```
1->g->g²->g³->...
1 + g + g² + ...
等比数列求和：
N = 最终元素个数
总搬迁量 ≈ N/(g-1)
```
