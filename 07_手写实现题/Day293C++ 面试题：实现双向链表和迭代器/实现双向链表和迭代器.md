# C++ 面试题：实现双向链表和迭代器

## 1. 考点

手写双向链表不仅考指针操作，还会考哨兵节点、迭代器、资源释放和异常安全。

面试主要考：

1. 前驱和后继指针维护
2. 哨兵节点
3. 插入和删除
4. 双向迭代器
5. 析构和禁用错误拷贝

---

## 2. 简化实现

```cpp
#include <cstddef>
#include <iterator>
#include <utility>

template <typename T>
class List {
    struct NodeBase {
        NodeBase* prev = this;
        NodeBase* next = this;
    };

    struct Node : NodeBase {
        explicit Node(T value) : value(std::move(value)) {}
        T value;
    };

public:
    class iterator {
    public:
        using iterator_category = std::bidirectional_iterator_tag;
        using value_type = T;
        using difference_type = std::ptrdiff_t;
        using pointer = T*;
        using reference = T&;

        iterator() = default;
        explicit iterator(NodeBase* node) : node_(node) {}

        reference operator*() const {
            return static_cast<Node*>(node_)->value;
        }
        pointer operator->() const { return &(**this); }

        iterator& operator++() {
            node_ = node_->next;
            return *this;
        }
        iterator operator++(int) {
            iterator old = *this;
            ++(*this);
            return old;
        }
        iterator& operator--() {
            node_ = node_->prev;
            return *this;
        }

        friend bool operator==(iterator a, iterator b) {
            return a.node_ == b.node_;
        }
        friend bool operator!=(iterator a, iterator b) {
            return !(a == b);
        }

    private:
        friend class List;
        NodeBase* node_ = nullptr;
    };

    List() = default;
    ~List() { clear(); }

    List(const List&) = delete;
    List& operator=(const List&) = delete;

    iterator begin() noexcept { return iterator(root_.next); }
    iterator end() noexcept { return iterator(&root_); }

    iterator insert(iterator pos, T value) {
        Node* node = new Node(std::move(value));
        NodeBase* current = pos.node_;
        NodeBase* before = current->prev;

        node->prev = before;
        node->next = current;
        before->next = node;
        current->prev = node;
        ++size_;
        return iterator(node);
    }

    iterator erase(iterator pos) {
        NodeBase* current = pos.node_;
        if (current == &root_) return end();

        NodeBase* next = current->next;
        current->prev->next = current->next;
        current->next->prev = current->prev;
        delete static_cast<Node*>(current);
        --size_;
        return iterator(next);
    }

    void push_back(T value) { insert(end(), std::move(value)); }
    void push_front(T value) { insert(begin(), std::move(value)); }

    void clear() noexcept {
        while (root_.next != &root_) {
            erase(iterator(root_.next));
        }
    }

    bool empty() const noexcept { return size_ == 0; }
    size_t size() const noexcept { return size_; }

private:
    NodeBase root_; // 不保存 T 的循环哨兵节点
    size_t size_ = 0;
};
```

---

## 3. 为什么使用哨兵节点？

空链表时 `root_.next == root_.prev == &root_`。首节点、尾节点和中间节点都能使用同一套插入删除逻辑，不再需要大量空指针分支。

哨兵使用 `NodeBase`，不直接保存 `T`，因此不要求 `T` 可默认构造。

---

## 4. 复杂度和迭代器失效

1. 已知位置的插入和删除是 O(1)
2. 查找第 k 个节点是 O(n)
3. `push_front`、`push_back` 是 O(1)
4. 插入不会使已有节点迭代器失效
5. 删除只会使指向被删节点的迭代器失效

---

## 5. 完整版本还要补什么？

1. 拷贝构造和拷贝赋值，通常使用逐元素复制和 copy-swap
2. 移动构造和移动赋值
3. `const_iterator`、反向迭代器
4. `front`、`back`、`splice`
5. 分配器支持
6. 构造节点失败时的强异常安全保证

---

## 6. 面试回答

双向链表的节点保存前驱和后继指针。使用循环哨兵节点后，空链表和首尾插入删除都不需要特殊分支。已知迭代器位置的插入删除是 O(1)，但随机访问是 O(n)。插入不会使其他迭代器失效，删除只使被删节点的迭代器失效。
