# C++ 面试题：实现跳表

## 1. 考点

跳表在有序链表上增加多级索引，通过随机层高获得期望 O(log n) 的查找、插入和删除复杂度。

面试主要考：

1. 多级链表
2. 查找路径复用
3. 随机层高
4. 插入和删除
5. 期望复杂度

---

## 2. 简化实现

```cpp
#include <cstddef>
#include <functional>
#include <random>
#include <stdexcept>
#include <utility>
#include <vector>

template <typename K, typename V, typename Compare = std::less<K>>
class SkipList {
    struct Node {
        Node(K key, V value, int level)
            : key(std::move(key)),
              value(std::move(value)),
              next(static_cast<size_t>(level), nullptr) {}

        K key;
        V value;
        std::vector<Node*> next;
    };

public:
    explicit SkipList(int max_level = 16)
        : max_level_(checked_level(max_level)),
          head_(new Node(K{}, V{}, max_level_)) {}

    ~SkipList() {
        Node* node = head_;
        while (node) {
            Node* next = node->next[0];
            delete node;
            node = next;
        }
    }

    SkipList(const SkipList&) = delete;
    SkipList& operator=(const SkipList&) = delete;

    V* find(const K& key) {
        Node* current = head_;
        for (int level = current_level_ - 1; level >= 0; --level) {
            while (current->next[level] &&
                   comp_(current->next[level]->key, key)) {
                current = current->next[level];
            }
        }

        current = current->next[0];
        return current && equal(current->key, key) ? &current->value : nullptr;
    }

    void insert_or_assign(K key, V value) {
        std::vector<Node*> update(static_cast<size_t>(max_level_), nullptr);
        Node* current = head_;

        for (int level = current_level_ - 1; level >= 0; --level) {
            while (current->next[level] &&
                   comp_(current->next[level]->key, key)) {
                current = current->next[level];
            }
            update[level] = current;
        }

        current = current->next[0];
        if (current && equal(current->key, key)) {
            current->value = std::move(value);
            return;
        }

        int level = random_level();
        if (level > current_level_) {
            for (int i = current_level_; i < level; ++i) {
                update[i] = head_;
            }
            current_level_ = level;
        }

        Node* node = new Node(std::move(key), std::move(value), level);
        for (int i = 0; i < level; ++i) {
            node->next[i] = update[i]->next[i];
            update[i]->next[i] = node;
        }
    }

    bool erase(const K& key) {
        std::vector<Node*> update(static_cast<size_t>(max_level_), nullptr);
        Node* current = head_;

        for (int level = current_level_ - 1; level >= 0; --level) {
            while (current->next[level] &&
                   comp_(current->next[level]->key, key)) {
                current = current->next[level];
            }
            update[level] = current;
        }

        current = current->next[0];
        if (!current || !equal(current->key, key)) return false;

        for (int i = 0; i < current_level_; ++i) {
            if (update[i]->next[i] != current) break;
            update[i]->next[i] = current->next[i];
        }
        delete current;

        while (current_level_ > 1 &&
               head_->next[current_level_ - 1] == nullptr) {
            --current_level_;
        }
        return true;
    }

private:
    static int checked_level(int level) {
        if (level <= 0) {
            throw std::invalid_argument("max_level must be positive");
        }
        return level;
    }

    bool equal(const K& a, const K& b) const {
        return !comp_(a, b) && !comp_(b, a);
    }

    int random_level() {
        int level = 1;
        while (level < max_level_ && coin_(rng_)) ++level;
        return level;
    }

    int max_level_;
    int current_level_ = 1;
    Node* head_;
    Compare comp_{};
    std::mt19937 rng_{std::random_device{}()};
    std::bernoulli_distribution coin_{0.5};
};
```

教学实现的头节点使用 `K{}`、`V{}`，因此要求它们可默认构造。完整实现可以把哨兵节点拆成不含键值的基类来消除限制。

---

## 3. 查找过程

从最高层开始向右移动，遇到大于等于目标的节点就下降一层。最终在第 0 层确认键是否相等。插入和删除会保存每一层最后一个小于目标的节点到 `update`，避免重复查找前驱。

---

## 4. 为什么随机层高？

每升高一层的概率通常为 1/2 或 1/4。层数越高，节点数量指数减少，从而形成稀疏索引。跳表不保证单次最坏 O(log n)，但随机分布下查找、插入、删除的期望复杂度都是 O(log n)。

---

## 5. 对比平衡树

1. 跳表实现和调试通常更简单
2. 范围遍历沿第 0 层顺序进行很自然
3. 平衡树提供确定的 O(log n) 上界
4. 并发跳表仍然复杂，需要解决节点删除和内存回收

---

## 6. 面试回答

跳表通过在有序链表上建立多级随机索引加速查找。搜索从最高层向右走，不能继续时下降；插入和删除保存各层前驱，再统一修改指针。随机层高让高层节点指数减少，因此查找、插入和删除的期望复杂度都是 O(log n)，空间复杂度是 O(n)。
