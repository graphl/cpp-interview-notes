## 2. 推荐刷题顺序

第一阶段，练边界和指针：

```text
strlen/strcmp -> strcpy -> memcpy -> memmove -> atoi
-> 反转链表 -> 链表环 -> 合并链表 -> 链表相交
```

第二阶段，练类设计和资源管理：

```text
unique_ptr -> string -> vector -> 双向链表
-> 二叉堆 -> HashMap -> LRU -> shared_ptr/weak_ptr
```

第三阶段，练并发：

```text
生产者消费者 -> 线程安全队列 -> 有界阻塞队列
-> 线程池 -> 读写锁 -> SPSC 无锁队列
```

第四阶段，练后端组件：

```text
环形缓冲区 -> 对象池 -> 最小堆定时器
-> 时间轮 -> 跳表 -> std::function -> Reactor
```

## 3. 每道题的验收标准

写完代码后至少能回答下面问题：

1. 接口的所有权语义是什么？谁创建、谁释放？
2. 空输入、容量为零、溢出、重复释放等边界怎么处理？
3. 时间复杂度和空间复杂度是多少？
4. 构造或分配失败时，是否泄漏资源、破坏原状态？
5. 哪些操作会让指针、引用或迭代器失效？
6. 并发代码由哪把锁或哪个原子变量保护？
7. 停止、取消、异常和线程退出路径是否完整？
8. 这是教学实现还是可用于生产？生产版本还缺什么？

## 4. 专题中的重合关系

1. Day101 与 Day109 都是 `string`，建议保留一篇主实现，另一篇用于比较不同写法。
2. Day92 是智能指针入门，Day290 专讲独占所有权，Day111 专讲共享/弱所有权。
3. Day94 是普通线程安全队列，Day113 增加容量和生产者阻塞，Day297 则限定为无锁 SPSC。
4. Day95 是并发模型，Day107 是它在任务调度中的工程化应用。
5. Day114 使用最小堆，Day299 使用时间轮，应重点比较精度、添加成本和任务规模。
