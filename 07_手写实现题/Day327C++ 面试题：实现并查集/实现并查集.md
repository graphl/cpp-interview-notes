# C++ 面试题：实现并查集

## 1. 并查集解决什么问题

并查集 Disjoint Set Union 维护若干互不相交的集合，核心操作是：

1. `find(x)`：找到元素所在集合的代表元；
2. `unite(a, b)`：合并两个集合；
3. `same(a, b)`：判断两个元素是否连通。

常见场景包括连通分量、最小生成树 Kruskal、冗余边检测和动态合并关系。

## 2. 教学实现

```cpp
#include <cstddef>
#include <numeric>
#include <stdexcept>
#include <utility>
#include <vector>

class DisjointSet {
public:
    explicit DisjointSet(std::size_t count)
        : parent_(count), size_(count, 1), components_(count) {
        std::iota(parent_.begin(), parent_.end(), std::size_t{0});
    }

    std::size_t find(std::size_t x) {
        check(x);
        while (x != parent_[x]) {
            parent_[x] = parent_[parent_[x]];
            x = parent_[x];
        }
        return x;
    }

    bool unite(std::size_t a, std::size_t b) {
        std::size_t root_a = find(a);
        std::size_t root_b = find(b);
        if (root_a == root_b) {
            return false;
        }

        if (size_[root_a] < size_[root_b]) {
            std::swap(root_a, root_b);
        }
        parent_[root_b] = root_a;
        size_[root_a] += size_[root_b];
        --components_;
        return true;
    }

    bool same(std::size_t a, std::size_t b) {
        return find(a) == find(b);
    }

    std::size_t component_size(std::size_t x) {
        return size_[find(x)];
    }

    std::size_t component_count() const noexcept {
        return components_;
    }

private:
    void check(std::size_t x) const {
        if (x >= parent_.size()) {
            throw std::out_of_range("DisjointSet index");
        }
    }

    std::vector<std::size_t> parent_;
    std::vector<std::size_t> size_;
    std::size_t components_;
};
```

这里同时使用两种优化：

- 路径压缩：`find` 时让路径上的节点更接近根；
- 按大小合并：把较小的树挂到较大的树下。

## 3. 为什么不能只写 parent[b] = a

`a` 和 `b` 不一定是根。直接修改 `parent[b]` 可能只移动一个节点，没有合并整个集合。正确做法是：

```text
root_a = find(a)
root_b = find(b)
parent[root_b] = root_a
```

按大小或按秩合并还能避免树快速变高。

## 4. 复杂度和边界

- 同时使用路径压缩和按大小合并后，单次操作的摊还复杂度是 `O(α(n))`；
- `α(n)` 是反阿克曼函数，在实际输入规模下可视为接近常数；
- 空并查集合法，但任何元素访问都越界；
- 本实现适合只合并、不拆分的关系；
- 删除边或拆分集合需要更复杂的数据结构，普通并查集不支持。

## 5. 面试口述版

并查集用一棵父指针树表示每个集合，根节点是代表元。find 负责找根并做路径压缩，unite 先找到两棵树的根，再按大小把小树挂到大树下。两种优化一起使用后，操作的摊还复杂度接近常数，但普通并查集只适合动态合并，不支持集合拆分。
