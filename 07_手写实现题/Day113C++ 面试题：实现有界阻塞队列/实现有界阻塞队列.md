# C++ 面试题：实现有界阻塞队列

## 1. 考点

有界阻塞队列是生产者消费者模型和线程池里很常见的基础组件。
相比普通线程安全队列，它多了容量限制。

面试主要考：

1. `std::mutex`
2. `std::condition_variable`
3. 队列为空时消费者阻塞
4. 队列满时生产者阻塞
5. 停止队列
6. 虚假唤醒

---

## 2. 实现

```cpp
#include <condition_variable>
#include <cstddef>
#include <mutex>
#include <queue>

template <typename T>
class BoundedBlockingQueue {
public:
    explicit BoundedBlockingQueue(size_t capacity)
        : capacity_(capacity) {}

    bool push(T value) {
        std::unique_lock<std::mutex> lock(mtx_);
        not_full_.wait(lock, [this] {
            return stopped_ || q_.size() < capacity_;
        });

        if (stopped_) {
            return false;
        }

        q_.push(std::move(value));
        not_empty_.notify_one();
        return true;
    }

    bool pop(T& value) {
        std::unique_lock<std::mutex> lock(mtx_);
        not_empty_.wait(lock, [this] {
            return stopped_ || !q_.empty();
        });

        if (q_.empty()) {
            return false;
        }

        value = std::move(q_.front());
        q_.pop();
        not_full_.notify_one();
        return true;
    }

    void stop() {
        {
            std::lock_guard<std::mutex> lock(mtx_);
            stopped_ = true;
        }
        not_empty_.notify_all();
        not_full_.notify_all();
    }

private:
    std::queue<T> q_;
    size_t capacity_;
    std::mutex mtx_;
    std::condition_variable not_empty_;
    std::condition_variable not_full_;
    bool stopped_ = false;
};
```

---

## 3. 为什么需要两个条件变量？

队列有两个等待条件：

1. 消费者等待队列非空
2. 生产者等待队列未满

所以可以使用两个条件变量：

1. `not_empty_`：队列非空时唤醒消费者
2. `not_full_`：队列未满时唤醒生产者

这样语义更清楚，也减少无意义唤醒。

---

## 4. 为什么 wait 要用谓词？

```cpp
cv.wait(lock, [] { return 条件成立; });
```

原因：

1. 防止虚假唤醒
2. 避免通知先发生导致永久等待
3. 条件判断和阻塞等待可以在同一把锁下完成

---

## 5. 注意点

1. `push` 时队列满了要阻塞
2. `pop` 时队列空了要阻塞
3. `stop` 时要同时唤醒生产者和消费者
4. 被唤醒后要再次判断条件
5. `notify_one` 通常放在修改队列之后
6. 析构前要保证使用队列的线程已经正确退出

---

## 6. 面试回答

有界阻塞队列的核心是用互斥锁保护共享队列，用条件变量实现阻塞等待。队列为空时消费者等待 `not_empty`，队列满时生产者等待 `not_full`。每次 `push` 成功后通知消费者，每次 `pop` 成功后通知生产者。`wait` 必须配合谓词，防止虚假唤醒。停止队列时要唤醒所有等待线程，让线程可以正常退出。
