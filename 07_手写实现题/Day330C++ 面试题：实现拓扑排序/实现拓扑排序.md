# C++ 面试题：实现拓扑排序

## 1. 它解决什么问题

拓扑排序把有向无环图中的节点排成线性顺序，使每条边 `u -> v` 都满足 `u` 出现在 `v` 前面。典型场景是课程依赖、构建依赖和任务调度。

只有 DAG 才存在拓扑序。面试实现还必须能够检测环，而不能只返回一个不完整序列。

## 2. Kahn 算法

```cpp
#include <cstddef>
#include <queue>
#include <stdexcept>
#include <utility>
#include <vector>

struct TopologicalResult {
    std::vector<int> order;
    bool has_cycle = false;
};

TopologicalResult topological_sort(
    std::size_t vertex_count,
    const std::vector<std::pair<int, int>>& edges) {
    std::vector<std::vector<int>> graph(vertex_count);
    std::vector<std::size_t> indegree(vertex_count, 0);

    for (const auto& edge : edges) {
        int from = edge.first;
        int to = edge.second;

        if (from < 0 || to < 0 ||
            static_cast<std::size_t>(from) >= vertex_count ||
            static_cast<std::size_t>(to) >= vertex_count) {
            throw std::out_of_range("vertex id out of range");
        }

        graph[from].push_back(to);
        ++indegree[to];
    }

    std::queue<int> ready;
    for (std::size_t vertex = 0;
         vertex < vertex_count; ++vertex) {
        if (indegree[vertex] == 0) {
            ready.push(static_cast<int>(vertex));
        }
    }

    TopologicalResult result;
    result.order.reserve(vertex_count);

    while (!ready.empty()) {
        int current = ready.front();
        ready.pop();
        result.order.push_back(current);

        for (int next : graph[current]) {
            if (--indegree[next] == 0) {
                ready.push(next);
            }
        }
    }

    result.has_cycle = result.order.size() != vertex_count;
    return result;
}
```

## 3. 为什么能检测环

Kahn 算法反复删除入度为零的节点。如果最后处理的节点数少于总结点数，剩余子图中每个节点都至少有一条入边，因此其中必然存在环。

有多条合法拓扑序时，普通队列只返回其中一条。如果要求字典序最小，可以把队列换成小根堆。

## 4. 复杂度与边界

1. 时间复杂度为 `O(V + E)`。
2. 空间复杂度为 `O(V + E)`。
3. 空图返回空序列且没有环。
4. 重复边会被分别计入入度，不影响正确性，但会增加空间。
5. 自环会被正确识别为环。

## 5. 面试口述版

先统计每个节点的入度，把所有入度为零的节点入队。每弹出一个节点，就把它指向节点的入度减一，新出现的零入度节点继续入队。最终处理数量等于节点总数时得到拓扑序；否则说明图中存在环。
