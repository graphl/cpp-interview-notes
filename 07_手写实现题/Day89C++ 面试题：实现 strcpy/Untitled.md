## 3. 为什么返回 `char*`？

为了支持链式调用。

```cpp
char buf[32];
printf("%s\n", my_strcpy(buf, "hello"));
```

---

## 4. 注意点

| 问题                | 说明                                      |
| ------------------- | ----------------------------------------- |
| 是否拷贝 `'\0'`     | 必须拷贝，否则目标不是合法 C 字符串       |
| `dest` 空间是否足够 | `strcpy` 不检查空间大小                   |
| `src == nullptr`    | 未定义行为，手写时可 `assert`             |
| 内存重叠            | `strcpy` 不保证正确，重叠应使用 `memmove` |

## 5. 为什么标准 `strcpy` 不处理内存重叠？

C 标准明确规定：**如果源和目的内存重叠，行为是未定义的（undefined behavior）**。

原因很简单：

- 为了**性能**（不做额外检查）
- 调用者有责任保证内存不重叠

## 6. 面试回答

`strcpy` 的核心是逐字符复制，并且一定要把字符串末尾的 `'\0'` 也复制过去。函数返回目标地址，方便链式调用。需要注意目标缓冲区必须足够大，并且源地址和目标地址不能发生重叠，否则结果是未定义行为。
