# C++ 面试题：实现单例模式

## 1. 考点

单例模式要求一个类在程序中只有一个实例，并提供全局访问点。

面试主要考：

1. 构造函数私有化
2. 禁止拷贝和赋值
3. 懒汉式和饿汉式
4. 线程安全
5. C++11 局部静态变量初始化线程安全

---

## 2. 推荐写法：局部静态变量

```cpp
class Singleton {
public:
    static Singleton& instance() {
        static Singleton obj;
        return obj;
    }

    Singleton(const Singleton&) = delete;
    Singleton& operator=(const Singleton&) = delete;

private:
    Singleton() = default;
    ~Singleton() = default;
};
```

---

## 3. 为什么推荐这种？

C++11 之后，函数内局部静态变量的初始化是线程安全的。

优点：

1. 懒加载
2. 自动析构
3. 不需要手动加锁
4. 代码简洁

---

## 4. 指针版本

```cpp
#include <mutex>

class Singleton {
public:
    static Singleton* instance() {
        static Singleton obj;
        return &obj;
    }

private:
    Singleton() = default;
};
```

一般更推荐返回引用，表示实例一定存在，不需要判空。

---

## 5. 面试回答

单例模式的核心是构造函数私有化，并删除拷贝构造和赋值运算符，防止创建多个对象。现代 C++ 推荐使用函数内局部静态变量实现，因为 C++11 保证其初始化过程线程安全，同时还能做到懒加载和自动析构。
