# C++ 面试题：手写内存池

## 1. 考点

内存池用于减少频繁 `new/delete` 带来的系统调用和碎片问题。

面试主要考：

1. 大块内存一次申请
2. 固定大小对象分配
3. 空闲链表
4. 分配和释放 O(1)
5. 对齐问题

---

## 2. 简化固定块内存池

```cpp
#include <cstddef>
#include <cstdlib>

class MemoryPool {
public:
    MemoryPool(size_t block_size, size_t block_count)
        : block_size_(block_size), block_count_(block_count) {
        if (block_size_ < sizeof(Node)) {
            block_size_ = sizeof(Node);
        }

        memory_ = static_cast<char*>(std::malloc(block_size_ * block_count_));
        free_list_ = nullptr;

        for (size_t i = 0; i < block_count_; ++i) {
            Node* node = reinterpret_cast<Node*>(memory_ + i * block_size_);
            node->next = free_list_;
            free_list_ = node;
        }
    }

    ~MemoryPool() {
        std::free(memory_);
    }

    void* allocate() {
        if (!free_list_) {
            return nullptr;
        }

        Node* node = free_list_;
        free_list_ = free_list_->next;
        return node;
    }

    void deallocate(void* p) {
        if (!p) {
            return;
        }

        Node* node = static_cast<Node*>(p);
        node->next = free_list_;
        free_list_ = node;
    }

private:
    struct Node {
        Node* next;
    };

    size_t block_size_;
    size_t block_count_;
    char* memory_;
    Node* free_list_;
};
```

---

## 3. 原理

初始化时一次申请大块内存，然后切成多个固定大小的块。

释放的内存块不会还给系统，而是挂回空闲链表。

下次分配时直接从空闲链表取一个块，时间复杂度 O(1)。

---

## 4. 注意点

真实内存池还需要考虑：

1. 内存对齐
2. 多线程安全
3. 不同大小块管理
4. 扩容策略
5. 析构对象和释放原始内存的区别

---

## 5. 面试回答

内存池的核心是一次申请一大块内存，切分成固定大小的小块，并用空闲链表管理。分配时从空闲链表取一个块，释放时把块挂回链表。这样可以减少频繁申请释放内存的开销，并降低内存碎片。
