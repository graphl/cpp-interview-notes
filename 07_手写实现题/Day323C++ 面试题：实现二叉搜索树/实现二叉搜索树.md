# C++ 面试题：实现二叉搜索树

## 1. 二叉搜索树解决什么问题

二叉搜索树 BST 维护如下顺序：

```text
左子树所有 key < 当前 key < 右子树所有 key
```

它可以同时支持查找、插入、删除和有序遍历。难点主要在删除：

1. 叶子节点可以直接删除；
2. 只有一个孩子时，用孩子接替当前位置；
3. 有两个孩子时，用右子树最小节点或左子树最大节点替换。

下面使用 `unique_ptr` 表达节点所有权，避免手动释放整棵树。

## 2. 教学实现

```cpp
#include <memory>
#include <utility>
#include <vector>

class BinarySearchTree {
    struct Node {
        explicit Node(int input) : value(input) {}

        int value;
        std::unique_ptr<Node> left;
        std::unique_ptr<Node> right;
    };

public:
    bool contains(int value) const {
        const Node* current = root_.get();
        while (current) {
            if (value < current->value) {
                current = current->left.get();
            } else if (value > current->value) {
                current = current->right.get();
            } else {
                return true;
            }
        }
        return false;
    }

    bool insert(int value) {
        std::unique_ptr<Node>* link = &root_;
        while (*link) {
            if (value < (*link)->value) {
                link = &(*link)->left;
            } else if (value > (*link)->value) {
                link = &(*link)->right;
            } else {
                return false;
            }
        }
        *link = std::make_unique<Node>(value);
        return true;
    }

    bool erase(int value) {
        return erase(root_, value);
    }

    std::vector<int> inorder() const {
        std::vector<int> result;
        inorder(root_.get(), result);
        return result;
    }

private:
    static bool erase(std::unique_ptr<Node>& node, int value) {
        if (!node) {
            return false;
        }
        if (value < node->value) {
            return erase(node->left, value);
        }
        if (value > node->value) {
            return erase(node->right, value);
        }

        if (!node->left) {
            node = std::move(node->right);
        } else if (!node->right) {
            node = std::move(node->left);
        } else {
            Node* successor = node->right.get();
            while (successor->left) {
                successor = successor->left.get();
            }
            node->value = successor->value;
            erase(node->right, successor->value);
        }
        return true;
    }

    static void inorder(const Node* node, std::vector<int>& out) {
        if (!node) {
            return;
        }
        inorder(node->left.get(), out);
        out.push_back(node->value);
        inorder(node->right.get(), out);
    }

    std::unique_ptr<Node> root_;
};
```

这个版本不保存重复 key。若需要支持重复元素，可以在节点中增加计数，或规定相等元素统一进入某一侧。

## 3. 删除的数据流

删除含两个孩子的节点时：

```text
找到右子树最小节点 successor
-> 用 successor 的值覆盖当前节点
-> 在右子树中删除 successor
```

后继节点不可能有左孩子，因此第二次删除会退化为叶子或单孩子情况。

## 4. 复杂度和局限

- 查找、插入、删除复杂度都是 `O(h)`。
- 随机情况下树高通常接近 `O(log n)`。
- 有序输入会让普通 BST 退化成链表，最坏复杂度为 `O(n)`。
- 红黑树、AVL 树通过维护平衡，把树高限制在 `O(log n)`。
- 泛型版本还要处理比较器、异常安全、迭代器和 key 不可赋值等问题。

## 5. 面试口述版

BST 根据 key 大小决定向左还是向右查找。删除分三种情况：无孩子直接删除，一个孩子让孩子接替，两个孩子则用中序后继替换当前值，再删除后继。所有操作复杂度是 `O(h)`，但普通 BST 可能退化，因此标准有序容器通常使用平衡树。
