# C++ 面试题：判断链表相交

## 1. 考点

两个链表相交，指的是节点地址相同，不是节点值相同。

面试主要考：

1. 指针地址比较
2. 双指针切换链表
3. 长度差法
4. 边界条件

---

## 2. 双指针实现

```cpp
struct ListNode {
    int val;
    ListNode* next;
};

ListNode* getIntersectionNode(ListNode* headA, ListNode* headB) {
    ListNode* pA = headA;
    ListNode* pB = headB;

    while (pA != pB) {
        pA = pA ? pA->next : headB;
        pB = pB ? pB->next : headA;
    }

    return pA;
}
```

---

## 3. 原理

如果两个链表相交：

```text
A 路径：A 独有部分 + 公共部分 + B 独有部分
B 路径：B 独有部分 + 公共部分 + A 独有部分
```

两个指针走过的总长度相同，所以会在交点相遇。

如果不相交，最后都会变成 `nullptr`。

---

## 4. 注意点

| 问题 | 说明 |
|---|---|
| 比较什么 | 比较节点地址，不是节点值 |
| 是否修改链表 | 不修改 |
| 时间复杂度 | O(m + n) |
| 空间复杂度 | O(1) |

---

## 5. 面试回答

判断链表相交可以用双指针。两个指针分别从两个链表头出发，走到尾部后切换到另一个链表头。这样两个指针走过的总路径长度相同，如果有交点会在交点相遇，没有交点会同时到达空指针。
