# C++ 面试题：实现时间轮定时器

## 1. 考点

时间轮把时间划分为固定刻度，每个槽位保存一批任务。它适合大量定时任务、精度要求固定的后台服务。

面试主要考：

1. 时间刻度与槽位映射
2. 轮数 `rounds`
3. 周期推进
4. 取消任务
5. 时间精度与复杂度权衡

---

## 2. 单层时间轮实现

```cpp
#include <algorithm>
#include <cstddef>
#include <cstdint>
#include <functional>
#include <list>
#include <stdexcept>
#include <unordered_set>
#include <utility>
#include <vector>

class TimingWheel {
public:
    using Callback = std::function<void()>;

    TimingWheel(size_t slot_count, uint64_t tick_ms)
        : slots_(slot_count), tick_ms_(tick_ms) {
        if (slot_count == 0 || tick_ms == 0) {
            throw std::invalid_argument("slot_count and tick_ms must be positive");
        }
    }

    size_t add(uint64_t timeout_ms, Callback callback) {
        uint64_t ticks = std::max<uint64_t>(
            1, (timeout_ms + tick_ms_ - 1) / tick_ms_);

        size_t slot = static_cast<size_t>(
            (current_slot_ + ticks) % slots_.size());
        uint64_t rounds = (ticks - 1) / slots_.size();
        size_t id = ++next_id_;

        slots_[slot].push_back(
            Task{id, rounds, std::move(callback)});
        return id;
    }

    void cancel(size_t id) {
        canceled_.insert(id); // 惰性删除
    }

    // 每经过 tick_ms 调用一次。
    void tick() {
        current_slot_ = (current_slot_ + 1) % slots_.size();
        auto& tasks = slots_[current_slot_];

        for (auto it = tasks.begin(); it != tasks.end();) {
            if (canceled_.erase(it->id) > 0) {
                it = tasks.erase(it);
            } else if (it->rounds > 0) {
                --it->rounds;
                ++it;
            } else {
                Callback callback = std::move(it->callback);
                it = tasks.erase(it);
                callback();
            }
        }
    }

private:
    struct Task {
        size_t id;
        uint64_t rounds;
        Callback callback;
    };

    std::vector<std::list<Task>> slots_;
    uint64_t tick_ms_;
    size_t current_slot_ = 0;
    size_t next_id_ = 0;
    std::unordered_set<size_t> canceled_;
};
```

## 3. 槽位和轮数怎么算？

假设有 N 个槽，任务距离当前还有 `ticks` 个刻度：

```text
slot   = (current_slot + ticks) % N
rounds = (ticks - 1) / N
```

`rounds` 表示到达目标槽位后还要跳过多少次。减一是为了让刚好 N 个 tick 后执行的任务在下一次到达该槽时执行。

---

## 4. 复杂度

1. 添加任务平均 O(1)
2. 取消任务使用惰性标记，平均 O(1)
3. 每次 tick 的成本与当前槽中的任务数量有关
4. 空间复杂度 O(槽位数 + 任务数)

最小堆添加和删除是 O(log n)，但能精确找到最近过期任务；时间轮添加快，但精度受 tick 限制，任务分布不均时某个槽可能很重。

---

## 5. 生产版本注意点

1. 用 `steady_clock` 驱动，不依赖可跳变的系统墙上时间
2. 回调不要在内部锁下执行
3. 回调执行太久会拖慢后续 tick，可投递到线程池
4. 线程暂停后恢复时，需要根据真实经过时间补跑多个 tick
5. 大范围超时可使用分层时间轮，避免很大的 `rounds`
6. 单线程事件循环可避免加锁；跨线程添加任务需要同步和唤醒机制
7. 取消不存在的 id 会让惰性删除集合残留，生产版本应验证 id 或定期清理

---

## 6. 面试回答

时间轮把时间切成固定 tick，并把任务映射到循环槽位。短期任务由目标槽决定，超过一圈的任务再记录剩余轮数。每次 tick 只处理当前槽，因此添加任务通常是 O(1)。它适合大量定时任务，但精度受 tick 限制；需要更大时间范围时可以使用分层时间轮。
