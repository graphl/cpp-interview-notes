## 3. 为什么要分方向拷贝？

如果目标地址在源地址前面，可以从前往后拷贝：

```cpp
char s[] = "abcdef";
my_memmove(s, s + 2, 4);  // cdefef
```

如果目标地址落在源区间内部，从前往后拷贝会覆盖还没有读取的数据，所以要从后往前拷贝：

```cpp
char s[] = "abcdef";
my_memmove(s + 2, s, 4);  // ababcd
```

---

## 4. 和 memcpy 的区别

`memcpy` 假设源区间和目标区间不重叠。
如果重叠，结果未定义。

`memmove` 会判断重叠关系，并选择合适的拷贝方向，因此可以处理重叠内存。

---

## 5. 注意点

1. 返回值是原始目标地址 `dest`
2. `void*` 不能直接解引用，也不能直接做指针运算
3. 使用 `unsigned char*` 是为了按字节操作原始内存
4. 反向拷贝时要先移动到末尾，再使用 `*--d = *--s`
5. `assert` 只是调试期检查，真实库函数对非法指针通常不保证行为

---

## 6. 面试回答

`memmove` 的核心是按字节拷贝，并且要处理内存重叠。实现时先把 `void*` 转成 `unsigned char*`。如果目标区间不在源区间内部，就从前往后拷贝；如果目标地址落在源区间内部，为了避免覆盖还没拷贝的数据，就从后往前拷贝。它和 `memcpy` 最大的区别是：`memmove` 可以处理重叠内存，而 `memcpy` 不保证。
