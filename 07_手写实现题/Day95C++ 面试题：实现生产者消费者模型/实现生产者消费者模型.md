# C++ 面试题：实现生产者消费者模型

## 1. 考点

生产者消费者模型用于解耦生产任务和处理任务。

核心组件：

1. 共享队列
2. 互斥锁
3. 条件变量
4. 生产者通知消费者
5. 消费者阻塞等待

---

## 2. 无界队列版本

```cpp
#include <condition_variable>
#include <iostream>
#include <mutex>
#include <queue>
#include <thread>

std::queue<int> q;
std::mutex mtx;
std::condition_variable cv;
bool done = false;

void producer() {
    for (int i = 0; i < 10; ++i) {
        {
            std::lock_guard<std::mutex> lock(mtx);
            q.push(i);
        }
        cv.notify_one();
    }

    {
        std::lock_guard<std::mutex> lock(mtx);
        done = true;
    }
    cv.notify_all();
}

void consumer() {
    while (true) {
        std::unique_lock<std::mutex> lock(mtx);
        cv.wait(lock, [] {
            return done || !q.empty();
        });

        if (q.empty() && done) {
            break;
        }

        int value = q.front();
        q.pop();
        lock.unlock();

        std::cout << value << std::endl;
    }
}
```

---

## 3. 有界队列版本考点

如果队列有容量限制，需要两个条件变量：

1. `not_empty`：队列非空，通知消费者
2. `not_full`：队列未满，通知生产者

---

## 4. 注意点

| 问题 | 说明 |
|---|---|
| 虚假唤醒 | `wait` 必须带条件 |
| 退出条件 | 要有 `done` 或停止标记 |
| 锁粒度 | 取出任务后可先解锁再处理 |
| 通知位置 | 入队后通知消费者 |

---

## 5. 面试回答

生产者消费者模型通常用队列、互斥锁和条件变量实现。生产者向队列放任务，消费者从队列取任务；队列为空时消费者阻塞等待，生产者放入数据后通知消费者。如果是有界队列，还要在队列满时阻塞生产者。
