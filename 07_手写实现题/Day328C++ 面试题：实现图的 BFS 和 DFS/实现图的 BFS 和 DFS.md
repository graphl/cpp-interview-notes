# C++ 面试题：实现图的 BFS 和 DFS

原来的 BFS、DFS 合并笔记已经拆成两个可以独立复习的实现题：

1. [实现图的 BFS](实现图的%20BFS.md)
   - 队列与逐层扩展；
   - 入队时标记 `visited`；
   - 无权图最短边数；
   - 非连通图的 BFS 森林。

2. [实现图的 DFS](实现图的%20DFS.md)
   - 递归与显式栈；
   - 入栈时标记 `visited`；
   - 连通性、路径探索和回溯；
   - 递归深度与栈溢出风险。

## 共同基础

图可能存在环、一个节点被多条边指向，以及多个互不连通的分量。因此 BFS 和 DFS 都必须维护访问状态。

使用邻接表时，两种遍历的复杂度相同：

```text
时间复杂度：O(V + E)
额外空间：  O(V)
```

## 如何选择

| 需求 | 更常用的遍历 |
|---|---|
| 无权图最短边数 | BFS |
| 按距离分层处理 | BFS |
| 连通性和可达性 | BFS 或 DFS |
| 路径探索与回溯 | DFS |
| 拓扑排序 | DFS 或基于入度的 BFS |
| 避免深递归栈 | BFS 或迭代 DFS |

## 非连通图

从一个起点只能访问它所在的连通分量。要覆盖整个图，需要在外层扫描顶点，并让多次搜索共享同一份 `visited`：

```text
for each vertex:
    if not visited:
        从该顶点启动一次 BFS 或 DFS
```

具体实现和常见错误分别放在两篇独立笔记中。
