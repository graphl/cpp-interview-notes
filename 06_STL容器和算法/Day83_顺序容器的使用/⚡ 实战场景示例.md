# 🔥 一、vector – 迭代器失效规则（最爱考）

| 操作                 | 迭代器是否失效     |
| -------------------- | ------------------ |
| `push_back` 扩容发生 | 全部失效           |
| `push_back` 未扩容   | 只有 end 失效      |
| 中间插入 `insert`    | 插入点后的全部失效 |
| 删除 `erase`         | 删除点后的全部失效 |
| `clear`              | 全部失效           |
| `reserve(n)`         | 若扩容 → 全部失效  |

📌 口诀：

> vector 一扩容，全失效；中间动，后失效。
