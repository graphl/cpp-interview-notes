# 🚀 二、deque – 迭代器失效规则（容易混）

| 操作                     | 迭代器是否失效           |
| ------------------------ | ------------------------ |
| `push_front / push_back` | 可能失效，但通常相对稳定 |
| 中间插入 `insert`        | 全部失效                 |
| 删除 `erase`（中间）     | 全部失效                 |
| 删除头尾                 | 大概率稳定               |
| `clear`                  | 全部失效                 |

📌 要点：

> 头尾增删比较稳，中间操作全部崩。
