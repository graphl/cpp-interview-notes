# C++ 面试题：deque 的底层实现

## 1. 核心结论

`deque` 是双端队列，支持头尾高效插入删除。

它不是一整块连续内存，而是分段连续内存。

---

## 2. 底层结构

可以理解为：

```text
map 指针数组
  |
  +--> buffer 1
  +--> buffer 2
  +--> buffer 3
```

`deque` 使用一个中控数组保存多个缓冲区指针，每个缓冲区内部是连续内存。

---

## 3. 特点

| 操作 | 复杂度 |
|---|---|
| 头部插入删除 | O(1) |
| 尾部插入删除 | O(1) |
| 随机访问 | O(1) |
| 中间插入删除 | O(n) |

---

## 4. 和 vector 的区别

| 对比点 | `vector` | `deque` |
|---|---|---|
| 内存 | 完全连续 | 分段连续 |
| 头插 | O(n) | O(1) |
| 尾插 | 均摊 O(1) | O(1) |
| 随机访问 | O(1)，更快 | O(1)，但多一层寻址 |
| 扩容搬移 | 可能整体搬移 | 通常新增缓冲区 |

---

## 5. 面试回答

`deque` 底层通常是分段连续空间，由一个中控数组管理多个缓冲区。它支持 O(1) 的头尾插入删除，也支持 O(1) 随机访问，但随机访问比 `vector` 多一次间接寻址。它适合两端频繁操作的场景。
