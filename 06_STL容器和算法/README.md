# C++ STL 容器与算法

学习 STL 不应从背 API 开始，而应从数据布局、复杂度、迭代器稳定性和所有权成本选择容器。算法部分重点理解区间语义、比较器要求和复杂度保证。

## 推荐学习顺序

```text
连续容器 vector/array/string
  -> 分段与节点容器 deque/list
  -> 容器适配器 stack/queue/priority_queue
  -> 有序关联容器 map/set
  -> 无序关联容器 unordered_map/set
  -> 迭代器、算法、allocator
```

## 容器选择四问

1. 是否要求连续内存、随机访问或与 C API 交互？
2. 插入删除发生在哪里，是否比遍历更频繁？
3. 是否需要稳定的指针、引用和迭代器？
4. 需要排序、范围查询，还是平均常数时间查找？

## 必会边界

- `reserve` 改容量不改元素个数；`resize` 改元素个数并涉及构造/析构。
- `emplace_back` 避免的是某些临时对象，不保证永远比 `push_back` 快。
- `unordered_map` 的平均复杂度依赖哈希质量和负载因子。
- 比较器必须满足严格弱序，否则有序算法和容器行为不可靠。

## 待补重点

红黑树插入修复、哈希表 rehash、透明比较、算法选择表，以及 allocator 如何分离原始存储与对象生命周期。
