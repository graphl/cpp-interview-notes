# C++ 面试题：set 和 unordered_set 的区别

## 1. 核心结论

`set` 是有序集合，底层通常是红黑树。

`unordered_set` 是无序集合，底层是哈希表。

---

## 2. 对比表

| 对比点 | `set` | `unordered_set` |
|---|---|---|
| 底层结构 | 红黑树 | 哈希表 |
| 是否有序 | 有序 | 无序 |
| 元素是否唯一 | 唯一 | 唯一 |
| 查找 | O(log n) | 平均 O(1) |
| 插入删除 | O(log n) | 平均 O(1) |
| 元素要求 | 可比较大小 | 可 hash，支持相等比较 |
| 范围查询 | 支持 | 不支持 |

---

## 3. 使用场景

用 `set`：

1. 需要自动排序
2. 需要找大于等于某值的元素
3. 需要范围遍历

用 `unordered_set`：

1. 只判断元素是否存在
2. 去重
3. 不关心顺序

---

## 4. 示例

```cpp
std::set<int> s = {3, 1, 2};
// 遍历结果：1 2 3
```

```cpp
std::unordered_set<int> us = {3, 1, 2};
// 遍历顺序不确定
```

---

## 5. 面试回答

`set` 底层是平衡搜索树，元素有序，查找插入删除是 O(log n)，适合排序和范围查询。`unordered_set` 底层是哈希表，元素无序，平均查找插入删除是 O(1)，适合快速判重和存在性判断。
