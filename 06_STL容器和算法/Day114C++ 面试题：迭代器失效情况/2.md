## 5. unordered_map / unordered_set

| 操作                 | 失效情况             |
| -------------------- | -------------------- |
| `insert` 未 rehash   | 通常已有迭代器不失效 |
| `insert` 触发 rehash | 所有迭代器失效       |
| `erase`1             | 被删除元素迭代器失效 |

---

## 6. 正确 erase 写法

```cpp
for (auto it = v.begin(); it != v.end(); ) {
    if (*it % 2 == 0) {
        it = v.erase(it);
    } else {
        ++it;
    }
}
```

---

## 7. 面试回答

迭代器失效和容器底层结构有关。`vector` 因为连续内存，扩容会导致所有迭代器失效，删除会导致删除点之后失效。`list`、`map`、`set` 节点相对稳定，通常只会让被删除元素的迭代器失效。哈希容器如果发生 rehash，会导致所有迭代器失效。
