## 2. vector

| 操作               | 失效情况                                 |
| ------------------ | ---------------------------------------- |
| `push_back` 不扩容 | `end()` 失效                             |
| `push_back` 扩容   | 所有迭代器、指针、引用失效               |
| `insert`           | 插入点及其后的迭代器失效；扩容则全部失效 |
| `erase`            | 删除点及其后的迭代器失效                 |

---

## 3. list

`list` 节点独立分配。

| 操作     | 失效情况                   |
| -------- | -------------------------- |
| `insert` | 不影响已有迭代器           |
| `erase`  | 只有被删除元素的迭代器失效 |

---

## 4. map / set

树形容器节点稳定。

| 操作     | 失效情况                   |
| -------- | -------------------------- |
| `insert` | 不影响已有迭代器           |
| `erase`  | 只有被删除元素的迭代器失效 |
