# C++ 面试题：vector 和 list 的区别

## 1. 核心结论

`vector` 是连续内存动态数组，适合随机访问和尾部插入。

`list` 是双向链表，适合频繁在任意位置插入和删除。

---

## 2. 对比表

| 对比点 | `vector` | `list` |
|---|---|---|
| 底层结构 | 连续数组 | 双向链表 |
| 随机访问 | O(1) | O(n) |
| 尾部插入 | 均摊 O(1) | O(1) |
| 中间插入删除 | O(n) | 已有迭代器时 O(1) |
| 内存连续 | 连续 | 不连续 |
| 缓存友好 | 好 | 差 |
| 迭代器类型 | 随机访问迭代器 | 双向迭代器 |
| 排序 | 可用 `std::sort` | 用成员函数 `list::sort` |

---

## 3. 什么时候用 vector？

适合：

1. 需要下标访问
2. 主要在尾部插入
3. 需要高缓存命中率
4. 数据量较大但修改不频繁

```cpp
std::vector<int> v;
v.push_back(1);
v.push_back(2);
std::cout << v[0] << std::endl;
```

---

## 4. 什么时候用 list？

适合：

1. 频繁在中间插入删除
2. 已经持有插入位置的迭代器
3. 不需要随机访问

```cpp
std::list<int> lst = {1, 3};
auto it = lst.begin();
++it;
lst.insert(it, 2);
```

---

## 5. 面试回答

`vector` 底层是连续数组，随机访问 O(1)，缓存友好，尾插均摊 O(1)，但中间插入删除需要移动元素。`list` 底层是双向链表，随机访问 O(n)，但在已知位置插入删除是 O(1)。实际开发中如果没有强烈的中间插删需求，通常优先选择 `vector`。
