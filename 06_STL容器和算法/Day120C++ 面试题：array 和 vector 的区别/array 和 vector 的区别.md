# C++ 面试题：array 和 vector 的区别

## 1. 核心结论

`std::array` 是固定大小数组。

`std::vector` 是动态大小数组。

---

## 2. 对比表

| 对比点 | `array` | `vector` |
|---|---|---|
| 大小 | 编译期固定 | 运行期可变 |
| 内存 | 对象内部连续存储 | 堆上连续存储 |
| 扩容 | 不支持 | 支持 |
| 随机访问 | O(1) | O(1) |
| 是否可作为 STL 容器 | 是 | 是 |

---

## 3. 示例

```cpp
std::array<int, 3> a = {1, 2, 3};
std::vector<int> v = {1, 2, 3};

v.push_back(4);
// a.push_back(4);  // 错误，array 大小固定
```

---

## 4. 和 C 数组相比

`std::array` 比 C 数组更安全、更像普通容器：

1. 有 `size()`
2. 支持迭代器
3. 可以直接赋值
4. 可配合 STL 算法

---

## 5. 面试回答

`array` 是固定大小的 STL 容器，大小在编译期确定，不支持扩容；`vector` 是动态数组，大小可以运行期增长，容量不足时会扩容。两者都支持连续存储和 O(1) 随机访问。
