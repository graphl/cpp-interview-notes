## 均摊为O(1)

##### 计算总操作数

假设我们 push_back n 次。

- 扩容发生在容量达到 1, 2, 4, 8, 16...
- 每次扩容需要拷贝元素数为 1, 2, 4, 8...（即容量值）

所以总拷贝次数：

​		
$$
T(n)=1+2+4+8+…+m≤2n
$$


- 因为 1 + 2 + 4 + … + 2^k = 2^(k+1) - 1 ≤ 2n
- 再加上每次 push_back 本身的操作 n → 总操作 ≤ 3n

##### 均摊复杂度

- 总操作 ≤ 3n

- push_back n 次 → 平均每次操作时间：
  
  $$
  均摊时间 = \frac{T(n)}{n} \le \frac{3n}{n} = O(1)
  $$
  

  

✅ 所以即使有 O(n) 扩容操作，**平均每次 push_back 仍然是 O(1)**。
