### Vector扩容总结

| 特点       | 说明                                          |
| ---------- | --------------------------------------------- |
| 扩容策略   | 通常倍增（2× 或 1.5×）                        |
| 触发条件   | size == capacity                              |
| 均摊复杂度 | push_back 平均 O(1)                           |
| 影响       | 迭代器、引用、指针可能失效；拷贝/移动元素开销 |
| 优化方法   | reserve(), emplace_back(), 避免频繁扩容       |
