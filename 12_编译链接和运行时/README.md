# C++ 编译、链接与运行时

这个专题要建立一条完整链路：源代码如何变成目标文件，符号如何被解析和重定位，程序如何被加载，最终如何进入 `main`。

## 推荐学习顺序

```text
预处理 -> 编译 -> 汇编 -> 目标文件
  -> 符号表、重定位、ODR
  -> 静态链接与动态链接
  -> ELF、PLT/GOT、动态加载器
  -> 进程启动、全局初始化、main
  -> dlopen/dlsym 与卸载
```

## 必会问题

1. 声明、定义和 ODR 分别约束什么？
2. 编译器为什么需要 name mangling，`extern "C"` 改变了什么？
3. 目标文件中的未解析符号如何在链接时找到定义？
4. 静态库为什么与链接顺序有关？
5. 动态库的地址在装载时如何通过重定位修正？
6. `main` 之前由谁建立进程环境并执行全局初始化？

## 待补重点

ELF 节与段、重定位表、PLT/GOT、lazy binding、`ld.so`、符号可见性、弱符号、PIC 和 ABI 兼容。
