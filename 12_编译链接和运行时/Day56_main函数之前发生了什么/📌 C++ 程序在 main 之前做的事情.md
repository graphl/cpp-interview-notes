## 📌 C++ 程序在 `main` 之前做的事情

### 1. **加载器（Loader）工作**

操作系统先把可执行文件加载进内存：

- 把代码段、数据段、堆、栈映射到进程地址空间；
- 设置 CPU 寄存器、栈指针；
- 把程序入口（不是 `main`，而是运行时入口 `_start`）设置好。

### 2. **进入运行时入口 `_start`**

- 在 Linux 下通常是 **glibc 提供的 `_start`**，Windows 下是 **CRT (C Runtime)** 的启动代码。
- `_start` 会做一些底层准备，比如获取命令行参数 `argc`/`argv`，环境变量 `envp` 等。

### 3. **初始化运行时环境**

在 C++ 里，这一步非常关键：

- **堆的初始化**（malloc/new 能正常工作）。
- **I/O 库初始化**（`std::cout`, `std::cin` 可用）。
- **全局/静态对象初始化**：
  1. **零初始化**：所有静态/全局变量先清零。
  2. **动态初始化**：调用全局/静态对象的构造函数。
- **线程局部存储（TLS）** 初始化。

👉 这就是为什么你能在 `main` 里直接用 `std::string` 或 `std::cout`。

### 4. **调用 `main` 函数**

当环境准备好后，运行时才会调用你写的：

```
int main(int argc, char* argv[], char* envp[]);
```



### 5. **main 之后的收尾工作**

当 `main` 返回后：

- 调用 `exit()`，进入运行时清理阶段。
- **调用所有全局/静态对象的析构函数**。
- 清理 I/O 缓冲区，关闭文件句柄。
- 归还堆内存。
- 通知操作系统进程退出，并返回 `main` 的返回值作为进程退出码。
