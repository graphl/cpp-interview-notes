# 🧬 为什么要出现这些特性？

| 特性     | 目的                           | 解决的问题                               |
| -------- | ------------------------------ | ---------------------------------------- |
| **封装** | 隐藏实现细节，仅暴露接口       | 提高模块的安全性、降低耦合               |
| **继承** | 子类复用父类功能，扩展已有逻辑 | 避免重复代码，提高复用性                 |
| **多态** | 同一接口多种实现（灵活扩展）   | 解耦调用者与被调用者，增加灵活性和扩展性 |
