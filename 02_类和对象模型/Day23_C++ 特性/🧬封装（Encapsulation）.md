# 🧬封装（Encapsulation）

### ✅ 定义：

封装是指将【数据】和【操作这些数据的函数】**绑定在一起**，并**隐藏实现细节**，只对外暴露必要的接口。

### ✅ 关键点：

| 项目       | 说明                             |
| ---------- | -------------------------------- |
| 访问控制符 | `private`, `protected`, `public` |
| 数据隐藏   | 外部不能直接访问 `private` 成员  |
| 接口暴露   | 通过 `public` 方法访问内部数据   |
