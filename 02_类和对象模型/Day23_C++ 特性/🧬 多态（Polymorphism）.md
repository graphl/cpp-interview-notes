## 🧬 多态（Polymorphism）

### ✅ 定义：

多态允许使用**同一接口调用不同子类的实现**。可分为：

| 类型       | 说明           | 举例                                 |
| ---------- | -------------- | ------------------------------------ |
| 编译时多态 | 函数重载、模板 | `void print(int)` vs `print(double)` |
| 运行时多态 | 虚函数+继承    | `virtual void speak()`               |
