## 🧬 继承（Inheritance）

### ✅ 定义：

继承允许一个类**基于已有类**创建新类，新类自动获得原类的成员变量和函数。

### ✅ 分类：

| 继承方式        | 基类成员访问限制                         |
| --------------- | ---------------------------------------- |
| `public`继承    | public -> public，protected -> protected |
| `protected`继承 | public/protected -> protected            |
| `private`继承   | public/protected -> private              |
