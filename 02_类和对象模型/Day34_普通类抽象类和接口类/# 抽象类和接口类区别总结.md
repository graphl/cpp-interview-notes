# 抽象类和接口类区别总结

| 对比点           | 抽象类 (Abstract Class)         | 接口类 (Interface Class) |
| ---------------- | ------------------------------- | ------------------------ |
| **纯虚函数数量** | 至少一个                        | 一般全部是纯虚函数       |
| **普通成员函数** | 可以有（带实现）                | 通常没有                 |
| **成员变量**     | 可以有                          | 通常没有                 |
| **主要作用**     | 部分抽象 + 部分实现，给子类复用 | 完全定义规范，不提供实现 |
| **继承意义**     | 继承的是“部分接口 + 部分实现”   | 继承的是“纯接口”         |
