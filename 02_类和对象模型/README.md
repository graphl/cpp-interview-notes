# C++ 类和对象模型

本专题关注“一个对象从哪里开始存在、内部有什么、复制或移动时资源如何变化、何时结束生命周期”。不要只背构造函数调用顺序，要把对象的内存、所有权和动态类型连起来。

## 推荐学习顺序

```text
封装与类的基本语义
  -> 构造、初始化列表、析构顺序
  -> 拷贝构造、赋值、移动语义
  -> Rule of Three/Five/Zero
  -> 对象内存布局、对象切片
  -> 继承关系中的构造与析构
```

## 必会问题

1. 初始化列表和构造函数体赋值为什么不是一回事？
2. 成员初始化顺序由声明顺序还是列表顺序决定？
3. 拷贝构造与拷贝赋值分别发生在什么对象状态上？
4. 类管理裸资源时为什么需要遵守三/五法则？
5. 对象切片丢失了什么？如何用引用或指针保留动态类型？
6. `delete this` 只有在什么严格条件下才可能成立？

## 建议画出的模型

```text
原始存储取得 -> 对象生命周期开始 -> 成员按声明顺序构造
-> 对象可用 -> 析构函数体执行 -> 成员逆序析构 -> 存储释放
```

## 待补重点

空基类优化（EBO）、`standard-layout`、`trivial`、POD 的历史关系，以及运算符重载的语义边界。
