## **2. 基类 → 成员变量 → 构造函数体**

初始化总顺序：

1. **先调用基类构造函数**（如果有多基类，按声明顺序）
2. **再初始化派生类成员变量**（按声明顺序）
3. **最后执行构造函数体**

```
#include <iostream>
using namespace std;

struct Base {
    Base() { cout << "Base\n"; }
};

struct Foo {
    Foo() { cout << "Foo\n"; }
};

struct Derived : Base {
    Foo f;
    Derived() { cout << "Derived\n"; }
};

int main() {
    Derived d;
}
```


输出:
Base
Foo
Derived
