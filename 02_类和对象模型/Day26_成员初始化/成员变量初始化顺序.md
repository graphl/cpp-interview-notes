# 成员变量初始化顺序

## **1. 初始化顺序和你写的顺序无关**

- **实际顺序**：由**成员在类中声明的顺序**决定
- **不是**由构造函数初始化列表中的顺序决定

```
#include <iostream>
using namespace std;

struct Foo {
    int a;
    int b;
    Foo(int val) : b(val), a(b) { } // 初始化列表写的顺序是 b -> a
};

int main() {
    Foo obj(42);
    cout << obj.a << " " << obj.b << endl;
}
```

**输出（未定义行为，通常是垃圾值）**：
因为：

1. `a` 在类里先声明，所以先初始化 `a`
2. 初始化 `a` 时，`b` 还没初始化（虽然你在初始化列表里写了 `b` 在前）
3. 结果就是 `a(b)` 用了一个未初始化的值
