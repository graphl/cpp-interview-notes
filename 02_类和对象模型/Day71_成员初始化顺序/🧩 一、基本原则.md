## 🧩 一、基本原则

### ✅ **构造函数：从外到内**

对象创建时，先构造基类，再构造成员变量，最后构造自己。

### ✅ **析构函数：从内到外**

对象销毁时，先析构自己，再析构成员变量，最后析构基类。

> 👉 换句话说：
>  **构造顺序 = 定义顺序**
>  **析构顺序 = 构造顺序的逆序**

## 🧱 二、普通类的构造 / 析构顺序

```
#include <iostream>
using namespace std;

class A {
public:
    A() { cout << "A 构造\n"; }
    ~A() { cout << "A 析构\n"; }
};

class B {
public:
    B() { cout << "B 构造\n"; }
    ~B() { cout << "B 析构\n"; }
};

class C {
    A a;
    B b;
public:
    C() { cout << "C 构造\n"; }
    ~C() { cout << "C 析构\n"; }
};

int main() {
    C c;
}
```

### 🔍 输出结果：

```
A 构造
B 构造
C 构造
C 析构
B 析构
A 析构
```

### 🧠 分析：

- 构造时：
  1. 成员 `a` 构造
  2. 成员 `b` 构造
  3. 类 `C` 自身构造
- 析构时：
  1. 类 `C` 析构
  2. 成员 `b` 析构
  3. 成员 `a` 析构
