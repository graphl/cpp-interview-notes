## 🧭 三、继承关系下的执行顺序

```
#include <iostream>
using namespace std;

class Base {
public:
    Base() { cout << "Base 构造\n"; }
    ~Base() { cout << "Base 析构\n"; }
};

class Derived : public Base {
public:
    Derived() { cout << "Derived 构造\n"; }
    ~Derived() { cout << "Derived 析构\n"; }
};

int main() {
    Derived d;
}
```

### 🔍 输出结果：

```
Base 构造
Derived 构造
Derived 析构
Base 析构
```

### 🧠 分析：

- 构造顺序：
   基类 → 派生类
- 析构顺序：
   派生类 → 基类

## 🧮 四、包含继承 + 成员对象 的综合示例

```
#include <iostream>
using namespace std;

class A {
public:
    A() { cout << "A 构造\n"; }
    ~A() { cout << "A 析构\n"; }
};

class B {
public:
    B() { cout << "B 构造\n"; }
    ~B() { cout << "B 析构\n"; }
};

class Base {
public:
    Base() { cout << "Base 构造\n"; }
    ~Base() { cout << "Base 析构\n"; }
};

class Derived : public Base {
    A a;
    B b;
public:
    Derived() { cout << "Derived 构造\n"; }
    ~Derived() { cout << "Derived 析构\n"; }
};

int main() {
    Derived d;
}
```

### 🔍 输出：

```
Base 构造
A 构造
B 构造
Derived 构造
Derived 析构
B 析构
A 析构
Base 析构
```
