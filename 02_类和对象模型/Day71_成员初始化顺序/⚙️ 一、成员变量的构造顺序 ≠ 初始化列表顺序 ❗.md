## ⚙️ 一、成员变量的构造顺序 ≠ 初始化列表顺序 ❗

这是最容易踩坑的地方。

### 🧩 示例：

```
#include <iostream>
using namespace std;

class A {
public:
    A(int x) { cout << "A(" << x << ")\n"; }
};

class B {
    A a1;
    A a2;
public:
    B() : a2(2), a1(1) {  // 注意：顺序写反了！
        cout << "B()\n";
    }
};
```

### 🔍 输出结果：

```
A(1)
A(2)
B()
```

### 🧠 原因：

- 成员变量的构造顺序**由声明顺序决定**，不是初始化列表书写顺序。
   即使你写成 `a2(2), a1(1)`，依然是先构造 `a1`，再构造 `a2`。

📌 **建议**：

> 在初始化列表中，按照成员变量的声明顺序书写。
>  否则可能引起未定义行为（如果后面的成员依赖前面的成员）。

## 🧱 二、继承体系下的析构函数要设为虚函数

### ❌ 错误写法：

```
class Base {
public:
    ~Base() { cout << "Base 析构\n"; }
};

class Derived : public Base {
public:
    ~Derived() { cout << "Derived 析构\n"; }
};

int main() {
    Base* p = new Derived();
    delete p;  // ⚠️ 未定义行为
}
```

### 🔍 输出：

```
Base 析构
```

`Derived` 的析构函数**不会被调用** → 资源泄漏。

------

### ✅ 正确写法：

```
class Base {
public:
    virtual ~Base() { cout << "Base 析构\n"; }
};
```

### 输出：

```
Derived 析构
Base 析构
```

📌 **总结**：

> 只要类会被继承并可能通过基类指针删除，一定要加 `virtual ~Base()`。
