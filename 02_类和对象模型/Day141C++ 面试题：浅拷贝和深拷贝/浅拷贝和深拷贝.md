# C++ 面试题：浅拷贝和深拷贝

## 1. 核心结论

浅拷贝只复制指针地址。

深拷贝会重新申请资源，并复制资源内容。

---

## 2. 浅拷贝问题

```cpp
class A {
public:
    int* p;
};
```

默认拷贝会让两个对象的 `p` 指向同一块内存。

可能导致：

1. 重复释放
2. 一个对象修改影响另一个对象
3. 悬空指针

---

## 3. 深拷贝示例

```cpp
class A {
public:
    A(int v) : p(new int(v)) {}

    ~A() {
        delete p;
    }

    A(const A& other) {
        p = new int(*other.p);
    }

    A& operator=(const A& other) {
        if (this != &other) {
            int* temp = new int(*other.p);
            delete p;
            p = temp;
        }
        return *this;
    }

private:
    int* p;
};
```

---

## 4. 什么时候需要深拷贝？

类中有裸指针或外部资源时，通常需要自己定义拷贝控制函数。

资源包括：

1. 堆内存
2. 文件句柄
3. socket
4. 互斥锁

---

## 5. 面试回答

浅拷贝只复制成员值，如果成员是指针，就只复制地址，多个对象会共享同一资源，容易 double free。深拷贝会为新对象重新申请资源并复制内容，使两个对象互不影响。类中有资源成员时，要特别注意拷贝构造和赋值运算符。
