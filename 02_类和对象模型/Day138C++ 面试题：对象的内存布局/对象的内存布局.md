# C++ 面试题：对象的内存布局

## 1. 核心结论

C++ 对象的内存布局和成员变量、继承、虚函数、内存对齐有关。

非静态成员变量通常存储在对象内部，成员函数和静态成员不占每个对象的空间。

---

## 2. 普通对象

```cpp
class A {
    int x;
    char c;
};
```

对象中主要存放非静态成员变量。

由于内存对齐，`sizeof(A)` 可能不是 `sizeof(int) + sizeof(char)`，通常会补齐。

---

## 3. 有虚函数的对象

```cpp
class A {
public:
    virtual void f() {}
private:
    int x;
};
```

有虚函数的对象通常会多一个虚表指针 `vptr`。

`vptr` 指向虚函数表，支持运行时多态。

---

## 4. 静态成员和成员函数

```cpp
class A {
    static int count;
    int x;
    void f();
};
```

`static` 成员属于类，不属于某个对象。

成员函数代码也不存储在对象内部。

---

## 5. 面试回答

C++ 对象内部通常只保存非静态成员变量。如果类有虚函数，对象中通常还会有虚表指针。静态成员变量属于类本身，不占单个对象空间；成员函数代码在代码区，也不占对象空间。对象大小还会受到内存对齐和继承关系影响。
