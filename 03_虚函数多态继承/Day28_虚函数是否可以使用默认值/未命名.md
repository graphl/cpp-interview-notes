

```
#include <iostream>
using namespace std;

class Base {
public:
    virtual void show(int x = 1) {
        cout << "Base::show, x = " << x << endl;
    }
};

class Derived : public Base {
public:
    void show(int x = 2) override { // 默认值 2
        cout << "Derived::show, x = " << x << endl;
    }
};

int main() {
    Base* p = new Derived();
    p->show(); // 会输出什么？
    delete p;
}
```

Derived::show, x = 1

- **`p->show()`** 调用时：
  - **虚函数选择**：运行时看对象实际类型 → 调用 `Derived::show`。
  - **默认参数选择**：编译时看 `p` 的静态类型是 `Base*` → 默认值取 `Base` 里的 `1`。

**所以默认值来自 Base，而实际调用函数来自 Derived。**
