 ```
 #include <iostream>
 using namespace std;
 struct A {
     virtual void f() { cout << "A\n"; }
 };
 struct B : A {
     void f(int) { cout << "B int\n"; }
 };
 int main() {
     B b;
     b.f(1);
     // b.f(); // 会怎样？
 }
 ```
> **问题**：为什么 `b.f()` 会报错？如何解决？
>
> 答：编译器在 `B` 中找 `f`，只找到 `void f(int)`，没有找到无参版本，于是报错：**没有匹配的函数**。
>
> ## **解决方法**

| 方式                                                         | 优点             | 缺点           |
| ------------------------------------------------------------ | ---------------- | -------------- |
| `using A::f;`<br />struct B : A {<br/>    using A::f; // 引入 A::f() 到 B 的作用域<br/>    void f(int) { cout << "B int\n"; }<br/>}; | 简洁，保留多态性 | 需要明确写一次 |
| 手动重写无参版本                                             | 可定制实现       | 维护成本高     |
| 作用域解析符调用                                             | 临时解决         | 不支持多态调用 |
