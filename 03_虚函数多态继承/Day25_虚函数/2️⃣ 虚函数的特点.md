# 2️⃣ 虚函数的特点

| 特性                 | 说明                                               |
| -------------------- | -------------------------------------------------- |
| 声明方式             | 在函数声明前加 `virtual`                           |
| 继承性               | 子类继承后默认也是虚函数（即使不写 `virtual`）     |
| 重写                 | 子类可以用同样函数签名覆盖父类版本                 |
| 调用方式             | 必须通过 **基类指针或引用** 调用，才会触发动态绑定 |
| 静态类型 vs 动态类型 | 动态类型决定调用哪个函数                           |
