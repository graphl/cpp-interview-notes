# C++ 虚函数、多态与继承

本专题的核心不是记住“有一张虚表”，而是理解一次虚调用如何从对象中的动态类型信息定位到最终函数，以及构造、析构和多继承为什么会改变这个过程。

## 推荐学习顺序

```text
静态绑定与动态绑定
  -> virtual、override、final
  -> vptr、vtable 与虚调用
  -> 虚析构和纯虚析构
  -> 构造/析构期间的动态类型
  -> 多继承、虚继承、this 调整
```

## 必会问题

1. 通过基类指针调用虚函数时，静态类型和动态类型分别负责什么？
2. 为什么通过基类指针删除派生对象时需要虚析构？
3. 构造和析构期间调用虚函数为什么不会落到最派生实现？
4. 多继承下为什么可能存在多个 vptr 和 `this` 指针调整？
5. 虚继承解决菱形继承中的什么问题，又增加了什么成本？
6. 虚函数一定无法内联吗？编译器何时可能去虚拟化？

## 实现相关边界

## 待补重点

RTTI、`dynamic_cast`、`typeid`、协变返回类型、去虚拟化条件和跨动态库 ABI 风险。
