- ## 3. **虚函数声明为 inline 会怎样？**

  ✅ **可能情况：**

  - 如果编译器在编译期就能确定调用的具体函数（**静态绑定**的情况，比如通过对象调用而不是指针/引用），那么即使是虚函数也可能被 **内联展开**。

  - 例如：

    ```
    struct Base {
        virtual inline void f() { std::cout << "Base\n"; }
    };
    int main() {
        Base b;
        b.f();  // 编译器知道是 Base::f，可以内联
    }
    ```

    这里 `b.f()` 是 **静态类型已知的直接调用**，编译器可以内联。

  ❌ **不能内联的情况：**

  - 如果是通过 **基类指针/引用** 调用：

    ```
    Base* p = new Base();
    p->f(); // 动态绑定，运行时才能确定目标函数
    ```

    这种情况下，必须走 **虚表查找**，所以无法真正做到内联。
