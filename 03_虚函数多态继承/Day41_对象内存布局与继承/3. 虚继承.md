## 3. 虚继承

- **虚继承**更复杂，编译器会引入“虚基表（vbtable）”或额外指针，帮助定位虚基类子对象。
- 对象里可能既有 vptr 又有 vbptr。
- 常见情况：一个类通过虚继承 `Base`，编译器会在对象布局里加一张“虚基表”来存偏移量。

```
struct A { virtual void f(); };
struct B : virtual A { };
struct C : virtual A { };
struct D : B, C { };
```

在 x86-64 上（典型 Itanium ABI）大致长这样：

```
[D]
 ├─ [B 子对象]
 │    └─ vptr -> D::B 部分用的 vtable
 ├─ [C 子对象]
 │    └─ vptr -> D::C 部分用的 vtable
 └─ [A 虚基类子对象]   <-- 只保留一份
      └─ vptr -> A 部分的 vtable
```
