## 1. 普通情况

- **单继承、没有虚继承**：
  - 一个类只会有 **1 个虚函数表（vtable）指针**。
  - 虚表里存放该类的虚函数地址。

```
struct Base {
    virtual void f();
    virtual void g();
};

struct Derived : public Base {
    void f() override;
};
```

这里：

- `Base` 有 1 个 vtable，里面是 `{&Base::f, &Base::g}`。
- `Derived` 也有 1 个 vtable，里面是 `{&Derived::f, &Base::g}`。
