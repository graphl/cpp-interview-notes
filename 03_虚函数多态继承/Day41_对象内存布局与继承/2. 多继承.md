## 2. 多继承

- **多继承**时，每个有虚函数的基类子对象，都会有自己的一份 vtable。
- 也就是说，一个类可能有 **多个 vtable 指针**。

```
struct Base1 { virtual void f1(); };
struct Base2 { virtual void f2(); };
struct Derived : public Base1, public Base2 {
    void f1() override;
    void f2() override;
    void f3();
};
```

这里：

- `Base1` 有 1 个 vtable。
- `Base2` 有 1 个 vtable。
- `Derived` 继承了两个基类，所以对象里会有 **两个 vptr（虚表指针）**，分别指向一个个 vtable, 不同地址。

```
[0] 偏移值
[1] type_info* for Base  // RTTI指针（用于typeid/ dynamic_cast） 
[2] &Base1::f1         // 虚函数地址 第一个vptr指向的地址
[3] &Derived::f3 // 虚函数地址
[4] 偏移值
[5] type_info* for Base  // RTTI指针（用于typeid/ dynamic_cast） 
[6] &Base2::f2   ///  第二个vptr指向的地址
```
