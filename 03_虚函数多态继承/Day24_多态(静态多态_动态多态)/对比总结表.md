# 对比总结表

| 特性         | 静态多态（编译时）           | 动态多态（运行时）         |
| ------------ | ---------------------------- | -------------------------- |
| **关键字**   | 模板、函数重载、运算符重载等 | `virtual`、`override`      |
| **绑定时机** | 编译期间                     | 运行期间                   |
| **性能**     | 更快，无虚表开销             | 有虚表查找，有少量性能损耗 |
| **可扩展性** | 编译时确定，扩展需重新编译   | 支持运行时扩展，代码更灵活 |
| **使用方式** | 编译时泛型逻辑、模板库       | 框架接口设计、插件式架构   |
| **典型例子** | STL、模板函数、内联函数      | 虚函数、运行时多态接口     |
