# 静态多态、动态多态

| 分类         | 绑定时机     | 实现方式                     | 是否依赖虚函数 | 性能影响 | 应用场景               |
| ------------ | ------------ | ---------------------------- | -------------- | -------- | ---------------------- |
| **静态多态** | 编译时期绑定 | 函数重载、模板、运算符重载等 | ❌ 否           | ✅ 更高效 | 模板库、STL            |
| **动态多态** | 运行时期绑定 | 虚函数 + 指针/引用调用       | ✅ 是           | ❌ 略慢   | 面向接口设计，框架扩展 |

## 🔬 从汇编/底层来看：

- **静态绑定**：直接跳转到函数地址（如 `call 0x400123`）
- **动态绑定**：通过虚函数表间接跳转（如 `mov eax, [ecx+8]` → `jmp [eax+4]`）
