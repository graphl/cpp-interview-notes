## 二、虚继承的解决方法

在继承时加上 `virtual` 关键字：

```
class A {
public:
    int value;
};

class B : virtual public A {};  // 虚继承
class C : virtual public A {};  // 虚继承
class D : public B, public C {};
```

这时 `D` 中只会保留 **一份 A 子对象**，从而消除了二义性。

------

## 三、虚继承的特点

1. **共享基类子对象**
   - 使用虚继承时，不管有多少条继承路径，最终派生类里只有 **一份虚基类**。
2. **内存布局不同**
   - 编译器一般会通过 **虚基类表指针（vbptr）** 来记录虚基类在内存中的偏移。
   - 因此访问虚基类成员时，编译器可能会生成额外的间接寻址代码。
3. **构造顺序**
   - 虚基类的构造由 **最终派生类** 负责，而不是中间类。
   - 比如上例中 `D` 构造时才会调用 `A` 的构造函数，`B` 和 `C` 不会调用。
