## 使用场景

- 多继承中需要避免重复的基类子对象。

- 最典型的例子就是 **iostream** 库：

  ```
  class ios_base { ... };
  class istream : virtual public ios_base { ... };
  class ostream : virtual public ios_base { ... };
  class iostream : public istream, public ostream { ... };
  ```

  `iostream` 同时继承了 `istream` 和 `ostream`，如果不使用虚继承，就会有两份 `ios_base`。
