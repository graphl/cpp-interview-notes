# Linux 后台开发扩展

本专题从系统调用和内核对象出发，理解一个服务如何接收连接、搬运数据、调度任务并处理异常退出。面试回答应尽量沿数据流，而不是只罗列 API。

## 推荐学习顺序

```text
进程、线程、用户态与内核态
  -> 文件描述符与系统调用
  -> IPC、共享内存、mmap
  -> socket 与 TCP 生命周期
  -> 阻塞/非阻塞、同步/异步
  -> select/poll/epoll
  -> Reactor、协程与服务架构
  -> proc/sys/dev 现场排查
```

## 必会问题

1. 文件描述符指向什么内核对象，复制和关闭如何影响引用？
2. 系统调用如何完成用户态到内核态的切换？
3. 共享内存为什么快，又为什么仍需要同步机制？
4. LT 与 ET 模式下，非阻塞 IO 和“读到 EAGAIN”为什么重要？
5. TCP 字节流为什么没有消息边界，应用层如何处理半包和粘包？
6. Reactor 的事件循环、连接状态、读写缓冲和工作线程如何协作？

## 建议使用的数据流

```text
网卡 -> 内核协议栈 -> socket 接收队列 -> epoll 就绪事件
-> accept/recv -> 用户态缓冲 -> 协议解析 -> 业务处理 -> send
```

## 待补重点

socket 编程闭环、信号处理、daemon、连接超时、背压、惊群、`SO_REUSEPORT`、零拷贝实际数据路径和线上排查案例。
