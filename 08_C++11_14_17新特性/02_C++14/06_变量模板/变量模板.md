# C++14：变量模板

变量模板允许为不同类型生成一组变量或编译期常量：

```cpp
template <typename T>
constexpr T pi = T(3.1415926535897932385L);

double d = pi<double>;
float f = pi<float>;
```

它减少了只为保存常量而定义类模板静态成员的样板代码。C++17 标准库中的 `_v` 类型特征快捷形式，例如 `std::is_same_v<T, U>`，就是变量模板的典型应用。

## 使用方法

```cpp
#include <iostream>

template <typename T>
constexpr T pi = static_cast<T>(3.1415926535897932385L);

template <typename T>
constexpr bool is_pointer = false;

template <typename T>
constexpr bool is_pointer<T*> = true; // 变量模板偏特化

int main() {
    float radius = 2.0f;
    float area = pi<float> * radius * radius;
    std::cout << area << '\n';
    static_assert(is_pointer<int*>, "int* must be a pointer");
}
```

调用格式为 `变量名<模板实参>`。变量模板支持偏特化，适合类型相关常量和类型特征；若放在头文件中，要注意 C++14 的多翻译单元定义规则，优先让常量保持 `constexpr`/内部链接或采用项目认可的定义方式。
