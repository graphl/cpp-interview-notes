# C++14：函数返回类型推导

C++14 允许普通函数用 `auto` 推导返回类型：

```cpp
auto square(int value) {
    return value * value;
}
```

存在多条 `return` 时，推导结果必须一致：

```cpp
auto choose(bool flag) {
    if (flag) return 1;
    return 2;  // 两条分支均为 int
}
```

只写 `auto` 按模板类型推导规则处理，通常会丢弃引用和顶层 `const`。需要精确保留表达式类型时，可使用 `decltype(auto)`。

## 使用方法

```cpp
#include <iostream>
#include <vector>

auto make_values() {
    return std::vector<int>{1, 2, 3}; // 推导为 std::vector<int>
}

auto sum(int a, int b) {
    return a + b;                    // 推导为 int
}

int main() {
    auto values = make_values();     // 接收返回对象
    std::cout << sum(values[0], values[1]) << '\n';
}
```

函数在首次使用前必须已经给出定义，因为调用点需要知道推导结果。所有参与推导的 `return` 必须得到同一类型；递归函数也必须先通过某条非递归返回语句确定返回类型。仅声明 API 或需要稳定接口类型时，仍建议显式写返回类型。
