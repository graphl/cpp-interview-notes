# C++14：数字分隔符

C++14 允许在数字字面量中使用单引号分隔数字，提高可读性：

```cpp
int population = 1'000'000;
unsigned mask = 0b1111'0000;
double value = 3.141'592'6;
```

分隔符不改变数值和类型，也不需要按照固定的三位或四位分组。它不能出现在字面量开头、末尾或小数点相邻的非法位置。

## 使用方法

```cpp
#include <cstdint>
#include <iostream>

int main() {
    constexpr std::uint64_t frequency = 2'400'000'000ULL;
    constexpr std::uint32_t ipv4Mask  = 0xFF'FF'FF'00u;
    constexpr std::uint8_t flags      = 0b1010'0101;
    constexpr double timeout          = 1'000.5;

    std::cout << frequency << ' ' << ipv4Mask << ' '
              << static_cast<int>(flags) << ' ' << timeout << '\n';
}
```

单引号只改善源码可读性，不参与数值计算。十进制常按三位分组，二进制常按四位或字段宽度分组，十六进制可按字节分组。字符字面量中的单引号与数字分隔符不是一回事。
