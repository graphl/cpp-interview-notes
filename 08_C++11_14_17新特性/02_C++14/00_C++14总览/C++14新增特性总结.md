# C++14 新增特性总结

## 1. C++14 的定位

C++14 是对 C++11 的增量改进，重点不是引入全新的编程范式，而是让类型推导、Lambda、`constexpr` 和模板编程更容易使用。

面试高频特性包括：

1. 泛型 Lambda；
2. Lambda 初始化捕获；
3. 普通函数返回类型推导；
4. `decltype(auto)`；
5. 放宽的 `constexpr`；
6. 变量模板；
7. `std::make_unique`。

---

## 2. 泛型 Lambda

C++14 允许 Lambda 的形参使用 `auto`：

```cpp
auto add = [](auto a, auto b) {
    return a + b;
};

auto x = add(1, 2);       // int
auto y = add(1.5, 2.0);   // double
```

泛型 Lambda 的闭包类型中包含一个函数调用运算符模板，概念上类似：

```cpp
struct Closure {
    template <typename T, typename U>
    auto operator()(T a, U b) const {
        return a + b;
    }
};
```

C++11 已经有 Lambda，但参数类型必须明确；泛型 Lambda 是 C++14 特性。

---

## 3. Lambda 初始化捕获

C++14 允许在捕获列表中创建并初始化新的闭包成员：

```cpp
#include <memory>

auto ptr = std::make_unique<int>(42);

auto task = [value = 10, p = std::move(ptr)]() {
    return value + *p;
};
```

初始化捕获的重要用途是把只能移动的对象，例如 `unique_ptr`，移动进 Lambda。

这里的 `p` 属于闭包对象，不是外部变量 `ptr` 的引用；调用 `std::move(ptr)` 后，外部 `ptr` 通常为空。

---

## 4. 普通函数返回类型推导

C++11 支持 Lambda 返回类型推导；C++14 进一步允许普通函数使用 `auto` 推导返回类型：

```cpp
auto square(int x) {
    return x * x;
}
```

如果函数存在多条 `return`，它们推导出的类型必须一致：

```cpp
auto choose(bool flag) {
    if (flag) return 1;
    return 2;             // 两条分支都是 int
}
```

仅写 `auto` 时按值推导，引用和顶层 `const` 通常会被丢弃。

---

## 5. `decltype(auto)`

`decltype(auto)` 使用 `decltype` 的规则推导类型，可以保留引用和 `const` 属性。

```cpp
int value = 10;

auto get_value() {
    return value;          // 返回 int
}

decltype(auto) get_ref() {
    return (value);        // 返回 int&，括号会影响 decltype 规则
}
```

这也是一个高频陷阱：

```cpp
decltype(auto) f() {
    int local = 10;
    return (local);        // 错误：返回局部变量的悬空引用
}
```

使用 `decltype(auto)` 时必须特别关注返回表达式的值类别和生命周期。

---

## 6. 放宽 `constexpr`

C++11 的 `constexpr` 函数限制很严格，函数体基本只能包含一个返回表达式。C++14 允许局部变量、循环和条件分支等语句：

```cpp
constexpr int factorial(int n) {
    int result = 1;
    for (int i = 2; i <= n; ++i) {
        result *= i;
    }
    return result;
}

static_assert(factorial(5) == 120, "wrong result");
```

`constexpr` 函数并不保证每次都在编译期执行。只有在常量表达式上下文中调用，并且实参满足条件时，才必须在编译期求值。

---

## 7. 变量模板

C++14 允许变量自身成为模板：

```cpp
template <typename T>
constexpr T pi = T(3.1415926535897932385L);

double d = pi<double>;
float f = pi<float>;
```

变量模板常用于为不同类型提供编译期常量。C++17 标准库中的 `_v` 类型特征快捷写法与这个能力密切相关，例如 `std::is_same_v<T, U>`。

---

## 8. 二进制字面量和数字分隔符

```cpp
int mask = 0b1010'1100;
long population = 1'000'000;
```

- `0b` 或 `0B` 表示二进制整数字面量；
- 单引号可作为数字分隔符，提高可读性，不影响数值。

---

## 9. `std::make_unique`

C++14 补充了 C++11 缺失的 `std::make_unique`：

```cpp
auto object = std::make_unique<Widget>(1, "worker");
auto array = std::make_unique<int[]>(100);
```

优点：

- 避免显式书写 `new`；
- 类型只写一次；
- 对象构造和所有权交接更清晰；
- 与 `auto` 配合简洁。

面试版本辨析：`make_shared` 属于 C++11，`make_unique` 属于 C++14。

---

## 10. 其他标准库增强

C++14 还加入或增强了：

- `std::integer_sequence`、`std::index_sequence`：编译期整数序列；
- `std::exchange`：用新值替换旧值并返回旧值；
- `std::shared_timed_mutex`、`std::shared_lock`：读写锁支持；
- `std::less<>` 等透明函数对象：支持异构比较；
- `std::quoted`：处理带引号字符串；
- `std::get<T>(tuple)`：按唯一类型访问元组元素；
- 标准用户定义字面量，例如 `"abc"s` 和时间单位后缀。

```cpp
int old = std::exchange(value, 0);
```

`std::exchange` 只是赋新值并返回旧值，它不是原子操作。

---

## 11. C++14 面试速答

> C++14 是对 C++11 的完善。最常考的是泛型 Lambda、Lambda 初始化捕获、普通函数的 `auto` 返回类型推导、能保留引用属性的 `decltype(auto)`、限制更少的 `constexpr`、变量模板以及 `std::make_unique`。它的核心方向是减少样板代码，让 C++11 的抽象能力更容易落地。

