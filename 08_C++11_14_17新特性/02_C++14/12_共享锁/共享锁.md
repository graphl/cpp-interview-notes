# C++14：共享锁

C++14 引入 `std::shared_timed_mutex` 和 `std::shared_lock`，支持多读单写：

```cpp
std::shared_timed_mutex mutex;

void read() {
    std::shared_lock<std::shared_timed_mutex> lock(mutex);
    // 多个读线程可以同时进入。
}

void write() {
    std::unique_lock<std::shared_timed_mutex> lock(mutex);
    // 写线程独占访问。
}
```

共享锁适合读多写少且临界区足够大的场景。它不天然保证公平性，具体实现可能出现读者或写者饥饿。

版本辨析：`shared_timed_mutex` 属于 C++14，`shared_mutex` 属于 C++17。

## 使用方法

```cpp
#include <iostream>
#include <mutex>
#include <shared_mutex>
#include <string>
#include <thread>
#include <unordered_map>
#include <utility>

class Cache {
public:
    std::string get(int key) const {
        std::shared_lock<std::shared_timed_mutex> lock(mutex_);
        auto it = data_.find(key);
        return it == data_.end() ? std::string{} : it->second;
    }

    void set(int key, std::string value) {
        std::unique_lock<std::shared_timed_mutex> lock(mutex_);
        data_[key] = std::move(value);
    }

private:
    mutable std::shared_timed_mutex mutex_;
    std::unordered_map<int, std::string> data_;
};

int main() {
    Cache cache;
    cache.set(1, "ready");
    std::thread reader([&] { std::cout << cache.get(1) << '\n'; });
    reader.join();
}
```

读操作用 `shared_lock`，写操作用 `unique_lock`，二者必须锁定同一个互斥量。不要在持有共享锁时直接升级为独占锁；标准接口没有提供无竞争的原子升级操作。临界区很小或写入频繁时，普通 `mutex` 可能更简单、更快。
