# C++14：共享锁

C++14 引入 `std::shared_timed_mutex` 和 `std::shared_lock`，支持多读单写：

```cpp
std::shared_timed_mutex mutex;

void read() {
    std::shared_lock<std::shared_timed_mutex> lock(mutex);
    // 多个读线程可以同时进入。
}

void write() {
    std::unique_lock<std::shared_timed_mutex> lock(mutex);
    // 写线程独占访问。
}
```

共享锁适合读多写少且临界区足够大的场景。它不天然保证公平性，具体实现可能出现读者或写者饥饿。

版本辨析：`shared_timed_mutex` 属于 C++14，`shared_mutex` 属于 C++17。
