# C++14：二进制字面量

C++14 支持以 `0b` 或 `0B` 开头的二进制整数字面量：

```cpp
unsigned mask = 0b10101100;
unsigned flag = 0B00000001;
```

它特别适合表示寄存器位、协议标志和权限掩码。二进制字面量只是源代码表示方式，最终整数类型仍由数值和后缀决定。

```cpp
auto value = 0b1111u;  // unsigned int
```

## 使用方法

```cpp
#include <cstdint>
#include <iostream>

enum RegisterBits : std::uint8_t {
    Enable    = 0b0000'0001,
    Interrupt = 0b0000'0010,
    Ready     = 0b1000'0000
};

int main() {
    std::uint8_t reg = Enable | Interrupt; // 初始化并置位
    reg |= Ready;                          // 设置 Ready
    reg &= static_cast<std::uint8_t>(~Interrupt); // 清除 Interrupt

    if ((reg & Enable) != 0) {             // 查询某一位
        std::cout << "enabled\n";
    }
}
```

二进制字面量通常与位或 `|`、位与 `&`、位反 `~` 和移位运算一起使用。寄存器或协议字段应优先采用固定宽度整数，并留意整型提升和取反后的类型。
