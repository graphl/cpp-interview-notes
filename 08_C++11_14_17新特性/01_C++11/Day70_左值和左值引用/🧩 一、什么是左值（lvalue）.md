## 🧩 一、什么是左值（lvalue）

**左值（lvalue）**：表示**有名字、可寻址的对象**。
 简单来说，就是**可以出现在赋值号左边的表达式**。

📘 举例：

```
int a = 10;   // a 是左值
int b = a;    // a 是左值（有地址，可取 &a）
```

✅ 左值的特点：

- 可以取地址（`&a`）
- 存在于某个内存位置中
- 生命周期可延续

❌ 右值（rvalue）：

```
int x = 10;      // 10 是右值（常量字面量）
int y = a + 2;   // a+2 是右值（临时结果）
```

## 🧷 二、左值引用定义

左值引用使用 `&` 声明：

```
int a = 10;
int& ref = a;  // ref 是 a 的左值引用
```

此时：

- `ref` 就是 `a` 的别名；
- 对 `ref` 的操作就是对 `a` 的操作。

📘 举例：

```
ref = 20;
std::cout << a;  // 输出 20
```
