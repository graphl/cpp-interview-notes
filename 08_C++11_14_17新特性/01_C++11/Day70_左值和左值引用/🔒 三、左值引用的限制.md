## 🔒 三、左值引用的限制

左值引用**不能绑定到右值（临时对象）**上：

```
int& r = 10;  // ❌ 错误！10 是右值
```

右值没有稳定的内存位置，因此普通左值引用不能绑定它。

------

## ⚙️ 四、常量左值引用（const &）

可以**绑定右值**：

```
const int& r = 10;  // ✅ OK！
```

解释：

- 编译器会在后台创建一个临时变量：

  ```
  int temp = 10;
  const int& r = temp;
  ```

- 所以 `r` 实际上引用的是一个临时对象 `temp`。

这就是为什么函数参数经常写成：

```
void print(const std::string& s);
```

可以接受：

```
std::string str = "hello";
print(str);        // 左值
print("hello");    // 右值（字面量）也 OK
```

------

## 🧠 五、左值引用常见用途

1. **作为函数参数传递**（避免拷贝）：

   ```
   void foo(int& x) { x++; }
   ```

2. **作为返回值**（允许修改原对象）：

   ```
   int& getValue() {
       static int val = 10;
       return val;
   }
   
   getValue() = 20;  // 修改静态变量 val
   ```

3. **配合 const 修饰**（提高通用性）：

   ```
   void show(const std::string& s);
   ```
