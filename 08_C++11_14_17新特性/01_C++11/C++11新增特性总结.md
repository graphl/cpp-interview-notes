# C++11 新增特性总结

## 1. C++11 的定位

C++11 是现代 C++ 的起点。它不仅增加了语法糖，还系统性地引入了移动语义、类型推导、Lambda、智能指针、并发库等基础设施。

面试时通常从下面几条主线考查：

1. 值类别、右值引用和移动语义；
2. `auto`、`decltype` 与模板类型推导；
3. Lambda、`std::function`、`std::bind`；
4. 智能指针与 RAII；
5. 可变参数模板和完美转发；
6. C++ 内存模型与并发库。

## 3. `nullptr`

C++11 用 `nullptr` 表示空指针，类型是 `std::nullptr_t`。它解决了整数 `0` 或宏 `NULL` 参与函数重载时可能产生的歧义。

```cpp
void f(int);
void f(const char*);

f(0);        // 调用 f(int)
f(nullptr);  // 调用 f(const char*)
```

面试要点：`nullptr` 不是整数 `0`，但可以隐式转换为任意指针类型和成员指针类型。

## 4. `= default`、`= delete`、`override`、`final`

```cpp
class Base {
public:
    virtual void run() = 0;
    virtual ~Base() = default;
};

class Worker final : public Base {
public:
    Worker() = default;
    Worker(const Worker&) = delete;
    Worker& operator=(const Worker&) = delete;

    void run() override {}
};
```

- `= default`：显式要求编译器生成默认实现；
- `= delete`：禁止某个函数参与调用，也可用于禁止特定隐式转换；
- `override`：让编译器检查函数是否正确重写虚函数；
- `final`：禁止类继续被继承，或禁止虚函数继续被重写。

这些关键字将原本依赖约定的设计意图变成编译期约束。

## 5. 委托构造和继承构造

### 委托构造

一个构造函数可以复用同类的另一个构造函数：

```cpp
class Config {
public:
    Config() : Config(0, "default") {}
    Config(int id, std::string name)
        : id_(id), name_(std::move(name)) {}

private:
    int id_;
    std::string name_;
};
```

### 继承构造

```cpp
class Derived : public Base {
public:
    using Base::Base;
};
```

委托构造减少同一个类内部的初始化重复；继承构造可以引入基类构造函数。

## 6. 可变参数模板

可变参数模板允许模板接收任意数量、任意类型的模板参数，是 `tuple`、工厂函数和通用包装器的重要基础。

```cpp
#include <iostream>

void print() {
    std::cout << '\n';
}

template <typename T, typename... Args>
void print(T&& first, Args&&... rest) {
    std::cout << std::forward<T>(first) << ' ';
    print(std::forward<Args>(rest)...);
}
```

其中：

- `Args...` 是模板参数包；
- `rest...` 是函数参数包；
- `std::forward<Args>(rest)...` 对参数包逐个进行完美转发。

C++11 通常通过递归展开参数包；C++17 可以使用折叠表达式。

## 7. 别名模板和类型特征

```cpp
template <typename T>
using Vec = std::vector<T>;

static_assert(std::is_integral<int>::value, "int must be integral");
```

- `using` 别名比 `typedef` 更易读，并且支持别名模板；
- `<type_traits>` 提供编译期类型查询和转换；
- `static_assert` 在编译期验证条件。

常见类型特征包括 `is_same`、`is_integral`、`remove_reference`、`decay` 和 `enable_if`。

---

## 8. `noexcept`

```cpp
Widget(Widget&& other) noexcept;
```

`noexcept` 表示函数承诺不抛出异常。若异常逃出 `noexcept` 函数，程序会调用 `std::terminate`。

它不只是文档说明，还会影响标准库的优化。例如 `std::vector` 扩容时，为保证异常安全，通常只有在元素的移动构造为 `noexcept` 或无法拷贝时才优先移动。

## 9. 智能指针

C++11 标准化了三种智能指针：

| 智能指针 | 所有权语义 | 典型用途 |
|---|---|---|
| `std::unique_ptr` | 独占所有权，不可拷贝、可移动 | 默认首选 |
| `std::shared_ptr` | 共享所有权，使用强引用计数 | 多方共同控制生命周期 |
| `std::weak_ptr` | 不拥有对象，保存弱引用 | 观察对象、打破循环引用 |

```cpp
auto p = std::make_shared<int>(42);
std::weak_ptr<int> weak = p;

if (auto locked = weak.lock()) {
    // locked 在当前作用域内保证对象存活。
}
```

注意：`std::make_unique` 是 C++14 才加入的，不能把它算作 C++11 特性。

## 10. 容器和标准库补充

C++11 新增或完善了：

- `std::array`：固定长度、具有标准容器接口的数组；
- `std::tuple`：保存不同类型元素；
- `std::unordered_map`、`std::unordered_set`：哈希容器；
- `emplace` 系列接口：在容器内部直接构造元素；
- `<chrono>`：时间点、时间段和时钟；
- `<random>`：随机数引擎和概率分布；
- `<regex>`：正则表达式；
- 用户定义字面量、原始字符串字面量。

`emplace_back` 不保证永远比 `push_back` 更快。若对象已经构造完成，二者通常都可以移动；`emplace_back` 的优势是直接转发构造参数。

## 11. 并发和内存模型

C++11 第一次在语言标准中定义内存模型，并提供标准线程库：

- `std::thread`；
- `std::mutex`、`std::lock_guard`、`std::unique_lock`；
- `std::condition_variable`；
- `std::future`、`std::promise`、`std::async`；
- `std::atomic`；
- `thread_local`；
- `std::call_once` 和 `std::once_flag`。

```cpp
std::mutex m;
int value = 0;

void add() {
    std::lock_guard<std::mutex> lock(m);
    ++value;
}
```

面试时要区分：

- 互斥锁保护的是一段临界区及其不变量；
- 原子变量保证单个原子操作，不自动保证多个操作组成的业务事务；
- `volatile` 不能替代锁或原子变量。

---

## 12. C++11 面试速答

> C++11 奠定了现代 C++ 的基础。语言层面包括类型推导、右值引用、移动语义、完美转发、Lambda、列表初始化、可变参数模板、`constexpr`、`noexcept` 等；标准库层面包括智能指针、哈希容器、`tuple`、时间库、随机数库和完整的线程并发库。最核心的思想是强化类型安全、资源自动管理、零开销抽象和并发支持。
