**`std::move` 本身不移动对象。它只是把表达式转换成右值引用。
 只有当这个转换后的值被用在移动构造或移动赋值的场景中时，才会发生真正的资源转移。**

因为：

> `std::move(x)` 本质只是把 `x` 转换为右值引用（xvalue）
>  它本身不执行“移动”“交换”“释放”之类的动作

------

## 🔍 示例

```
std::string s = "hello";
std::move(s);   // ← 只写这个
```

运行后：

- `s` 不会变成空
- 不会触发移动构造或移动赋值
- 不会释放资源
- 没有任何副作用

✔ `s` 依然是 `"hello"`
 ❗ 编译器甚至可能直接把那行代码优化掉

------

## 什么时候才会真正 “移动”？

只有在 **`std::move(s)` 的结果被用在某个接受右值的地方** 才会触发移动语义：

例如：

```
std::string a = "hello";
std::string b = std::move(a);   // 触发移动构造 (资源转移)
```

移动只有**在某个函数 / 构造器 / 容器真的接收它并执行移动语义后才会发生**。
