## 🔹std::move 到底是什么？

很多人以为：

> std::move = “把对象移动到别的变量”

❌ **其实不是。**

👉 **std::move 本质只是一个类型转换：把左值转成右值引用（xvalue）。**
 它自己不做“移动”，只是让编译器有机会调用类的移动构造/移动赋值，从而“偷走资源”。

> std::move = 许可证
>  真正做“搬家”的是移动构造函数/移动赋值运算符

## 🔹为什么要把对象转成右值引用？

因为 C++ 的移动语义只在 **右值** 上触发。

示例：

```
std::string a = "hello";
std::string b = std::move(a); // 触发 string 的移动构造，而不是拷贝
```

移动构造 ≈ “把指针直接偷走，不做深拷贝”
 ✔ 更快
 ✔ 更节省资源
