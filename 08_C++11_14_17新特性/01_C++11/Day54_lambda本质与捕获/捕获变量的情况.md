## 捕获变量的情况

### 值捕获

```
int a = 10;
auto f = [a](int x) { return x + a; };
```

编译器展开成：

```
struct __Lambda_2 {
    int a;
    int operator()(int x) const {
        return x + a;  // 用的是成员变量
    }
};
auto f = __Lambda_2{a};
```

👉 值捕获就是把变量拷贝到匿名类的成员变量里。

### 引用捕获

```
int a = 10;
auto f = [&a](int x) { return x + a; };
```

展开成：

```
struct __Lambda_3 {
    int& a;  // 引用成员
    int operator()(int x) const {
        return x + a;
    }
};
auto f = __Lambda_3{a};
```

👉 引用捕获就是在类里存一个引用。
