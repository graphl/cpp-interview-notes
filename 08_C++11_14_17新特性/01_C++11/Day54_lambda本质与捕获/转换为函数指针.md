##  转换为函数指针

如果没有捕获变量，lambda 可以隐式转换成普通函数指针：

```
auto f = [](int x){ return x+1; };
int (*fp)(int) = f; // OK
```

编译器会生成一个静态函数，然后让 lambda 转换成它的指针。

```
// 编译器生成的静态函数
static int __lambda_func(int x) { return x + 1; }

// lambda 对象可以隐式转为函数指针
int (*fp)(int) = &__lambda_func;
```

## 失败案例（有捕获）

```
int a = 5;
auto lam = [a](int x) { return x + a; };

// ❌ 错误：无法转成函数指针
int (*fp)(int) = lam;
```

## 和 `std::function` 的关系

- `lambda` 本质上是个类 → 仿函数。
- `std::function` 可以存储任何仿函数 → 所以能直接接收 lambda。

例如：

```
std::function<int(int)> f = [](int x){ return x+1; };
```

编译器会把 lambda 生成类，然后传给 `std::function`，最后通过 **类型擦除** 封装。
