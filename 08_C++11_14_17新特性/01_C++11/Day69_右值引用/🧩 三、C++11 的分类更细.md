## 🧩 三、C++11 的分类更细

在 C++11 之后，右值被细分为：

| 类型        | 名称                     | 说明                           | 举例                             |
| ----------- | ------------------------ | ------------------------------ | -------------------------------- |
| **lvalue**  | 左值                     | 有名字、可取地址               | `a`、`obj`                       |
| **xvalue**  | 将亡值（eXpiring Value） | 即将被销毁的对象，可以“偷资源” | `std::move(a)`                   |
| **prvalue** | 纯右值（Pure rvalue）    | 纯粹的临时值、字面值           | `10`、`a+b`、`std::string("hi")` |

👉 右值（rvalue）其实是：

> **右值 = xvalue + prvalue**

## 🧱 四、为什么需要右值引用（rvalue reference）

以前（C++98），只有左值引用：

```
void setValue(const string& s);
```

它不能绑定到右值：

```
setValue("abc"); // 可以，因为const引用可绑定右值
```

但是如果需要**修改**或**转移资源**，就不行了。
 于是 C++11 引入：

```
void setValue(string&& s);  // 右值引用
```
