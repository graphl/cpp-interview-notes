## ⚙️ 五、右值引用的作用：支持移动语义

### 🧳 示例

```
#include <iostream>
#include <string>
using namespace std;

class Person {
public:
    string name;

    Person(string n) : name(move(n)) {}   // 接收右值
};

int main() {
    string s = "Tom";
    Person p(move(s));  // 调用右值构造
    cout << "s is now: " << s << endl;  // s 的内容已被“偷走”
}
```

> `move(s)` 将左值 `s` 强制转成右值（xvalue），触发移动构造而非拷贝构造。

## 🧩 六、右值引用与 `std::move`

- `std::move` 不会移动数据，只是**类型转换**成右值引用（xvalue），表示“这个对象的资源可以被转移”。
- 真正的移动由**移动构造函数**或**移动赋值运算符**完成。

```
T&& && → T&&      // 折叠规则
T&  && → T&       // 左值优先
```

## ✅ 七、总结表

| 概念             | 是否可取地址 | 生命周期 | 是否有名字 | 示例           |
| ---------------- | ------------ | -------- | ---------- | -------------- |
| 左值 (lvalue)    | ✅            | 稳定     | ✅          | `a`, `obj`     |
| 纯右值 (prvalue) | ❌            | 临时     | ❌          | `10`, `a+b`    |
| 将亡值 (xvalue)  | ✅            | 即将销毁 | ✅/❌        | `std::move(a)` |
