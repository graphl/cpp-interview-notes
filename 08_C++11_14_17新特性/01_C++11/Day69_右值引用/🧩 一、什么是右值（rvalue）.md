## 🧩 一、什么是右值（rvalue）

在 C++ 中，表达式的结果要么是：

- **左值（lvalue）**：有名字、可取地址；
- **右值（rvalue）**：没有名字、不可取地址。

> ✅ 简单记法：
>
> - **左值**：可以放在“=”左边。
> - **右值**：只能放在“=”右边。

## 🧠 二、例子快速区分

| 表达式                     | 分类   | 原因                     |
| -------------------------- | ------ | ------------------------ |
| `int a = 10;`              | —      | —                        |
| `a`                        | ✅ 左值 | 有名字，可取地址（`&a`） |
| `10`                       | ✅ 右值 | 字面值，临时存在         |
| `a + 1`                    | ✅ 右值 | 表达式计算结果是临时值   |
| `std::string("abc")`       | ✅ 右值 | 临时对象                 |
| `func()`（返回值为非引用） | ✅ 右值 | 临时返回值               |
| `func()`（返回左值引用）   | ✅ 左值 | 实际是某个已存在变量     |
