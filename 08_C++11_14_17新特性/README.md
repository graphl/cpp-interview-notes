# C++11 / C++14 / C++17 新特性专题

本专题按语言标准分为三个目录：

| 目录 | 定位 | 建议学习重点 |
|---|---|---|
| `01_C++11` | 现代 C++ 的基础 | 移动语义、类型推导、Lambda、智能指针、并发 |
| `02_C++14` | 对 C++11 的易用性增强 | 12 个独立专题：泛型 Lambda、初始化捕获、返回值推导等 |
| `03_C++17` | 工程开发常用能力 | 19 个独立专题：结构化绑定、`if constexpr`、标准库新类型等 |

## 目录说明

原有的 Day 目录主要属于 C++11，已统一归入 `01_C++11`。其中“函数指针和回调函数”本身早于 C++11，但它是理解 `std::function`、`std::bind` 和 Lambda 的前置内容，因此仍放在 C++11 学习链中。

每个版本目录都有一份总览文档。C++14 和 C++17 还按照“一个知识点一个文件夹”拆成独立专题，用于：

1. 汇总该版本的重要语言和标准库特性；
2. 标出当前已有的专题；
3. 补充原目录没有覆盖的面试高频知识；
4. 给出版本辨析和面试回答重点。

## 推荐学习顺序

```text
C++11：auto / decltype
    -> 左值、右值与移动语义
    -> 完美转发
    -> Lambda 与可调用对象
    -> 智能指针、容器与并发库

C++14：泛型 Lambda
    -> Lambda 初始化捕获
    -> 返回值推导与 decltype(auto)
    -> constexpr 增强

C++17：结构化绑定
    -> if / switch 初始化语句
    -> if constexpr
    -> 折叠表达式与类模板参数推导
    -> optional / variant / any / string_view
    -> filesystem 与并行算法
```

## 版本速记

```text
C++11：建立现代 C++ 的基础设施
C++14：让 C++11 更容易写、更容易用
C++17：增强编译期编程，并补齐大量工程标准库
```
