# C++17：并发锁增强

C++17 新增 `std::shared_mutex` 和 `std::scoped_lock`。

```cpp
std::shared_mutex rw_mutex;

std::shared_lock read_lock(rw_mutex); // 共享读
```

`scoped_lock` 可以一次管理多把互斥锁，并使用避免死锁的加锁算法：

```cpp
std::scoped_lock lock(mutex1, mutex2);
```

它采用 RAII 自动解锁，但不能消除所有业务层死锁。版本辨析：`shared_timed_mutex` 和 `shared_lock` 来自 C++14，`shared_mutex`、`scoped_lock` 来自 C++17。

## 初始化与加锁调用

```cpp
#include <mutex>
#include <shared_mutex>
#include <string>
#include <utility>

class Account {
public:
    int balance() const {
        std::shared_lock lock(mutex_);        // CTAD 推导锁类型
        return balance_;
    }

    friend void transfer(Account& from, Account& to, int amount) {
        if (&from == &to) return;
        std::scoped_lock lock(from.mutex_, to.mutex_); // 无死锁地锁两把锁
        from.balance_ -= amount;
        to.balance_ += amount;
    }

private:
    mutable std::shared_mutex mutex_;
    int balance_{100};
};

int main() {
    Account first, second;
    transfer(first, second, 20);
    return second.balance() == 120 ? 0 : 1;
}
```

读路径用 `shared_lock`，写路径用 `unique_lock` 或单锁 `scoped_lock`。多锁操作应一次交给 `scoped_lock`，不要在不同函数中用相反顺序逐个加锁。所有访问同一共享不变量的路径必须遵守相同锁规则。
