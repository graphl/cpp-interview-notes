# C++17：标准属性

C++17 增加了三个常用标准属性：

```cpp
[[nodiscard]] bool save();

[[maybe_unused]] int debug_value = 0;

switch (state) {
case 0:
    prepare();
    [[fallthrough]];
case 1:
    run();
}
```

- `[[nodiscard]]`：提醒调用者不要忽略返回值；
- `[[maybe_unused]]`：抑制有意未使用的警告；
- `[[fallthrough]]`：明确表示 `switch` 分支有意贯穿。

这些属性主要改善诊断和表达意图，并不会自动实现错误处理。

## 使用方法

```cpp
#include <iostream>

[[nodiscard]] bool save() { return false; }

int main() {
    [[maybe_unused]] int debugCode = 7;

    if (!save()) {                    // 显式处理 nodiscard 返回值
        std::cerr << "save failed\n";
    }

    int state = 0;
    switch (state) {
    case 0:
        std::cout << "prepare\n";
        [[fallthrough]];
    case 1:
        std::cout << "run\n";
        break;
    }
}
```

属性写在它所修饰的声明或语句允许的位置。`nodiscard` 产生的是诊断，是否作为错误取决于编译选项；`fallthrough` 只能用于有意进入下一 `case` 的空语句位置，不能替代 `break`。
