# C++17：关联容器增强

C++17 为关联容器增加了节点句柄、`try_emplace` 和 `insert_or_assign`。

```cpp
map.try_emplace(key, constructor_arg);
map.insert_or_assign(key, value);

auto node = source.extract(key);
target.insert(std::move(node));
```

- `try_emplace`：键已存在时不构造新的映射值；
- `insert_or_assign`：不存在则插入，存在则赋值；
- 节点句柄：可在兼容容器间转移节点，避免重新分配元素。

节点转移仍需满足分配器等约束，不能把它理解为任意容器之间都能零成本搬运。

## 插入、更新与节点转移

```cpp
#include <iostream>
#include <map>
#include <string>
#include <utility>

int main() {
    std::map<int, std::string> source;

    auto [it1, inserted1] = source.try_emplace(1, 5, 'x');
    auto [it2, inserted2] = source.try_emplace(1, "ignored");
    // 第二次键已存在，不构造新的 mapped value

    auto [it3, inserted3] = source.insert_or_assign(1, "updated");
    // inserted3 == false，已有值被赋值

    std::map<int, std::string> target;
    auto node = source.extract(1);
    if (!node.empty()) {
        node.key() = 2;                       // 节点脱离容器后可修改键
        target.insert(std::move(node));
    }

    std::cout << target.at(2) << '\n';
}
```

`try_emplace` 适合构造成本高且“不覆盖旧值”的场景；`insert_or_assign` 明确表达新增或覆盖。`extract()` 返回拥有节点的句柄，未重新插入时句柄析构会释放节点；插入结果失败时要继续处理返回的节点句柄。
