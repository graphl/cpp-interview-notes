# C++17：结构化绑定

结构化绑定可以将数组、`pair`、`tuple` 或满足协议的对象拆成多个名字。

```cpp
std::pair<int, std::string> item{1, "apple"};
auto [id, name] = item;          // 绑定到副本
auto& [id_ref, name_ref] = item; // 引用原对象
```

遍历关联容器时常写成：

```cpp
for (const auto& [key, value] : table) {
    use(key, value);
}
```

易错点：是否添加 `&` 会影响复制、修改原对象和生命周期，不能把结构化绑定简单理解为声明两个完全独立的变量。

## 使用方法

```cpp
#include <iostream>
#include <map>
#include <string>
#include <tuple>

std::tuple<int, std::string, bool> query() {
    return {7, "camera", true};
}

int main() {
    auto [id, name, online] = query();       // 接收函数的多个返回值

    std::map<int, std::string> devices{{1, "sensor"}};
    for (const auto& [key, value] : devices) // 只读引用，避免复制
        std::cout << key << ':' << value << '\n';

    auto& [key, value] = *devices.begin();   // 引用原节点
    value = "camera";                        // 可修改 value；map 的 key 为 const
}
```

常见声明有 `auto [...]`（复制）、`auto& [...]`（可写引用）和 `const auto& [...]`（只读引用）。绑定临时对象时可用 `const auto&` 延长隐藏对象的生命周期，但不要返回其中成员的悬空引用。
