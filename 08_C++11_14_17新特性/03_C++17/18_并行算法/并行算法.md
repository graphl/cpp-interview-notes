# C++17：并行算法

C++17 为部分标准算法增加执行策略：

```cpp
std::sort(std::execution::par, values.begin(), values.end());
```

常见策略包括：

- `seq`：顺序执行；
- `par`：允许多线程并行；
- `par_unseq`：允许并行和向量化交错执行。

回调函数必须满足相应并发要求，不能无保护地修改共享状态。并行策略也不保证一定更快，小数据量、内存带宽限制和调度成本都可能抵消收益。

## 初始化与算法调用

```cpp
#include <algorithm>
#include <execution>
#include <iostream>
#include <numeric>
#include <vector>

int main() {
    std::vector<int> values(1'000'000);
    std::iota(values.begin(), values.end(), 0);

    std::for_each(std::execution::par, values.begin(), values.end(),
                  [](int& value) { value *= 2; });

    std::sort(std::execution::par, values.begin(), values.end());
    std::cout << values.back() << '\n';
}
```

执行策略是算法的第一个参数。回调应避免共享可变状态、锁、阻塞 IO 和依赖调用顺序；`par_unseq` 下还要满足向量化安全要求。先用顺序版本建立正确性与基准，再通过真实数据规模验证并行版本是否获益。部分标准库需要额外并行运行库才能真正并行。
