# C++17：折叠表达式

折叠表达式用一个二元运算符展开模板参数包：

```cpp
template <typename... Args>
auto sum(Args... args) {
    return (args + ...);
}

template <typename... Args>
void print(Args&&... args) {
    (std::cout << ... << args);
}
```

共有一元左折叠、一元右折叠、二元左折叠和二元右折叠。外层括号不能省略，左右方向会影响减法等非结合运算符的结果。

空参数包是否有效取决于运算符或是否提供初始值。
