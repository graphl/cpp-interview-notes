# C++17：折叠表达式

折叠表达式用一个二元运算符展开模板参数包：

```cpp
template <typename... Args>
auto sum(Args... args) {
    return (args + ...);
}

template <typename... Args>
void print(Args&&... args) {
    (std::cout << ... << args);
}
```

共有一元左折叠、一元右折叠、二元左折叠和二元右折叠。外层括号不能省略，左右方向会影响减法等非结合运算符的结果。

空参数包是否有效取决于运算符或是否提供初始值。

## 使用方法

```cpp
#include <iostream>
#include <utility>

template <typename... Args>
auto sum(Args&&... args) {
    return (0 + ... + std::forward<Args>(args)); // 有初值的左折叠
}

template <typename... Args>
void print_line(Args&&... args) {
    (std::cout << ... << std::forward<Args>(args)) << '\n';
}

template <typename... Predicates>
bool all(Predicates... predicates) {
    return (... && predicates);               // 逻辑与展开
}

int main() {
    std::cout << sum(1, 2, 3) << '\n';
    print_line("id=", 7, ", ready=", true);
    std::cout << all(true, true, false) << '\n';
}
```

常用形式包括 `(包 op ...)`、`(... op 包)`、`(初值 op ... op 包)` 和 `(包 op ... op 初值)`。减法、除法和字符串拼接等对结合方向敏感；需要接受空参数包时应提供合适初值。
