# C++17：内联变量

C++17 允许变量使用 `inline`，使变量可以在头文件中定义，并在多个翻译单元中表示同一个实体。

```cpp
class Config {
public:
    inline static const std::string name = "server";
};
```

它解决了许多静态数据成员必须在 `.cpp` 文件中额外提供定义的问题。

`inline` 在这里主要涉及 ODR（单一定义规则），不代表编译器一定把变量“内联”，也不是线程同步机制。

## 使用方法

```cpp
// config.h
#pragma once
#include <string_view>

struct Config {
    inline static int connectionCount = 0;
    inline static constexpr std::string_view name = "server";
};
```

```cpp
// main.cpp
#include "config.h"
#include <iostream>

int main() {
    ++Config::connectionCount;             // 访问并修改同一个静态对象
    std::cout << Config::name << ' '
              << Config::connectionCount << '\n';
}
```

定义可直接放在头文件并被多个 `.cpp` 包含。动态初始化仍要注意跨翻译单元初始化顺序；多个线程修改非原子内联变量仍然需要锁或 `std::atomic`。
