# C++17：保证的复制消除

C++17 在某些纯右值场景中保证直接在目标位置构造结果对象：

```cpp
Widget make_widget() {
    return Widget{};
}

Widget widget = make_widget();
```

这里不要求存在可访问的拷贝或移动构造函数。

但具名返回值优化 NRVO 仍不总是强制：

```cpp
Widget make_widget() {
    Widget widget;
    return widget; // 通常 NRVO，但不是同一种强制保证场景
}
```

因此不要把“C++17 保证复制消除”误解为所有返回对象的代码都绝不会移动。

## 使用方法

```cpp
#include <iostream>

class Token {
public:
    Token() { std::cout << "construct\n"; }
    Token(const Token&) = delete;
    Token(Token&&) = delete;
};

Token make_token() {
    return Token{}; // C++17：直接在调用者的目标位置构造
}

int main() {
    Token token = make_token();
}
```

优先按值返回局部结果，让编译器完成复制消除，不要为了“优化”写 `return std::move(local);`，它可能阻碍 NRVO。保证场景主要是同类型纯右值直接初始化目标；返回具名局部变量属于 NRVO，通常发生但并非强制。
