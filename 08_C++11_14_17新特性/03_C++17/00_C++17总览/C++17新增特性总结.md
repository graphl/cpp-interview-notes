# C++17 新增特性总结

## 1. C++17 的定位

C++17 同时增强了语言表达能力、编译期编程和工程标准库。结构化绑定、`if constexpr`、折叠表达式解决了大量模板样板代码；`optional`、`variant`、`string_view` 和 `filesystem` 则直接改善了工程开发体验。

面试高频特性包括：

1. 结构化绑定；
2. `if constexpr`；
3. `if`、`switch` 初始化语句；
4. 内联变量；
5. 折叠表达式；
6. 类模板参数推导；
7. 保证的复制消除；
8. `optional`、`variant`、`any`、`string_view`、`filesystem`。

---

## 2. 结构化绑定

结构化绑定可以把数组、`pair`、`tuple` 或满足特定协议的对象拆成多个名字：

```cpp
std::pair<int, std::string> item{1, "apple"};
auto [id, name] = item;          // 拷贝
auto& [id_ref, name_ref] = item; // 引用原对象
```

遍历关联容器时非常常用：

```cpp
for (const auto& [key, value] : table) {
    // 使用 key 和 value
}
```

注意 `auto [a, b]` 与 `auto& [a, b]` 的区别：前者通常绑定到一个副本，后者允许修改原对象。

---

## 3. `if` 和 `switch` 初始化语句

C++17 允许在条件之前初始化局部对象，其作用域限制在整个 `if` 或 `switch` 语句中：

```cpp
if (auto it = table.find(key); it != table.end()) {
    use(it->second);
}
```

它可以缩小变量作用域，避免查找结果泄漏到后续代码中。

---

## 4. `if constexpr`

`if constexpr` 根据编译期条件选择分支，未选择的分支不会为当前模板实例进行实例化：

```cpp
#include <type_traits>

template <typename T>
auto length(const T& value) {
    if constexpr (std::is_integral_v<T>) {
        return value;
    } else {
        return value.size();
    }
}
```

普通 `if` 的两个分支都必须是合法代码；`if constexpr` 可以根据类型丢弃不适用的分支，因此特别适合模板编程。

它与 `constexpr` 函数不是同一个概念：

- `constexpr` 函数表示函数可以参与常量表达式求值；
- `if constexpr` 表示在编译期选择代码分支。

---

## 5. 内联变量

C++17 允许变量使用 `inline`：

```cpp
class Config {
public:
    inline static const std::string name = "server";
};
```

内联变量可以在头文件中定义，并允许多个翻译单元出现相同定义，链接后仍表示同一个实体。它解决了许多静态数据成员需要在 `.cpp` 文件中额外提供定义的问题。

`inline` 的关键含义是处理 ODR（单一定义规则），并不保证编译器一定执行内联优化。

---

## 6. 折叠表达式

C++17 可以用一个运算符直接展开参数包：

```cpp
template <typename... Args>
auto sum(Args... args) {
    return (args + ...);
}

template <typename... Args>
void print(Args&&... args) {
    (std::cout << ... << args);
}
```

折叠表达式分为一元左折叠、一元右折叠、二元左折叠和二元右折叠。括号不可省略，折叠方向会影响非结合运算符的结果。

```text
(... op pack)          一元左折叠
(pack op ...)          一元右折叠
(init op ... op pack)  二元左折叠
(pack op ... op init)  二元右折叠
```

---

## 7. 类模板参数推导（CTAD）

C++17 可以根据构造函数实参推导类模板参数：

```cpp
std::pair pair{1, 2.5};       // 推导为 pair<int, double>
std::vector values{1, 2, 3};  // 推导为 vector<int>
```

用户自定义类也可以使用推导指引：

```cpp
template <typename T>
struct Box {
    Box(T value) : value(value) {}
    T value;
};

Box(const char*) -> Box<std::string>;
```

不要把 CTAD 和函数模板实参推导混为一谈：函数模板早就能推导，类模板自动推导是 C++17 引入的。

---

## 8. 保证的复制消除

C++17 对某些纯右值场景保证不创建中间临时对象：

```cpp
Widget make_widget() {
    return Widget{};
}

Widget w = make_widget();
```

在这种场景中，结果对象直接在目标存储位置构造，即使拷贝构造和移动构造被删除也可以成立。

注意：具名返回值优化 NRVO 仍不是强制保证，因为返回的是具名局部变量：

```cpp
Widget make_widget() {
    Widget w;
    return w;  // NRVO 通常发生，但标准并非始终强制
}
```

## 9. 其他语言特性

C++17 还包括：

- 嵌套命名空间简写：`namespace a::b {}`；
- `[[nodiscard]]`、`[[maybe_unused]]`、`[[fallthrough]]`；
- `template <auto N>`：非类型模板参数使用 `auto`；
- `constexpr` Lambda；
- 更严格的表达式求值顺序规则；
- 十六进制浮点字面量；
- `static_assert(condition)` 可省略提示字符串。

```cpp
[[nodiscard]] bool save();

template <auto N>
struct Buffer {
    std::array<char, N> data;
};
```

## 10. `std::optional`

`optional<T>` 表示“可能存在，也可能不存在的一个 `T`”，适合表达查找失败，而不必依赖特殊值或空指针。

```cpp
std::optional<int> find_id(std::string_view name) {
    if (name == "root") return 0;
    return std::nullopt;
}

if (auto id = find_id("root")) {
    use(*id);
}
```

`optional` 不等于错误处理系统：它只能表达有值或无值，不能携带丰富的失败原因。

---

## 11. `std::variant` 和 `std::any`

### `std::variant`

`variant<Ts...>` 是类型安全的联合体，值只能是给定类型集合之一：

```cpp
std::variant<int, std::string> value = "hello";

std::visit([](const auto& item) {
    std::cout << item;
}, value);
```

访问错误类型时，`std::get` 会抛出 `std::bad_variant_access`。

### `std::any`

`any` 可以保存任意满足要求的类型，但取值时必须知道实际类型：

```cpp
std::any value = 42;
int number = std::any_cast<int>(value);
```

选择原则：类型集合已知时优先 `variant`；确实需要开放类型擦除时使用 `any`。

---

## 12. `std::string_view`

`string_view` 是对连续字符序列的非拥有只读视图，通常只保存指针和长度：

```cpp
void parse(std::string_view text);

parse("hello");
parse(std::string{"world"});
```

优点是避免不必要的字符串分配和复制。最大风险是生命周期：`string_view` 不拥有字符数据，原字符串销毁或重新分配后，视图会悬空。

```cpp
std::string_view bad() {
    return std::string("temporary"); // 错误：返回悬空视图
}
```

此外，`string_view` 指向的数据不保证以 `\0` 结尾，不能无条件把 `data()` 传给要求 C 字符串的接口。

---

## 13. 文件系统库

`<filesystem>` 提供跨平台路径和文件系统操作：

```cpp
#include <filesystem>

namespace fs = std::filesystem;

for (const auto& entry : fs::directory_iterator(".")) {
    std::cout << entry.path() << '\n';
}
```

常用类型和操作包括 `path`、`exists`、`file_size`、`create_directories`、`copy`、`rename` 和目录迭代器。

工程中要关注错误处理、符号链接、权限、路径编码和 TOCTOU 竞争，不能把“先检查再操作”当成原子事务。

---

## 14. 其他标准库增强

C++17 还加入或增强了：

- `std::apply`、`std::invoke`；
- `std::make_from_tuple`；
- `std::shared_mutex`、`std::scoped_lock`；
- `std::from_chars`、`std::to_chars`；
- `std::byte`；
- `std::pmr` 多态内存资源；
- `std::clamp`、`std::gcd`、`std::lcm`；
- 容器节点句柄 `extract`、`merge`；
- `map::try_emplace`、`insert_or_assign`；
- 并行算法与执行策略。

```cpp
std::scoped_lock lock(mutex1, mutex2); // 一次锁住多把互斥锁

map.try_emplace(key, constructor_arg); // key 已存在时避免构造 mapped value
```

---

## 15. C++17 面试速答

> C++17 的语言层面重点是结构化绑定、带初始化语句的 `if/switch`、`if constexpr`、内联变量、折叠表达式、类模板参数推导和保证的复制消除；标准库层面重点是 `optional`、`variant`、`any`、`string_view`、`filesystem`、`charconv`、并行算法和新的并发工具。它显著减少了模板样板代码，并补充了工程开发常用组件。
