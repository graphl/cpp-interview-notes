# C++17：类模板参数推导

类模板参数推导（CTAD）允许编译器根据构造实参推导类模板参数：

```cpp
std::pair pair{1, 2.5};       // pair<int, double>
std::vector values{1, 2, 3};  // vector<int>
```

自定义类可以编写推导指引：

```cpp
template <typename T>
struct Box { Box(T); };

Box(const char*) -> Box<std::string>;
```

函数模板早已支持实参推导；类模板自动推导是 C++17 特性。CTAD 推导的是类模板参数，不等于对象声明可以随意省略所有类型信息。
