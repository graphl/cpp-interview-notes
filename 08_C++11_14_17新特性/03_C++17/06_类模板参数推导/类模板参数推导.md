# C++17：类模板参数推导

类模板参数推导（CTAD）允许编译器根据构造实参推导类模板参数：

```cpp
std::pair pair{1, 2.5};       // pair<int, double>
std::vector values{1, 2, 3};  // vector<int>
```

自定义类可以编写推导指引：

```cpp
template <typename T>
struct Box { Box(T); };

Box(const char*) -> Box<std::string>;
```

函数模板早已支持实参推导；类模板自动推导是 C++17 特性。CTAD 推导的是类模板参数，不等于对象声明可以随意省略所有类型信息。

## 使用方法

```cpp
#include <iostream>
#include <string>
#include <utility>
#include <vector>

template <typename T>
struct Box {
    T value;
    explicit Box(T v) : value(std::move(v)) {}
};

Box(const char*) -> Box<std::string>; // 自定义推导指引

int main() {
    std::pair pair{1, 2.5};       // std::pair<int, double>
    std::vector values{1, 2, 3};  // std::vector<int>
    Box text{"hello"};            // Box<std::string>
    std::cout << text.value << '\n';
}
```

对象仍通过构造函数初始化，只是不必重复写模板实参。推导结果不符合接口意图时显式写 `Box<Type>`，或提供推导指引；不要依赖容易受构造函数改动影响的隐式推导作为公共接口约定。
