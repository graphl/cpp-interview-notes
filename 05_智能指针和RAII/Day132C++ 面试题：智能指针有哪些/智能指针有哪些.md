# C++ 面试题：智能指针有哪些

## 1. 核心结论

C++ 标准库常见智能指针有：

1. `std::unique_ptr`
2. `std::shared_ptr`
3. `std::weak_ptr`

旧标准中的 `auto_ptr` 已废弃，不推荐使用。

---

## 2. unique_ptr

独占所有权，不能拷贝，只能移动。

```cpp
std::unique_ptr<int> p = std::make_unique<int>(10);
```

适合一个对象只有一个明确拥有者的场景。

---

## 3. shared_ptr

共享所有权，通过引用计数管理对象生命周期。

```cpp
auto p1 = std::make_shared<int>(10);
auto p2 = p1;
```

当最后一个 `shared_ptr` 被销毁时，对象才会释放。

---

## 4. weak_ptr

弱引用，不增加引用计数，不拥有对象。

```cpp
std::weak_ptr<int> wp = p1;
if (auto sp = wp.lock()) {
    // 对象仍然存在
}
```

主要用于解决 `shared_ptr` 循环引用。

---

## 5. 对比表

| 智能指针 | 所有权 | 可拷贝 | 典型用途 |
|---|---|---|---|
| `unique_ptr` | 独占 | 不可拷贝，可移动 | 单一所有者 |
| `shared_ptr` | 共享 | 可拷贝 | 多个所有者 |
| `weak_ptr` | 不拥有 | 可拷贝 | 观察对象，打破循环引用 |

---

## 6. 面试回答

现代 C++ 常见智能指针有 `unique_ptr`、`shared_ptr` 和 `weak_ptr`。`unique_ptr` 表示独占所有权，不能拷贝；`shared_ptr` 使用引用计数实现共享所有权；`weak_ptr` 不增加引用计数，通常用于观察 `shared_ptr` 管理的对象以及解决循环引用问题。
