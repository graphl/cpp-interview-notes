## 2. 为什么需要 RAII

没有 RAII 时：

```
void foo() {
    FILE* fp = fopen("data.txt", "r");
    if (!fp) return;

    // 逻辑...
    if (error) return; // 可能忘记 fclose(fp)
    
    fclose(fp);
}
```

→ 出错分支很多，容易忘记 `fclose`，资源泄漏。

有 RAII 时：

```
#include <fstream>

void foo() {
    std::ifstream ifs("data.txt");
    if (!ifs) return; // 析构自动关闭文件
    // 逻辑...
} // 作用域结束，自动调用 ~ifstream()，关闭文件
```

→ 不管函数怎么退出，文件一定被正确释放。
