# C++ 面试题：循环引用是什么？如何解决？

## 1. 核心结论

循环引用是指多个对象之间互相持有 `shared_ptr`，导致引用计数永远不能归零，对象无法释放。

解决方法是把其中一方改成 `weak_ptr`。

---

## 2. 错误示例

```cpp
struct B;

struct A {
    std::shared_ptr<B> b;
};

struct B {
    std::shared_ptr<A> a;
};

int main() {
    auto pa = std::make_shared<A>();
    auto pb = std::make_shared<B>();

    pa->b = pb;
    pb->a = pa;
}
```

`pa` 和 `pb` 离开作用域后，两个对象仍然互相引用，引用计数无法变成 0。

---

## 3. 正确写法

```cpp
struct B;

struct A {
    std::shared_ptr<B> b;
};

struct B {
    std::weak_ptr<A> a;
};
```

`weak_ptr` 不增加强引用计数，所以不会阻止对象释放。

---

## 4. 如何判断谁用 weak_ptr？

一般原则：

1. 真正拥有对象的一方用 `shared_ptr`
2. 只是观察或反向引用的一方用 `weak_ptr`
3. 父子关系中，父拥有子，子弱引用父

---

## 5. 面试回答

循环引用是两个或多个对象通过 `shared_ptr` 互相持有，导致引用计数无法归零，最终内存泄漏。解决方法是把不拥有对象的一方改成 `weak_ptr`，因为 `weak_ptr` 不增加强引用计数，不会影响对象释放。
