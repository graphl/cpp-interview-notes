# C++ 模板与泛型编程

模板代码要分清三个时间点：模板定义、模板参数替换、最终实例化。许多难点都来自“当前名字是否依赖模板参数，以及编译器现在能知道多少信息”。

## 推荐学习顺序

```text
函数模板与类模板
  -> 参数推导与实例化
  -> 全特化、偏特化
  -> 依赖名、typename、template 消歧义
  -> SFINAE、enable_if、traits
  -> 可变参数、折叠表达式
  -> CRTP、Concepts
```

## 必会问题

1. 隐式实例化和显式实例化分别发生在何处？
2. 函数模板为什么没有偏特化，通常如何用重载替代？
3. `typename` 什么时候用于告诉编译器“这是一个类型”？
4. SFINAE 为什么只忽略替换阶段的失败？
5. traits 如何把类型信息转成编译期可查询的接口？
6. CRTP 如何实现静态多态，它和虚函数的取舍是什么？

## 待补重点

模板实参推导规则、两阶段查找、依赖名、检测惯用法、折叠表达式、Concepts 与友好的约束诊断。现有主题需要增加更多最小可编译示例。
