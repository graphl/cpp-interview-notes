# 05 资源句柄泄漏

## 1. 类型定义

资源句柄泄漏不一定是直接的堆内存泄漏，但会导致进程资源不断增长，并间接占用内核内存或用户态对象。

常见资源包括：

```text
文件描述符 fd
socket
线程
mutex / condition variable
timer
epoll fd
数据库连接
系统句柄
```

---

## 2. 典型现象

```text
RSS 可能上涨
fd 数量持续上涨
线程数持续上涨
最终报 Too many open files
socket 连接关闭不完整
服务运行越久越慢
```

---

## 3. 典型代码

fd 泄漏：

```cpp
void read_file() {
    int fd = open("test.txt", O_RDONLY);
    if (fd < 0) {
        return;
    }

    // 忘记 close(fd)
}
```

线程泄漏：

```cpp
void start() {
    std::thread t([] {
        // work
    });

    t.detach(); // 如果无退出机制，可能造成线程资源长期存在
}
```

socket 泄漏：

```cpp
int fd = socket(AF_INET, SOCK_STREAM, 0);
// 错误路径忘记 close(fd)
```

---

## 4. 排查方法

查看 fd：

```bash
ls /proc/<pid>/fd | wc -l
lsof -p <pid>
```

查看线程数：

```bash
cat /proc/<pid>/status | grep Threads
ps -T -p <pid>
```

跟踪系统调用：

```bash
strace -f -e trace=open,close,socket,accept,connect ./app
```

看限制：

```bash
ulimit -n
cat /proc/<pid>/limits
```

---

## 5. 修复方式

fd 使用 RAII 封装：

```cpp
class Fd {
public:
    explicit Fd(int fd) : fd_(fd) {}
    ~Fd() {
        if (fd_ >= 0) {
            close(fd_);
        }
    }

    Fd(const Fd&) = delete;
    Fd& operator=(const Fd&) = delete;

private:
    int fd_;
};
```

线程要明确生命周期：

```cpp
std::thread t(worker);
t.join();
```

C++20 可用：

```cpp
std::jthread t(worker);
```

---

## 6. 面试总结

资源句柄泄漏不一定表现为 `new` 出来的内存没释放，但它会导致 fd、socket、线程等资源持续增长。排查时看 `/proc/<pid>/fd`、`lsof`、线程数和系统调用，修复时用 RAII 封装资源生命周期。
