## 🧩 一、常见崩溃类型分类

| 类型                 | 常见错误描述                                     | 原因分析                           | 常见场景              |
| -------------------- | ------------------------------------------------ | ---------------------------------- | --------------------- |
| **空指针访问**       | `0xC0000005: 读取位置 0x00000000 时发生访问冲突` | 对未初始化或已释放指针进行访问     | `p->member`，`*ptr`   |
| **野指针访问**       | 随机崩溃、地址不固定                             | 指针指向无效内存（已释放或未赋值） | `delete` 后继续使用   |
| **数组越界**         | `heap corruption`、`stack smashing`              | 访问数组或容器边界之外的内存       | `arr[10]` 越界        |
| **释放错误**         | `double free`、`invalid free`                    | 对同一内存多次释放或释放非法地址   | `delete` 两次         |
| **未定义行为（UB）** | 随机崩溃或逻辑错乱                               | 对象生命周期结束后访问、类型不匹配 | 返回局部变量引用      |
| **栈溢出**           | `Stack overflow`                                 | 递归过深、分配过大局部数组         | 无限递归函数          |
| **内存泄漏**         | 程序长期运行后占用增长                           | 动态内存未释放                     | `new` 无对应 `delete` |
| **多线程并发问题**   | 数据竞争、死锁、崩溃                             | 未加锁访问共享资源                 | 多线程同时改写指针    |
