## 🔍 四、建议的防护策略

1. **启用编译器安全选项**
   - `-fsanitize=address -g -O1`
   - MSVC: `/fsanitize=address /RTC1 /EHsc`
2. **RAII 管理资源**
   - 用智能指针 (`std::unique_ptr` / `std::shared_ptr`)
   - 避免手动 `new` / `delete`
3. **容器边界检查**
   - 使用 `std::vector::at()` 或启用 `_GLIBCXX_DEBUG`
4. **日志 + Core Dump**
   - 启用 `ulimit -c unlimited`（Linux）
   - 保留崩溃现场以分析
5. **多线程安全设计**
   - 共享资源加锁
   - 避免数据竞争和悬空引用
