  - Linux:

    ```
    gdb ./app core

    ```

  - Windows:
     查看 VS 调试窗口或 `.dmp` 文件（Windbg）。

### 2️⃣ 内存与越界检测工具

| 工具                           | 平台                                 | 功能                       |
| ------------------------------ | ------------------------------------ | -------------------------- |
| **AddressSanitizer (ASan)**    | Linux/macOS/Windows (Clang/GCC/MSVC) | 检测越界、UAF、栈溢出      |
| **Valgrind / Memcheck**        | Linux                                | 检测内存泄漏、越界访问     |
| **Dr.Memory**                  | Windows                              | 类似 Valgrind 的检测工具   |
| **Visual Studio 内存诊断工具** | Windows                              | 内存分析、对象生命周期追踪 |
| **Electric Fence**             | Linux                                | 快速检测越界（简单易用）   |

## ⚙️ 三、常见崩溃模式与解决方案

| 崩溃模式   | 示例代码                                 | 解决方式                         |
| ---------- | ---------------------------------------- | -------------------------------- |
| 空指针访问 | `int *p = nullptr; *p = 1;`              | 使用前判断指针是否为空           |
| 野指针     | `int* p = new int(1); delete p; *p = 2;` | delete 后置空：`p = nullptr;`    |
| 越界访问   | `int arr[3]; arr[3] = 1;`                | 使用 `std::vector` 并调用 `at()` |
| 重复释放   | `delete p; delete p;`                    | 统一内存管理，避免手动释放       |
| 栈溢出     | 无限递归函数调用                         | 限制递归深度或改迭代             |
| 并发崩溃   | 多线程访问同一对象                       | 使用 `mutex` 或 `atomic`         |
