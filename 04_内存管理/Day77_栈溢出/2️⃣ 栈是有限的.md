### 2️⃣ 栈是有限的

栈空间的大小在程序创建线程时就被系统固定下来，比如：

| 操作系统                | 默认栈大小     |
| ----------------------- | -------------- |
| Linux 主线程            | 8 MB           |
| Linux 子线程（pthread） | 8 MB（可配置） |
| Windows 主线程          | 1 MB           |
| Windows 子线程          | 1 MB（可配置） |

栈是连续的线性内存，系统不可能给每个线程无限大的栈，否则很快会耗尽内存。

------

### 3️⃣ 栈溢出的原因

当函数调用层级太深或局部变量太大时，超出系统分配的栈范围，就会覆盖到**不属于栈的内存**，触发 **段错误（Segmentation Fault）** 或 **访问冲突（0xC0000005）**。

#### 常见例子：

**① 递归过深：**

```
void f() { f(); } // 无限递归
int main() { f(); } // 栈空间被函数帧不断消耗，直到爆
```

**② 局部数组过大：**

```
int main() {
    int bigArray[10000000]; // 约 40MB > 栈限制
}
```

**③ 未控制递归栈：**

```
void dfs(int n) {
    int temp[1024]; // 每层都分配 4KB
    if (n) dfs(n-1);
}
```
