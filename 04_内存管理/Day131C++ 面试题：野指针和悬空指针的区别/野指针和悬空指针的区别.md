# C++ 面试题：野指针和悬空指针的区别

## 1. 核心结论

野指针是没有被正确初始化的指针。

悬空指针是曾经指向有效对象，但对象生命周期结束后仍然保存原地址的指针。

---

## 2. 野指针

```cpp
int* p;
*p = 10;  // 错误，p 未初始化
```

`p` 的值不确定，可能指向任意地址。

---

## 3. 悬空指针

```cpp
int* p = new int(10);
delete p;

*p = 20;  // 错误，p 已经悬空
```

`p` 仍保存原来的地址，但那块内存已经被释放。

---

## 4. 对比表

| 对比 | 野指针 | 悬空指针 |
|---|---|---|
| 来源 | 未初始化 | 指向的对象已销毁 |
| 是否曾经有效 | 不一定 | 曾经有效 |
| 危险 | 随机访问非法内存 | use after free |
| 解决 | 初始化为 `nullptr` | 释放后置空 |

---

## 5. 避免方法

```cpp
int* p = nullptr;

p = new int(10);
delete p;
p = nullptr;
```

更推荐：

```cpp
auto p = std::make_unique<int>(10);
```

---

## 6. 面试回答

野指针通常指未初始化或值不确定的指针；悬空指针是指向的对象已经被释放或销毁，但指针仍然保存原地址。两者解引用都会导致未定义行为。避免方式是初始化指针、释放后置空，并尽量使用智能指针管理生命周期。
