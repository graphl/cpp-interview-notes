# C++ 内存管理

本专题需要同时区分三层：原始字节存储、对象生命周期、资源所有权。`malloc/free` 管理存储，`new/delete` 表达式还负责对象构造与析构，RAII 再把释放责任绑定到对象生命周期。

## 推荐学习顺序

```text
进程地址空间与栈/堆
  -> malloc/free 与 new/delete
  -> 对象生命周期、placement new
  -> 对齐、碎片、分配策略
  -> 泄漏、悬空、double free、越界
  -> 内存池与排查工具
```

## 必会问题

1. `new T` 为什么不等于简单调用 `malloc(sizeof(T))`？
2. `delete` 与 `delete[]` 不匹配为什么属于未定义行为？
3. placement new 在现有存储上开始对象生命周期后，谁负责显式析构？
4. 内存对齐影响哪些地址、大小和硬件访问行为？
5. 内部碎片与外部碎片分别来自哪里？
6. 泄漏、悬空指针、越界和 use-after-free 应该用什么证据定位？

## 教学实现边界

手写分配器应明确内存来源、对齐要求、块头格式、分割/合并策略和线程安全范围，不能宣称是生产级 `malloc`。

## 待补重点

简化 malloc/free、`operator new/delete` 重载、数组分配、分配失败策略和 allocator 与容器的关系。
