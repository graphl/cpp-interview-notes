# C++ 面试题：堆和栈的区别

## 1. 核心结论

栈由编译器自动管理，堆通常由程序员手动管理或由智能指针管理。

---

## 2. 对比表

| 对比 | 栈 | 堆 |
|---|---|---|
| 管理方式 | 自动管理 | 手动或 RAII 管理 |
| 分配速度 | 快 | 相对慢 |
| 生命周期 | 作用域结束自动释放 | 主动释放或智能指针释放 |
| 空间大小 | 较小 | 较大 |
| 碎片问题 | 少 | 可能有 |
| 典型对象 | 局部变量 | `new` 出来的对象 |

---

## 3. 示例

```cpp
void func() {
    int a = 10;              // 栈
    int* p = new int(20);    // 堆
    delete p;
}
```

---

## 4. 常见问题

栈上常见问题：

1. 栈溢出
2. 返回局部变量地址

堆上常见问题：

1. 内存泄漏
2. 重复释放
3. use after free

---

## 5. 面试回答

栈内存由编译器自动分配和释放，速度快，但空间较小，生命周期随作用域结束。堆内存由程序员动态申请，空间较大，生命周期灵活，但需要手动释放或用智能指针管理，否则容易出现泄漏、重复释放和悬空指针问题。
