#### **方法 3：继承一个“禁止栈分配”的基类**

```
class HeapOnlyBase {
protected:
    ~HeapOnlyBase() = default;
    HeapOnlyBase() = default;
};

class HeapOnly : private HeapOnlyBase {
public:
    static HeapOnly* create() { return new HeapOnly(); }
private:
    HeapOnly() = default;
};
```

这种写法是把**限制构造和析构访问权限**封装到基类里。
