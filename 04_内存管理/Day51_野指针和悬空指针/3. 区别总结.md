## 区别总结

| 特性       | 悬空指针                                       | 野指针                             |
| ---------- | ---------------------------------------------- | ---------------------------------- |
| 产生原因   | 指向的内存已释放/失效                          | 指针未初始化 / 越界 / 随机地址     |
| 曾经合法性 | 曾经合法 → 现在非法                            | 从未合法过                         |
| 解决办法   | 释放后置 `nullptr`，避免返回局部地址，智能指针 | 定义时初始化为 `nullptr`，边界检查 |
