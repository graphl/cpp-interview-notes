# C++ 面试题：内存对齐是什么

## 1. 核心结论

内存对齐是指变量地址按照其类型要求的边界存放。

目的是提高 CPU 访问效率，有些平台不对齐访问还可能出错。

---

## 2. 示例

```cpp
struct A {
    char c;
    int i;
};
```

`sizeof(A)` 通常不是 5，而可能是 8。

原因是 `int` 通常要求按 4 字节对齐，中间会插入 padding。

---

## 3. 对齐规则

常见规则：

1. 每个成员按自身对齐要求放置
2. 结构体整体大小是最大对齐值的整数倍
3. 成员顺序会影响结构体大小

---

## 4. 优化成员顺序

```cpp
struct A {
    char c;
    int i;
    char d;
};
```

可能占 12 字节。

```cpp
struct B {
    int i;
    char c;
    char d;
};
```

可能占 8 字节。

---

## 5. 面试回答

内存对齐是编译器按照类型对齐要求安排对象地址和结构体成员位置。它会引入填充字节，使 CPU 访问更高效。结构体大小不仅取决于成员大小之和，还受成员顺序和最大对齐值影响。
