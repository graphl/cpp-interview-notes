# 🔹 数据段分类总览

| 区段         | 说明                                               | 示例代码                       |
| ------------ | -------------------------------------------------- | ------------------------------ |
| `.data` 段   | **已初始化**的全局/静态变量                        | `int a = 5;`                   |
| `.bss` 段    | **未初始化**的全局/静态变量，运行时置为 0          | `int b;` 或 `static int x;`    |
| `.rodata` 段 | **只读常量数据区**，如字符串字面值、`const` 常量等 | `const int c = 10;`、`"hello"` |
