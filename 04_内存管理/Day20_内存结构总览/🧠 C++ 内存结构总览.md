# 🧠 C++ 内存结构总览

| 区域                       | 作用                         | 示例                           |
| -------------------------- | ---------------------------- | ------------------------------ |
| **栈（Stack）**            | 局部变量、函数调用、参数传递 | `int a = 10;`                  |
| **堆（Heap）**             | 动态分配内存，需手动释放     | `new int;` / `malloc()`        |
| **静态区（Data Segment）** | 全局变量、静态变量           | `static int x = 0;`            |
| **常量区（ROData）**       | 字符串常量、`const` 常量     | `"Hello"` / `const int a = 5;` |
| **代码区（Text）**         | 程序指令                     | 函数体等                       |
