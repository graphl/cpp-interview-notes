## 2. 推荐复习顺序

第一轮打基础：

```text
01_C++基础语法
  -> 02_类和对象模型
  -> 03_虚函数多态继承
  -> 04_内存管理
  -> 05_智能指针和RAII
```

第二轮刷高频：

```text
06_STL容器和算法
  -> 07_手写实现题
  -> 08_C++11_14_17新特性
  -> 09_异常安全
```

第三轮进阶：

```text
10_多线程并发
  -> 11_模板和泛型编程
  -> 12_编译链接和运行时
  -> 13_Linux后台开发扩展
```

---

## 3. 归类原则

1. 每个 Day 目录只放入一个主分类。
2. 有交叉属性的题目，按最主要的复习场景归类。
3. 手写实现类题目优先放入 `07_手写实现题`。
4. 资源管理思想类题目放入 `05_智能指针和RAII`。
5. 系统、网络、IO、Linux 后端相关题目放入 `13_Linux后台开发扩展`。
