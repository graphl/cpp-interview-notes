# 🎯 变量的作用域（Scope）

| 类型              | 说明                                       |
| ----------------- | ------------------------------------------ |
| 块作用域（local） | 函数体、`{}` 代码块内                      |
| 函数作用域        | 函数参数、函数内局部变量                   |
| 类作用域          | 成员变量、成员函数                         |
| 命名空间作用域    | `namespace` 中定义的变量或函数             |
| 全局作用域        | 整个程序中都可访问（有 extern 还可跨文件） |
