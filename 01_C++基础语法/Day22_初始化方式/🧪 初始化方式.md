# 🧪 初始化方式

| 初始化方式 | 示例         | 说明                                |
| ---------- | ------------ | ----------------------------------- |
| 默认初始化 | `int a;`     | 值不确定（局部变量）                |
| 括号初始化 | `int a(5);`  | 传统方式，适用于内置类型            |
| 等号初始化 | `int a = 5;` | 常见，清晰易读                      |
| 列表初始化 | `int a{5};`  | C++11 起推荐，防止窄化（narrowing） |
| 值初始化   | `int a{};`   | 初始化为 0，安全                    |
