# 🔄 变量的生命周期（Life Cycle）



| 类型             | 存储位置                | 生命周期                                 | 说明                          |
| ---------------- | ----------------------- | ---------------------------------------- | ----------------------------- |
| **局部变量**     | 栈（stack）             | 作用域结束时自动销毁                     | 函数或代码块内                |
| **静态局部变量** | 数据段 `.data` / `.bss` | 程序整个运行期<br />初始化(第一次运行时) | `static` 关键字修饰           |
| **全局变量**     | 数据段                  | 程序整个运行期(main函数之前)             | 定义在函数外                  |
| **动态变量**     | 堆（heap）              | 直到 `delete`                            | 使用 `new` 创建，需要手动释放 |
