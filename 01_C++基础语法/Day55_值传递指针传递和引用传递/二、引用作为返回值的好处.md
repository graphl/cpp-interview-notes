## 二、引用作为返回值的好处

### 1. 支持链式调用

```
int& element(std::vector<int>& v, size_t i) {
    return v[i];
}

std::vector<int> vec = {1, 2, 3};
element(vec, 1) = 42; // 直接修改 vec[1]
```

返回引用后可以直接赋值，否则如果返回值是拷贝，就无法修改原始容器。

------

### 2. 避免拷贝，提高效率

```
std::string& getName(Person& p) {
    return p.name;
}
```

- 返回引用 → 避免一次拷贝。
- 如果返回值是对象，会再调用拷贝构造函数。

------

### 3. 配合运算符重载

许多运算符重载需要返回引用：

```
int& operator[](size_t idx) {
    return data[idx];
}
```

这样才能支持：

```
arr[3] = 100;  // 修改原始数组
```
