# 📌 参数传递方式对比

| 方式             | 写法                 | 是否拷贝 | 是否能修改实参     | 可读性    | 典型用途                             |
| ---------------- | -------------------- | -------- | ------------------ | --------- | ------------------------------------ |
| **值传递**       | `void f(T x)`        | ✅ 会拷贝 | ❌ 不行             | ⭐⭐⭐ 易懂  | 小对象（int、double）传递            |
| **指针传递**     | `void f(T* p)`       | ❌ 不拷贝 | ✅ 可以（需解引用） | ⭐⭐ 稍复杂 | C 风格接口，参数可选（传 `nullptr`） |
| **引用传递**     | `void f(T& r)`       | ❌ 不拷贝 | ✅ 可以             | ⭐⭐⭐⭐ 直观 | 需要修改实参，C++ 推荐方式           |
| **常量引用传递** | `void f(const T& r)` | ❌ 不拷贝 | ❌ 不行             | ⭐⭐⭐⭐ 清晰 | 大对象只读传参，避免拷贝             |
