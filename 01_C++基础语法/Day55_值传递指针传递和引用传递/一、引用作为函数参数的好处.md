## 一、引用作为函数参数的好处

### 1. 避免拷贝，提高效率

如果参数是一个大对象（如 `std::string`, `std::vector`），用值传递会调用拷贝构造函数，开销大。
 用引用传递就能避免拷贝。

```
void print(const std::string& s) {   // 按引用传递
    std::cout << s << std::endl;
}
```

- 如果用 `void print(std::string s)`，调用时会复制一份字符串，浪费性能。
- `const std::string&` 传递更高效，同时保证不会修改内容。

### 2. 允许修改实参

如果需要在函数里修改外部变量，必须使用引用或指针：

```
void addOne(int& x) {
    x += 1;
}
```

调用：

```
int a = 10;
addOne(a);
std::cout << a; // 输出 11
```

------

### 3. 接口更直观

引用语义比指针更清晰：

- `f(int* p)`：调用时要写 `&a`，调用者要意识到是地址。
- `f(int& r)`：调用时直接写 `a`，更自然。
