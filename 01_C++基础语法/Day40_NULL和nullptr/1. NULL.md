1. ## 1. **NULL**

   - 定义：宏，一般在 `<cstddef>` 或 `<stddef.h>` 里定义：

     ```
     #define NULL 0       // 在C++
     #define NULL ((void*)0) // 在C
     ```

   - 在 **C++** 中，`NULL` 本质就是 **整型常量 `0`**。

   - 所以在函数重载时可能引起二义性：

     ```
     void f(int);
     void f(char*);
     
     f(NULL);   // 调用 f(int)，不是 f(char*)
     ```
