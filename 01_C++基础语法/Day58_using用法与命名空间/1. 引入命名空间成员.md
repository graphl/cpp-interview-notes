### 1. **引入命名空间成员**

```
using namespace std;      // 引入整个 std 命名空间
using std::cout;          // 只引入 cout
```

### 2. **类型别名**

和 `typedef` 类似，不过 `using` 更直观，支持模板别名。

```
typedef unsigned int uint1;    // C 风格
using uint2 = unsigned int;    // C++11 起推荐

template<typename T>
using vec = std::vector<T>;    // 模板别名
vec<int> v;                    // 相当于 std::vector<int>
```

### 3. **继承时改变基类成员的可见性**

```
struct Base {
    void f(int) {}
protected:
    int x;
};

struct Derived : Base {
    using Base::f;  // 让 Base::f 在 Derived 中可见（避免被隐藏）
    using Base::x;  // 改变成员可见性（受保护 → public）
};
```

### 4. **声明类型别名模板**

```
template <typename T>
using Ptr = T*;

Ptr<int> p; // 相当于 int*
```
