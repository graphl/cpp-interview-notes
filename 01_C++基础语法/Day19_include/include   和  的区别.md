# include " " 和 <> 的区别

| 用法       | 语法                  | 查找路径                               | 通常用途                       |
| ---------- | --------------------- | -------------------------------------- | ------------------------------ |
| 双引号包含 | `#include "filename"` | 先从**当前目录**查找，再从系统目录查找 | 引入**自己写的头文件**         |
| 尖括号包含 | `#include <filename>` | 只从**系统路径**查找                   | 引入**标准库或第三方库**头文件 |
