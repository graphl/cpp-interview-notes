 **指针加减运算时移动的字节数，等于所指类型的大小 (`sizeof(T)`)。**

##  基本规则

假设 `T* p;`

- `p + 1` 的意思不是地址加 1 字节，而是 **加 `sizeof(T)` 字节**。
- `p + n` 就是地址加 `n * sizeof(T)`。
- `p2 - p1`（两个同类型指针相减）得到的结果是 **元素个数差**，而不是字节数差。

##  常见情况对比

| 类型             | `sizeof(T)` | `p+1` 实际跨距 |
| ---------------- | ----------- | -------------- |
| `char*`          | 1           | +1 字节        |
| `int*`           | 4           | +4 字节        |
| `double*`        | 8           | +8 字节        |
| `struct S{...}*` | `sizeof(S)` | +结构体大小    |

##  指针减法

```
int arr[10];
int* p1 = &arr[2];
int* p2 = &arr[7];

cout << (p2 - p1) << endl; // 输出 5
```

`p2 - p1` 的结果 = 元素个数差 = `5`，而不是字节差。
 如果要得到字节差，需转成 `char*` 再减。
