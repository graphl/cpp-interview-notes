 # 常见 C++ 调用约定对比表（Windows）

| 名称          | 关键词         | 参数压栈顺序  | 清理栈的责任人 | 可变参数 | 参数传递       | 名字修饰                       | 应用场景                           |
| ------------- | -------------- | ------------- | -------------- | -------- | -------------- | ------------------------------ | ---------------------------------- |
| C Declaration | `__cdecl`      | 右→左         | **调用者**     | ✅ 支持   | 栈             | `_func`                        | 默认，适用于通用 C/C++ 函数        |
| Standard Call | `__stdcall`    | 右→左         | **被调用者**   | ❌ 不支持 | 栈             | `_func@N`                      | Windows API，DLL导出函数           |
| Fast Call     | `__fastcall`   | 寄存器+右→左  | **被调用者**   | ❌ 不支持 | ECX, EDX→栈    | `@func@N`                      | 性能优化，微软专用（MSVC）         |
| This Call     | `__thiscall`   | 类似 fastcall | **被调用者**   | ❌ 不支持 | ECX(this) + 栈 | MSVC特定，不修饰或装饰方式不同 | C++ 成员函数（默认）               |
| Vector Call   | `__vectorcall` | 寄存器+右→左  | **被调用者**   | ❌ 不支持 | SIMD/寄存器    | `_vectorcall_func@N`           | C++ 性能优化，支持 SIMD 参数传递   |
| Naked         | `__naked`      | 自定义        | 无             | 自管理   | 你控制         | 无                             | 写内联汇编时禁用函数 prolog/epilog |
