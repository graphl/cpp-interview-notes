# Day164 C++ 面试题：extern 关键字的作用

## 1. 面试主要考哪几方面？

这道题面试一般会围绕下面几个点展开：

1. extern 关键字的作用 的核心结论
2. 语法含义
3. 使用场景
4. 和相近关键字的区别
5. 常见误区

核心一句话：

extern 用来声明变量或函数在别处定义，也常用于指定 C 语言链接方式。

---

## 2. 面试题总结

### 2.1 这个题的核心结论是什么？

extern 用来声明变量或函数在别处定义，也常用于指定 C 语言链接方式。

面试回答：

回答这类题时，先给结论，再补充底层原因和使用场景。不要只说概念，要说明它在 C++ 对象模型、资源管理、编译期机制或并发场景中解决了什么问题。

---

### 2.2 面试官想听到哪些关键词？

1. extern 声明不分配存储空间
2. 全局变量可以在一个文件定义、多个文件声明
3. extern "C" 用来避免 C++ name mangling

面试回答：

可以按“定义 -> 原理 -> 场景 -> 坑点”的顺序回答。先说明它是什么，再说明为什么需要它，最后结合实际开发中容易出错的地方收尾。

---

### 2.3 实际开发中要注意什么？

实际开发中要结合类型安全、作用域、对象生命周期和可维护性来回答。

需要特别注意：

1. 不要只背结论，要能说出背后的原因
2. 要能和相近概念做对比
3. 要能说明错误使用会导致什么问题

---

## 3. 高频追问

### 3.1 面试官为什么喜欢问这个？

因为这个题能看出你是否真正理解 C++ 的底层语义，而不是只会使用语法。尤其是涉及对象生命周期、内存管理、并发、模板或链接过程时，面试官通常会继续追问底层原因。

---

### 3.2 它和相近概念怎么区分？

区分时不要只看表面写法，要看它解决的问题和发生的阶段。

重点可以围绕：

1. extern 声明不分配存储空间
2. 全局变量可以在一个文件定义、多个文件声明
3. extern "C" 用来避免 C++ name mangling

---

### 3.3 常见坑是什么？

不要只背语法，要说明它解决什么问题，以及滥用时会带来什么风险。

面试中如果能主动说出这个坑点，会比只背定义更像真实写过 C++ 项目。

---

## 4. 最终背诵版

extern 用来声明变量或函数在别处定义，也常用于指定 C 语言链接方式。

面试时可以这样答：这个问题首先要看它的核心语义，其次要看底层机制和实际使用场景。关键点包括：extern 声明不分配存储空间；全局变量可以在一个文件定义、多个文件声明；extern "C" 用来避免 C++ name mangling。实际开发中还要注意相关坑点，避免因为理解不清导致资源泄漏、对象生命周期错误、编译链接错误或并发安全问题。
