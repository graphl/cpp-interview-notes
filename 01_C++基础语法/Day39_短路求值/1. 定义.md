### 1. 定义

**短路求值**是指在布尔运算时，一旦能确定整个表达式的结果，就不再继续计算剩下的部分。

常见于逻辑运算符：

- `&&`（逻辑与）
- `||`（逻辑或）

### 2. 逻辑与 `&&`

规则：**只要有一个是 `false`，整个结果就是 `false`**。

- 如果左边为 `false`，右边就不会再计算（因为结果一定是 `false`）。

例子：

```
int a = 0;
if (a != 0 && 10 / a > 1) {
    // 不会执行到 10 / a，避免了除零错误
}
```

### 3. 逻辑或 `||`

规则：**只要有一个是 `true`，整个结果就是 `true`**。

- 如果左边为 `true`，右边就不会再计算（因为结果一定是 `true`）。

例子：

```
int a = 0;
if (a == 0 || 10 / a > 1) {
    // 由于 a == 0 为 true，右边不会执行，不会出错
}
```

------

### 4. 好处

**提高效率**：减少不必要的计算。

**避免错误**：常用于避免除零、空指针解引用等危险操作。

### 5. 总结口诀

- `A && B` → 如果 `A` 假，B 不算。
- `A || B` → 如果 `A` 真，B 不算。
