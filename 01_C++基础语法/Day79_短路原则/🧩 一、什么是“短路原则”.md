## 🧩 一、什么是“短路原则”

> **短路原则（short-circuit evaluation）**：
>  当使用逻辑运算符 `&&` 或 `||` 时，如果**第一个表达式的结果**已经足以确定整个表达式的真假，
>  那么 **第二个表达式将不会被求值**。

------

## ⚙️ 二、逻辑运算符与短路行为

| 运算符         | 运算规则                               | 短路条件              | 举例                                 |
| -------------- | -------------------------------------- | --------------------- | ------------------------------------ |
| `&&`（逻辑与） | 若左操作数为 `false`，结果必为 `false` | 左边为 `false` 时短路 | `false && (任意)` → 不再计算右边     |
| `              |                                        | `（逻辑或）           | 若左操作数为 `true`，结果必为 `true` |

------

### ✅ 示例 1：`&&` 短路

```
int a = 0;
if (a != 0 && (10 / a > 1)) {
    // ...
}
```

> 由于 `a != 0` 为 `false`，第二个表达式 `(10 / a)` 不会执行，
>  否则会出现除零错误。
>
> ✔️ 这就是短路的保护作用。

------

### ✅ 示例 2：`||` 短路

```
bool checkA() { std::cout << "A\n"; return true; }
bool checkB() { std::cout << "B\n"; return false; }

int main() {
    if (checkA() || checkB()) {}
}
```

输出：

```
A
```

因为 `checkA()` 返回 true，`checkB()` 根本不会执行。
