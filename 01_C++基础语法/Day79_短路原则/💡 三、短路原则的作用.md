## 💡 短路原则的作用

### 1️⃣ **防止不必要的计算**

- 避免右侧复杂运算，提高性能。

### 2️⃣ **防止异常/错误**

- 常用于防止访问空指针、除零等。

```
if (ptr && ptr->valid()) { ... } // ptr 为空时不会访问右边
```

### 3️⃣ **控制副作用的执行**

- 若右侧表达式有副作用（如自增、函数调用），可能不会被执行。

## 🧩 短路与求值顺序

在 `a && b` 和 `a || b` 中：

- **左侧表达式先求值**
- 如果不短路，再求右侧
- C++17 开始正式保证：
   左侧表达式一定**先于右侧执行**

## ⚙️复合表达式中的短路示例

```
if (x > 0 && (y / x > 2)) {
    // 只有当 x>0 时才会执行除法
}
```

或者：

```
if ((ptr != nullptr) && (ptr->data > 0)) {
    // 安全访问
}
```

✅ 典型的短路防护写法。
