## 🧩 四、典型应用场景

### ✅ 1. 节省存储空间

```
struct Status {
    unsigned is_ready  : 1;
    unsigned has_error : 1;
    unsigned retry_cnt : 3;
};
```

> 仅占用一个字节，而不是三个独立的 `int`。

------

### ✅ 2. 硬件寄存器映射

在嵌入式系统中非常常见：

```
struct GPIO {
    unsigned MODE : 2;
    unsigned PULL : 2;
    unsigned SPEED : 2;
    unsigned OUTPUT : 1;
    unsigned INPUT : 1;
};
```

这样可以直接通过结构体操作硬件寄存器的各个位。

------

### ✅ 3. 协议或数据包的位定义

比如 TCP 报文首部中的 flag 字段：

```
struct TCPFlag {
    unsigned FIN : 1;
    unsigned SYN : 1;
    unsigned RST : 1;
    unsigned PSH : 1;
    unsigned ACK : 1;
    unsigned URG : 1;
};
```
