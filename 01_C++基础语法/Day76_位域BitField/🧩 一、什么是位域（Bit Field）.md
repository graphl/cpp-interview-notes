## 🧩 一、什么是位域（Bit Field）

**位域** 是一种允许在结构体中按“位（bit）”而不是按“字节（byte）”来定义成员的机制，用于节省存储空间或映射硬件寄存器。

```
struct Flags {
    unsigned int a : 1;  // 占 1 bit
    unsigned int b : 3;  // 占 3 bits
    unsigned int c : 4;  // 占 4 bits
};
```

这段定义的结构体总共占用 `8 bits = 1 byte`（具体取决于编译器对齐方式），每个成员不是独立的字节，而是 **共享同一个整数的部分位。**

## 🧠 二、语法说明

| 项目     | 含义                                                         |
| -------- | ------------------------------------------------------------ |
| **类型** | 通常为 `unsigned int`、`signed int`、`int`（也可以是 `bool`、`char`，但不同编译器实现不同） |
| **名称** | 位域成员名                                                   |
| **宽度** | 冒号 `:` 后的数字，表示占用的二进制位数                      |

例如：

```
struct S {
    unsigned int a : 2;  // 0~3
    unsigned int b : 5;  // 0~31
};
```
