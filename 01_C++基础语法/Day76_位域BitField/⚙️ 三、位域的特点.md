## ⚙️ 三、位域的特点

1. **不能取地址**

   ```
   S s;
   &s.a;  // ❌ 错误：位域成员没有独立地址
   ```

2. **宽度不能超过类型大小**

   ```
   unsigned int x : 40; // ❌ 超过 32 位（unsigned int）
   ```

3. **内存对齐与填充**

   - 同一类型的连续位域可能会共用同一个字。
   - 不同类型之间，编译器可能自动对齐到下一个边界。

   ```
   struct A {
       unsigned a : 3;
       unsigned b : 5; // 与 a 共享同一字节
       unsigned c : 10; // 可能会被放到下一字节
   };
   ```

4. **可以使用无名位域来跳过或填充对齐位**

   ```
   struct Reg {
       unsigned mode : 3;
       unsigned : 2;   // 跳过 2 位
       unsigned flag : 3;
   };
   ```
