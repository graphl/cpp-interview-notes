## 1. 格式划分

一个 `float` 的 32 位被分为三部分：

| 部分                        | 位数    | 作用                                                         |
| --------------------------- | ------- | ------------------------------------------------------------ |
| 符号位（Sign）              | 1 bit   | 表示正负，0 = 正，1 = 负                                     |
| 指数位（Exponent）          | 8 bits  | 用“偏移量表示法”（Bias）存储指数                             |
| 尾数位（Mantissa/Fraction） | 23 bits | 存储有效数字的小数部分（二进制），最高位的 1 被省略（隐藏位） |

## 2. 计算公式

浮点数的值由公式给出：

Value=(−1)sign×(1.mantissa)×2exponent−bias\text{Value} = (-1)^{sign} \times (1.\text{mantissa}) \times 2^{exponent - bias}Value=(−1)sign×(1.mantissa)×2exponent−bias

- `sign`：0 表示正数，1 表示负数
- `exponent`：存储的 8 位指数值
- `bias`（偏移量）：单精度是 **127**
- `mantissa`：23 位二进制小数，前面有一个默认的 `1.`（除非是非正规数）
