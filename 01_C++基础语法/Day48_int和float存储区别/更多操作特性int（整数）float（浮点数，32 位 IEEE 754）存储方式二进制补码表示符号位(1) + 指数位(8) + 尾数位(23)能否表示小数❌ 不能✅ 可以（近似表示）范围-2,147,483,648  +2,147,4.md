| 特性             | `int`（整数）                           | `float`（浮点数，32 位 IEEE 754）  |
| ---------------- | --------------------------------------- | ---------------------------------- |
| **存储方式**     | 二进制补码表示                          | 符号位(1) + 指数位(8) + 尾数位(23) |
| **能否表示小数** | ❌ 不能                                  | ✅ 可以（近似表示）                 |
| **范围**         | -2,147,483,648 ~ +2,147,483,647 (32 位) | 大约 ±3.4 × 10^38                  |
| **精度**         | 精确表示整数                            | 大约 7 位十进制有效数字（有误差）  |
| **内存占用**     | 4 字节                                  | 4 字节                             |
| **除法行为**     | 整除，例如 5 / 2 = 2                    | 真除法，例如 5.0 / 2.0 = 2.5       |
| **溢出**         | 溢出后回绕（模 2^32）                   | 溢出变为 +∞ 或 -∞                  |
| **特殊值**       | 无                                      | NaN（非数）、+∞、-∞、非正规数      |
