# C++ 基础语法

这个专题不是语法字典，而是后续对象模型、模板和并发的共同前置知识。学习重点是理解一段表达式在编译期如何完成类型检查，以及它在运行期读写了什么对象。

## 推荐学习顺序

```text
声明与定义、作用域、生命周期
  -> const、static、extern、inline
  -> 指针、引用、void*、this
  -> 初始化、隐式转换、explicit
  -> 重载、名字改编、调用约定
  -> sizeof、对齐、整数提升、短路求值
```

## 必会问题

1. 声明和定义、作用域和生命周期分别约束什么？
2. 指针与引用在可空性、重新绑定和语法上的区别是什么？
3. 顶层 `const` 与底层 `const` 如何影响传参和重载？
4. `explicit` 阻止哪类隐式转换？`explicit operator bool` 有什么特殊用途？
5. `sizeof` 计算的是类型还是对象内容？为什么空类仍需唯一地址？
6. 宏、`const`、`constexpr` 和 `inline` 的边界分别是什么？

## 阅读时要警惕

- `volatile` 不是线程同步工具，不能替代原子变量和锁。
- `inline` 不保证编译器一定内联，它还影响多定义规则。
- 引用通常由地址实现，但标准语义不是“不可为空的指针”。
- 浮点数比较、整数溢出和有符号/无符号混算需要单独检查。
