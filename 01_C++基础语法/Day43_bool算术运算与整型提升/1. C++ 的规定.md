## 1. C++ 的规定

在 C++ 中，`bool` 是一个整型（integer type），只有两个取值：`true` / `false`。

当 `bool` 参与算术运算时，会发生 **整型提升 (integer promotion)**：

- `false` 会转换成 `0`
- `true` 会转换成 `1`

所以：

```
bool a = true;
bool b = false;
auto c = a + b;  // c == 1
```

## 2. 结果的数据类型

按照标准：

- `bool` 在算术运算中会被提升为 `int`。
- 因此 `a + b` 的结果类型是 **int**。

在 C++ 里，两个 `bool` 相加时，会先提升为 `int`，最终结果的类型是 **int**。
