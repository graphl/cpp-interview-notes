# explicit 

| 项目                   | 说明                         | 使用场景               | 例子                        | 是否支持隐式调用             |
| ---------------------- | ---------------------------- | ---------------------- | --------------------------- | ---------------------------- |
| `explicit` 构造函数    | 防止单参数构造函数被隐式调用 | 避免不小心自动类型转换 | `explicit A(int x);`        | ❌                            |
| 非 `explicit` 构造函数 | 允许隐式类型转换             | 类型转换便捷但易误用   | `A(int x);`                 | ✅                            |
| `explicit operator`    | 防止类型转换操作符被隐式调用 | 控制类型转换安全       | `explicit operator bool();` | ❌（但 if/while/switch 支持） |
