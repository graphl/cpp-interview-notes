# 引用 vs 指针全对比

| 特性                          | 引用（Reference）                  | 指针（Pointer）               |
| ----------------------------- | ---------------------------------- | ----------------------------- |
| 是否必须初始化                | ✅ 是，声明时必须初始化             | ❌ 否，可以延迟或为 `nullptr`  |
| 是否可为空                    | ❌ 理论上不能为 null                | ✅ 可以为 `nullptr`            |
| 是否可以重新指向别的对象      | ❌ 一旦绑定不能更改                 | ✅ 可以随时改指向              |
| 是否是一个变量                | ❌ 不是变量，没有独立内存           | ✅ 是变量，独立存在            |
| 是否需要解引用访问            | ❌ 不需要，用引用名就能访问原对象   | ✅ 需要 `*` 运算符             |
| 是否支持运算（偏移/加减）     | ❌ 不支持任何运算                   | ✅ 可以指针加减，遍历数组      |
| 是否可以组成数组              | ❌ 不行（不能写 `int& arr[10]`）    | ✅ 可以（`int* arr[10]` 合法） |
| 是否可用于函数参数            | ✅ 常用于函数传引用                 | ✅ 可传地址，也用于动态内存    |
| 是否影响 `is_standard_layout` | ✅ 会，引用类型不能是标准布局结构体 | ✅ 指针可以出现在标准布局中    |
