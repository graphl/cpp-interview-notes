 # static 总结对比表：

| 用法位置            | 作用                       | 生命周期         | 作用域         |
| ------------------- | -------------------------- | ---------------- | -------------- |
| 函数内变量          | 保留值，避免重复初始化     | 程序整个生命周期 | 当前函数       |
| 类中成员            | 类共享，不属于任何对象     | 程序整个生命周期 | 类作用域       |
| 函数/变量前（全局） | 仅当前文件可见（内部链接） | 程序整个生命周期 | 当前 .cpp 文件 |

| 比较项         | 声明                        | 定义                           |
| -------------- | --------------------------- | ------------------------------ |
| 是否分配内存   | ❌ 否                        | ✅ 是                           |
| 是否可多次出现 | ✅ 是                        | ❌ 否（一次）                   |
| 常见关键字     | `extern`, `class`, `struct` | 没有特别关键字，带实现内容即可 |
| 存放位置       | 通常在头文件 `.h`           | 通常在源文件 `.cpp`            |
