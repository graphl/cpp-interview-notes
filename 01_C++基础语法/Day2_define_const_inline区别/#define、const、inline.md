# #define、const、inline

| 特性       | `#define`        | `const`            | `inline`         |
| ---------- | ---------------- | ------------------ | ---------------- |
| 替换时机   | 预处理阶段       | 编译阶段           | 编译阶段         |
| 类型安全   | ❌ 无             | ✅ 有               | ✅ 有             |
| 调试支持   | ❌ 无             | ✅ 可查看           | ✅ 可查看         |
| 作用域控制 | ❌ 无（全局展开） | ✅ 有               | ✅ 有             |
| 替代建议   | ⚠️ 尽量少用       | ✅ 建议用于常量定义 | ✅ 替代宏函数更合 |

inline:  这就是“替换”的结果，但**不是文本替换，而是语义级的、类型安全的编译替换**。
