# **函数重写（Override）**、**函数重载（Overload）** 和 **函数隐藏（Hide）**

| 特性       | 重写（Override）              | 重载（Overload）                   | 隐藏（Hiding）                                               |
| ---------- | ----------------------------- | ---------------------------------- | ------------------------------------------------------------ |
| 发生位置   | 子类覆盖父类的虚函数          | 同一作用域中函数名相同，参数不同   | 子类中定义了一个与父类同名的函数，<br />会**隐藏**父类中所有同名函数（无论参数是否一样) |
| 参数列表   | 必须完全一致                  | 必须不同（参数类型或个数）         | 可以相同，也可以不同                                         |
| 关键字     | `virtual`、`override`（推荐） | 无特殊关键字                       | 无特殊关键字                                                 |
| 是否是多态 | ✅ 是                          | ❌ 否                               | ❌ 否                                                         |
| 主要用途   | 实现多态                      | 接口重载，使用同一函数名的多种实现 | 意外地隐藏父类版本，需要小心                                 |
