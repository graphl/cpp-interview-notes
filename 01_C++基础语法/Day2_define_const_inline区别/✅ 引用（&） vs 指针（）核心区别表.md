# ✅ 引用（`&`） vs 指针（`*`）核心区别表

| 特性                 | 引用（Reference）              | 指针（Pointer）          |
| -------------------- | ------------------------------ | ------------------------ |
| 是否必须初始化       | ✅ 是，声明时必须初始化         | ❌ 否，可以为 `nullptr`   |
| 是否可以为 null      | ❌ 不行（理论上）               | ✅ 可以                   |
| 是否可以改变绑定对象 | ❌ 一旦绑定就不可变             | ✅ 指向谁都可以随时改     |
| 是否需要解引用       | ❌ 不需要 `*`                   | ✅ 需要 `*p` 才能访问内容 |
| 是否支持运算         | ❌ 不支持运算                   | ✅ 可以做加减、偏移等运算 |
| 实现方式（底层）     | 通常是指针的语法糖（隐式指针） | 显式指针                 |
| 是否有对象           | ✅ 引用本身不是对象             | ✅ 指针本身是一个对象     |
| 是否可以组成数组     | ❌ 不行                         | ✅ 可以 `int* arr[5];`    |
