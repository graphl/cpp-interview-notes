# new、delete和malloc、free的差别

| 特性              | `new / delete`（C++）       | `malloc / free`（C）      |
| ----------------- | --------------------------- | ------------------------- |
| 所属语言          | C++                         | C                         |
| 内存分配方式      | 操作符（可重载）            | 函数                      |
| 返回类型          | 类型安全（自动推导）        | `void*`（需强制类型转换） |
| 构造/析构函数调用 | ✅ 会自动调用                | ❌ 不会调用构造/析构       |
| 分配失败行为      | 抛出异常 `std::bad_alloc`   | 返回 `NULL`               |
| 支持重载          | ✅ 可重载 `operator new`     | ❌ 不支持                  |
| 初始化行为        | 可以带参数直接初始化        | 不做初始化                |
| 配对释放方式      | `delete` 或 `delete[]`      | `free()`                  |
| 使用推荐程度      | 推荐（现代 C++ 用智能指针） | 尽量避免直接使用          |
