# 一图看懂： 

| 特性/区别点      | `enum`（传统枚举）       | `enum class`（强类型枚举）           |
| ---------------- | ------------------------ | ------------------------------------ |
| **作用域**       | 枚举成员暴露在外围作用域 | 枚举成员限定在枚举类型作用域内       |
| **类型安全**     | 可隐式转换为整型         | 必须显式转换，类型更安全             |
| **可比较性**     | 不同 enum 类型可比较     | 不同 enum 类型不可比较               |
| **与整数混用**   | 可直接用于整数运算       | 不能直接参与运算，需强转             |
| **用作标志位**   | 可以位或运算             | 不直接支持位操作（需重载）           |
| **底层类型指定** | 默认 int，但不可自定义   | 可以指定（如 `: char`, `: uint8_t`） |
| **前向声明支持** | ❌ 不支持                 | ✅ 支持                               |
| **语法复杂度**   | 简单                     | 稍复杂，但更安全                     |
| **switch 用法**  | ✅ 可用                   | ✅ 可用（但需要 `Color::Red`）        |
