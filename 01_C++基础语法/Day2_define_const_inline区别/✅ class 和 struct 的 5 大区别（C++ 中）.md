# ✅ `class` 和 `struct` 的 5 大区别（C++ 中）

| 对比项                 | `struct`（结构体）     | `class`（类）          |
| ---------------------- | ---------------------- | ---------------------- |
| **默认成员权限**       | `public`               | `private`              |
| **默认继承权限**       | `public`               | `private`              |
| **语义/使用习惯**      | 通常表示 POD 数据结构  | 通常表示具有行为的对象 |
| **兼容 C 语言 struct** | ✅ 是                   | ❌ 否                   |
| **成员函数支持**       | ✅ 有完整的成员函数支持 | ✅ 一样                 |

## POS数据结构

| 条件     | POD 要求                         |
| -------- | -------------------------------- |
| 构造函数 | 没有用户自定义构造函数           |
| 析构函数 | 没有用户自定义析构函数           |
| 成员函数 | 没有虚函数                       |
| 成员变量 | 只包含 POD 成员（int、float 等） |
| 继承关系 | 没有继承                         |
| 访问控制 | 所有成员同一权限（如都 public）  |
