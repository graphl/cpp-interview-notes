# ✅ 一、定义（Definition）和声明（Declaration）是什么？

| 项目         | **声明 Declaration**                  | **定义 Definition**                                          |
| ------------ | ------------------------------------- | ------------------------------------------------------------ |
| 含义         | 告诉编译器“这个名字存在”，不分配内存  | **创建实体本身**（变量/函数/类），会分配内存等               |
| 是否分配内存 | ❌ 否                                  | ✅ 是                                                         |
| 常见关键字   | `extern`, `class`, `struct`           | 没有特别关键字，带实现内容即可                               |
| 是否唯一     | ✅ 可多次（在不同地方引用）            | ✅ 每个实体只能有 **一次定义**                                |
| 示例         | `extern int x;``class A;``int foo();` | `int x = 5;``class A {};``int foo() {}`                      |
| 存放位置     | 通常在头文件 `.h`                     | 通常在源文件 `.cpp` ( 如果放在头文件中，引用头文件的地方都会产生一份备份) |
