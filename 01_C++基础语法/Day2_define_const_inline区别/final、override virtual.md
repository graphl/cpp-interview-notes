# final、override、virtual

| **关键字** | **适用对象** | **作用**                         | **备注/限制**                                                |
| ---------- | ------------ | -------------------------------- | ------------------------------------------------------------ |
| `virtual`  | 成员函数     | 表示此函数为虚函数，可被子类重写 | 非静态成员函数才能为虚函数                                   |
| `override` | 成员函数     | 表示这是对父类虚函数的重写       | 编译器检查是否真的在重写（防止拼写错误）                     |
| `final`    | 成员函数     | 表示此虚函数不能再被重写         | 只能用于虚函数，与 `override` 可组合使用<br /><br />void func() override final; // 合法组合：重写 + 禁止再重写 |
| `final`    | 类           | 表示此类不能被继承               | 类层级终结，常用于安全封闭设计<br />class B : public A final {}; ❌错误语法：final 放在类声明后<br />class B final : public A {}; ✅ |
