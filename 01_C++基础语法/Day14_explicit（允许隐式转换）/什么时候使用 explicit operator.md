# 什么时候使用 `explicit operator`

| 场景                                         | 是否建议加 `explicit` |
| -------------------------------------------- | --------------------- |
| 类转换为 `bool`，用于判断                    | ✅ 建议                |
| 不希望该类型自动参与任何算术/逻辑运算        | ✅ 建议                |
| 有多种类型转换需求时（比如 `int`, `double`） | ✅ 更加推荐            |
| 需要与 legacy 代码兼容（C++98）              | ⛔ 不能用              |
