#  this 指针的 3 个关键点

| 特性             | 说明                                                  |
| ---------------- | ----------------------------------------------------- |
| 📍 所在位置       | 只在**非静态成员函数**中有效                          |
| 📎 类型           | `ClassName* const this` —— 不能修改指向，只能修改内容 |
| 🚫 静态函数中没有 | 静态成员函数不属于对象 → 没有 `this` 指针             |
