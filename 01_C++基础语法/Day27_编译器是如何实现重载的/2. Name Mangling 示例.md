## 2. **Name Mangling 示例**

用 g++ 编译：

```
#include <iostream>
void foo(int)    { std::cout << "int\n"; }
void foo(double) { std::cout << "double\n"; }

int main() {
    foo(1);
    foo(1.0);
}
```

用 `g++ -c test.cpp && nm test.o` 查看符号：

```
0000000000000000 T _Z3fooi     // foo(int)
0000000000000010 T _Z3food     // foo(double)
```

- `_Z` 是 GCC 的前缀
- `3foo` 表示函数名长度和名字
- `i` 表示 `int` 类型
- `d` 表示 `double` 类型

这样，即使你写了多个 `foo`，编译器内部也是**不同的符号名**，链接器能正确区分。
