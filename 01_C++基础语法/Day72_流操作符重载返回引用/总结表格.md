## 总结表格

| 操作符          | 常见函数签名                              | 返回类型   | 原因                      |
| --------------- | ----------------------------------------- | ---------- | ------------------------- |
| 输出运算符 `<<` | `ostream& operator<<(ostream&, const T&)` | `ostream&` | 支持链式输出 + 避免复制流 |
| 输入运算符 `>>` | `istream& operator>>(istream&, T&)`       | `istream&` | 支持链式输入 + 检查状态   |
| 算术运算符 `+`  | `T operator+(const T&, const T&)`         | 返回值     | 新对象（非原对象）        |
| 赋值运算符 `=`  | `T& operator=(const T&)`                  | 引用       |                           |

## 总结一句话

> **流操作符重载返回引用，是为了支持链式操作，并保持流对象语义与性能。**

`ostream`、`istream` 对象（如 `cout`、`cin`）**不能被复制**：

```
std::ostream cout = std::cout;  // ❌ 错误：ostream 不可拷贝
```

因为流对象内部管理缓冲区、文件描述符等资源，复制会破坏状态。

👉 因此，函数必须返回**引用（引用原对象）**而不是返回一个新对象。
