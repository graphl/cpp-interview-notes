## “流操作符重载为什么返回引用
（如 `ostream& operator<<(ostream&, const T&)`）”是 C++ 运算符重载中**最常见又最容易被忽略的设计细节**。

 我们来系统地讲一遍。

------

## 🧩 一、先看标准写法

```
#include <iostream>
using namespace std;

class Person {
    string name;
    int age;
public:
    Person(string n, int a) : name(n), age(a) {}

    // 友元方式重载输出运算符
    friend ostream& operator<<(ostream& os, const Person& p) {
        os << p.name << " " << p.age;
        return os;   // ✅ 返回引用
    }
};
```

使用：

```
Person p("Tom", 18);
cout << p << endl;
```

------

## 🧠 二、为什么要返回引用？

### 1️⃣ 为了**支持连续输出**（链式调用）

如果返回引用，就可以写：

```
cout << p << " OK" << endl;
```

编译器实际做的是：

```
((cout << p) << " OK") << endl;
```

这要求：

- 第一次调用 `operator<<` 返回的对象，
   仍然是同一个可继续操作的 `ostream` 对象。

📘 具体过程：

1️⃣ `cout << p`
 → 调用 `operator<<(ostream&, const Person&)`
 → 返回 `cout` 的引用

2️⃣ `cout << " OK"`
 → 再次调用 `operator<<(ostream&, const char*)`
 → 同样返回 `cout` 的引用

3️⃣ 最后 `cout << endl` 执行。

📌 如果你不返回引用，而是返回一个临时对象或 void：

```
ostream operator<<(ostream& os, const Person& p)  // ❌ 错误设计
{
    os << p.name << " " << p.age;
    return os;   // 返回副本（效率低，也无法继续 <<）
}
```

就会导致：

- 每次都复制 `ostream`（代价高昂）；
- 不能连续输出，因为副本不是同一个流对象。

------

### 2️⃣ 为了**性能和语义正确性**

`ostream`、`istream` 对象（如 `cout`、`cin`）**不能被复制**：

```
std::ostream cout = std::cout;  // ❌ 错误：ostream 不可拷贝
```

因为流对象内部管理缓冲区、文件描述符等资源，复制会破坏状态。

👉 因此，函数必须返回**引用（引用原对象）**而不是返回一个新对象。

------

### 3️⃣ 为了**支持错误检测链式表达式**

有时候我们会这样写：

```
if (!(cin >> a >> b)) {
    cerr << "输入错误！\n";
}
```

`operator>>` 必须返回 `istream&` 引用，
 这样每次操作完都可以继续传递输入流对象的状态。

如果输入失败，`cin.fail()` 会为真，后续链式操作会自动失效。
