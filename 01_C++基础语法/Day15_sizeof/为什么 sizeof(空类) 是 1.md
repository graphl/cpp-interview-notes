# 为什么 `sizeof(空类)` 是 1

📌 原因一：**对象必须具有唯一地址**， 如果大小是 0，两个空对象的地址会一样，那就无法区分这两个对象了。为了避免这个问题，**C++ 要保证每个对象都有唯一地址 → 至少 1 字节**。

即使类里什么都没有，C++ 也必须为它分配至少一个字节的空间：

```
class Empty {};

int main() {
    Empty e1;
    Empty e2;
    printf("%p\n", &e1);
    printf("%p\n", &e2);
}
```

`sizeof(Empty)` 通常是 1，但 **编译器可以做优化**（如：不放在数组里时可能优化掉）。
